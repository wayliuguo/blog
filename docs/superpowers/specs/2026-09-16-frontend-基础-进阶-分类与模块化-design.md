# 前端知识体系「基础 / 进阶」分类与 Node 式模块化设计

> 日期：2026-09-16
> 状态：待用户 review
> 目标：将 `frontend/` 重构为「基础 / 进阶」两级目录，并全量对齐 node 后端章节的模块化组织格式。

## 一、背景与目标

当前 `frontend/` 为 11 个平级章节目录，每章含 `NN-面试模式.md` 与 `code/`。本次调整：

1. 按学习路径分为「基础」「进阶」两个部分（物理移动目录）。
2. 对齐 node 后端组织格式：每章新增无序号 `总结.md`，现有「面试模式」改名无序号 `面试题.md`。
3. code 目录严格一一对应：基础章与进阶章各自持有自己的 code，不跨章引用。
4. 每篇小文档末尾新增「本节小结」。

## 二、分类规则

- **基础**：HTML、CSS、JavaScript 核心、网络与浏览器、前端框架 React（不含原理）、前端框架 Vue（不含原理）。
- **进阶**：TypeScript、前端工程化与构建、交付与质量、前端框架原理（React 原理 + Vue 原理合并）、性能优化与监控、工程实践与架构。
- 「04-网络与浏览器」的 `04-前端安全` 留在基础（与同源策略、Cookie 作用域一体讲解）。

## 四、命名与格式规则（对齐 node）

| 项 | 规则 | node 参照 |
| --- | --- | --- |
| 模块总结 | 文件名 `总结.md`，无序号；知识主线（依赖链）+ 分篇知识点 | `node/01-运行环境/总结.md` |
| 模块面试题 | 文件名 `面试题.md`，无序号；五步法（结论/原理/边界/追问/场景） | `node/01-运行环境/面试题.md` |
| 章节小结 | 每篇小文档末尾「本节小结」2-4 行收口 | 各 node 正文尾部 |
| 侧边栏 | 章末列「模块总结（章名）」「模块面试题（章名）」 | `.vitepress/config/node.js` |

原 `NN-面试模式.md` 全部改名 `面试题.md`（去序号），内容沿用。

## 五、code 一一对应

- 每章只引用自己 `code/` 下的 demo。
- React 原理 / Vue3 原理的 demo（mini-runtime、vdom-diff、hooks-demo、mini-reactive、compiler-demo、vdom-vue-diff 等）**复制**进进阶 `04-前端框架原理/code/`；React/Vue 基础章 code 保留原 demo，基础章正文引用不变。
- 移入进阶的原理篇正文中，code 引用改为本章 `code`。

## 六、侧边栏与导航

- `frontend.js` 重构为「基础」「进阶」两个大组；每组按章分组，章末挂「模块总结」「模块面试题」。
- `nav.js`「前端」入口指向基础第一章 `01-HTML 基础/01-HTML 语义化与结构`。

## 七、执行步骤概要

1. 建 `frontend/基础/` 与 `frontend/进阶/`，按结构移动/复制目录（robocopy /MOVE 规避 Windows 锁）。
2. React/Vue 原理文件移入进阶新章；基础章重编号（React 面试模式 08→07、Vue 面试模式 05→04 时改为无序号 `面试题.md`，不占编号）。
3. 各章新增 `总结.md`；原 `NN-面试模式.md` 改名 `面试题.md`。
4. 复制原理 demo 至进阶章 code，并修正移入文件中的 code 引用与交叉引用。
5. 重写 `frontend.js`，更新 `nav.js`。
6. 每篇小文档补「本节小结」。
7. `vitepress build` 验证无死链。
