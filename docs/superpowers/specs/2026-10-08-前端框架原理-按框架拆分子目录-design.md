# 前端框架原理：按框架拆分子目录（react/ 与 vue3/）

## 背景与目标

`frontend/进阶/前端框架原理/` 模块现有 6 篇文档 + 3 套配套代码，React 与 Vue3 内容平铺在模块根目录，状态管理为一篇框架无关的「三条路线」通用篇。本次改造：

1. 模块按框架拆分为 `react/` 与 `vue3/` 两个子目录。
2. 状态管理原理与实现按框架拆分进各子目录：React 侧覆盖当前最流行的 Redux / Zustand，Vue3 侧覆盖 Pinia。
3. 配套代码按框架拆成两个实验台，原 `mini-store` 拆散并入。

- 子目录命名沿用用户指定 `react/`、`vue3/`，无编号，符合板块规范。
- 总结.md / 面试题.md 保留在模块根目录，符合「模块元页面在模块根」的约定。
- 侧边栏 `.vitepress/config/frontend.js` 中「前端框架原理」items 改为指向子目录链接。

## react/ 状态管理篇内容映射

「三条路线」中 reducer 与 setState 两条归 React（判断放在订阅者手里的两条路），signal 归 Vue3。

- **引子**：三个真问题 + 判断分层（保留核心论点「被唤醒 ≠ 重渲染」）。
- **路线一 reducer → mini-redux**：纯函数、引用短路、原地改后果、immer 说明；实现 `createStore`/`combineReducers`（复用原 redux-like.js）+ 新增绑定层 Provider/useSelector/useDispatch（context + 订阅，跑在假渲染器上计数）。
- **路线二 setState → mini-zustand**：浅合并、逐键 Object.is、选择器返回新对象陷阱、shallowEqual、记忆化；实现 `create`（复用原 zustand-like.js）+ 新增绑定层 useStore（getSnapshot+subscribe+selector，等价 useSyncExternalStore 语义，假渲染器实测重渲染次数）。
- **对照与选型**：原篇场景表去掉 signal 行，保留「Redux vs Zustand」；边界（服务端状态、何时不需要状态库）。

## vue3/ 状态管理篇内容映射

- **引子**：三个真问题 + 判断分层，衔接响应式路线（判断放在 store 内部）。
- **响应式底座**：三层依赖表、effect cleanup、computed——简短带过并回链手写 mini-vue 篇，说明「这就是 Pinia 精确唤醒的机制」。
- **store 是什么**：state/getters/actions、setup store、id 即命名空间、storeToRefs 解构。
- **手写 mini-pinia**：`defineStore`（setup 风格）、`useStore`（activePinia 单例实例化）、`storeToRefs`（proxyRefs 思路，只解包第一层）、`$patch`（批量更新 + 逐键 Object.is）、跨 store 引用。
- **对照表**：Pinia vs Vuex vs Redux（复用原篇对照表并精简）。

## 配套代码拆解

**code/react/mini-state**（新实验台，由 mini-store 拆分）
- `redux-like.js`（原样）：createStore + combineReducers
- `zustand-like.js`（原样）：create + 逐键 Object.is
- `harness.js`（原样）：subscribeWithSelector / mount / shallowEqual
- 新增 `binding.js`：Redux 绑定（Provider/useSelector/useDispatch，context 传递 store + 订阅）与 Zustand 绑定（useStore = getSnapshot + subscribe + selector），均对接假渲染器（复用 mount 计数）
- steps/：`01-reducer.js`、`02-selector.js` 保留改写，新增 `03-binding.js`（跑出「重渲染次数」实测）；删除 signal 相关的 03/04
- test：`store.test.js` 拆成 redux 单测 + zustand 单测 + 绑定层单测

**code/vue3/mini-pinia**（新实验台）
- `reactivity.js`（由 signal.js 拆出）：三层依赖表 / effect / computed
- 新增 `pinia.js`：`createPinia` + `defineStore`（setup 风格）+ `useStore`（activePinia 实例化）+ `storeToRefs`（proxyRefs 思路）+ `$patch`
- steps/：`01-reactivity.js`（精简，回链 mini-vue）、`02-pinia.js`（defineStore/storeToRefs/$patch 实测）、`03-compare.js`（Pinia vs 直接 reactive vs Vuex 式 mutation 对照）
- test：响应式底座单测 + pinia 单测（含 $patch、storeToRefs、跨 store 引用）

**code 目录调整**
- `mini-react` → `code/react/mini-react`，`mini-vue` → `code/vue3/mini-vue`（原样移动）
- `site/` 演示页按框架归属：vdom-vue-diff / mini-reactive / compiler-demo → vue3/；vdom-diff / mini-runtime / hooks-demo → react/
- 删除原 `mini-store` 项目与顶层 `server.js`（入口并入两实验台各自 package.json）
