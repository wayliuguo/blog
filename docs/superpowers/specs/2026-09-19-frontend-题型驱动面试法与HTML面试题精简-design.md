## 3. 题型驱动答题法（方法论核心，保留并重写）

### 3.1 4 类题型与骨架

单一模板改为**按题型定结构**，每类骨架 2–3 步，几步用不上就跳过：

| 题型 | 骨架（2–3 步） | 一句话标注 | 覆盖的诊断原题 |
|------|----------------|-----------|----------------|
| **概念题**（是什么） | 定义一句 → 为什么/原理 → 反例或边界 | 讲"它是什么" | Q1、Q2、Q4 |
| **机制题**（怎么工作） | 输入→过程→输出（步骤/时序）→ 一个关键细节 | 讲"它怎么动起来的" | Q5、Q10、Q12 |
| **对比题**（A vs B） | 一句话本质区别 → 按固定维度列对比 → 一句实际取舍 | 讲"它俩差在哪" | Q3、Q7、Q14、Q6 |
| **场景/选型题**（怎么办） | 目标 → 排查/步骤顺序 → 最终选型或修复 | 讲"出问题时怎么做" | Q20 |

### 3.2 归型原则

- **题型由"题眼"决定**，而非"题目里有几个知识点"。看面试官真正问什么——"解释原理"归机制、"给方案"归场景。
- 一道题既涉及机制又涉及场景时，以主题型为主，另一类作纵深（不另起骨架）。
- 每题必须以**一句能背下来的判断句打头**（保底结论），保证不冷场；往深答与否由题型 + 时间决定。

### 3.3 题型驱动 vs 五步答题法

| 维度 | 五步答题法 | 题型驱动答题法 |
|------|-----------|----------------|
| 结构来源 | 统一五步（结论/原理/场景/边界/追问） | 由题型决定 2–3 步骨架 |
| 重点 | 平均用力，易冗余 | 每类题的关键点天然突出 |
| 题型适配 | 概念/对比/场景一套模板通吃 | 各自骨架，不凑步骤 |
| 时间匹配 | 五步全走易拖沓 | 骨架短，符合 1–3 分钟答题节奏 |
