## 5. 模块总结新格式（样板：HTML 基础，已确认）

文件 `frontend/基础/HTML 基础/总结.md` 为已确认样板。文件结构：

```markdown
# 模块总结 · HTML 基础

## 大纲
- **1. 文档结构与语义化**
  - 1.1 标签形态与文档骨架
  - 1.2 文档头部：meta 与渲染模式
  - …
- **2. 表单与标签**
  - 2.1 表单基础：提交、输入控件与标签
  - …
- **3. 无障碍与可访问性**
  - 3.1 无障碍树：role / name / state
  - …

## 1. 文档结构与语义化
### 1.1 标签形态与文档骨架
（知识域正文，必要时嵌 ASCII 图 / 代码）
…
```

要点（已经用户确认）：

- **开头无说明段**：`# 模块总结` 之后直接进 `## 大纲`，删去「知识主线」「分篇知识点」「篇级 ASCII 树」「主轴段落」等独立说明。
- **大纲按知识体系章节分层**，不扁平：一级章节用 `- **N. 章节名**`，章节下再列 `N.N` 知识域；按 HTML 知识体系的三大板块（结构语义 / 表单 / 无障碍）归类，而不是把全部知识域 1~17 平铺。
- **正文两级标题**：章节用 `## N`、知识域用 `### N.N`，与大纲编号一一对应，标题层级不跳级（符合无障碍规范）。
- **方案②局部 ASCII 图**：不画模块级总骨架图；只在知识域节点内、内容本身有结构时落局部 ASCII 图（树 / 分步 / 对比盘）。
- **内容形态→表达方式**：有父子/嵌套→树形 ASCII；有先后→分步 ASCII；对比→表格/两列；平级罗列→列表。
- **全量收纳**：按知识体系结构化收纳全部知识文档内容，不遗漏、不做高频筛选、不注出处篇号；每个点细化到"能一句话讲清 + 必要时恰配 ASCII/代码"，不允许只留名词。
- 规范 `reference/模块总结与模块面试题.md` 里写入该模板与五维选点原则（面试命中 / 日常复用 / 底层关联 / 纵深区分 / 排查刚需）。
