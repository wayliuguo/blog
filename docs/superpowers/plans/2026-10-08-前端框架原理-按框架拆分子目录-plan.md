## P1 react/ 实验台 mini-state

由 `code/mini-store` 拆出 + 新增绑定层：

- 原样迁入：`src/redux-like.js`、`src/zustand-like.js`、`src/harness.js`、`src/demo.js`
- 新增 `src/binding.js`：Redux 绑定（`Provider` + `useSelector` + `useDispatch`，context 传递 store + 订阅）与 Zustand 绑定（`useStore = getSnapshot + subscribe + selector`，等价 `useSyncExternalStore` 语义），两者对接假渲染器 `mount` 计数
- `steps/01-reducer.js`、`steps/02-selector.js` 保留改写；新增 `steps/03-binding.js`（跑出「绑定层重渲染次数」实测）；删除 `03-signal.js`、`04-compare.js`
- `test/store.test.js` 拆为 redux 单测 + zustand 单测 + 绑定层单测（`node:test`，零依赖）
- `package.json`：保留 step / test scripts

**验证**：`cd code/react/mini-state && npm test` 全绿；`npm run step:binding` 输出「被唤醒 / 重渲染」计数且与正文摘录逐字一致。

- 由 `mini-store` 的 `src/signal.js` 拆出 `src/reactivity.js`（三层依赖表 / effect / computed）
