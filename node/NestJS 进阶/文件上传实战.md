## 单文件上传

> 摘自 `./code/advanced-lab/src/04-file-upload.ts`（运行：`npm run 04upload`）

```typescript
// …（上传根目录在系统临时目录里，跑完自动清掉，不污染仓库）

const UPLOAD_ROOT = join(tmpdir(), 'advanced-lab-uploads')
const AVATAR_DIR = join(UPLOAD_ROOT, 'avatars')

// …

@Controller('upload')
export class UploadController {
    @Post('avatar')
    @UseInterceptors(
        FileInterceptor('file', {
            storage: diskStorage({
                destination: AVATAR_DIR,
                filename: (req, file, callback) => {
                    const uniqueSuffix = Date.now() + '-' + Math.round(Math.random() * 1e9)
                    const ext = extname(file.originalname)
                    callback(null, `${uniqueSuffix}${ext}`)
                }
            }),
            limits: {
                fileSize: 2 * 1024 * 1024 // 2MB
            },
            fileFilter: (req, file, callback) => {
                if (!file.mimetype.match(/^image\/(jpeg|png|webp)$/)) {
                    callback(new BadRequestException('只支持 JPEG/PNG/WebP 格式'), false)
                    return
                }
                callback(null, true)
            }
        })
    )
    uploadAvatar(@UploadedFile() file: Express.Multer.File) {
        if (!file) {
            throw new BadRequestException('请选择文件')
        }
        return {
            url: `/uploads/avatars/${file.filename}`,
            size: file.size,
            mimetype: file.mimetype
        }
    }

    // …（同一个控制器里还有多文件上传、管道校验、目录列表三个接口）
}
```

实测输出（`npm run 04upload`，脚本用 `fetch` + `FormData` 真的把文件传上去）：

```
=== 1) 单文件上传：图片通过两道闸，落盘并返回 URL ===
  POST /upload/avatar  avatar.png   (image/png, 2048B) → 201 {"url":"/uploads/avatars/1789629115598-201496100.png","size":2048,"mimetype":"image/png"}

=== 2) 按返回的 URL 把文件读回来：静态资源确实开好了 ===
  GET  /uploads/avatars/1789629115598-201496100.png → 200 image/png
  磁盘上这个文件 2048 字节，和上传的 2048 字节一致：true

=== 3) fileFilter 挡下非图片：只支持 JPEG/PNG/WebP ===
  POST /upload/avatar  note.txt     (text/plain, 128B) → 400 {"message":"只支持 JPEG/PNG/WebP 格式","error":"Bad Request","statusCode":400}

=== 4) limits.fileSize 挡下超大文件：2MB 上限 ===
  POST /upload/avatar  huge.png     (image/png, 3145728B) → 413 {"message":"File too large","error":"Payload Too Large","statusCode":413}
```

两道闸的分工在输出里看得很清楚：`fileFilter` 拦下的请求**进不了 controller**（400 + 自己写的消息），`limits.fileSize` 超限则由 multer 抛出、Nest 翻译成 **413**（消息是框架默认的 `File too large`）。文件名用「时间戳 + 随机数 + 原扩展名」，重名和中文乱码都躲开了。

## 多文件上传

> 摘自 `./code/advanced-lab/src/04-file-upload.ts`（运行：`npm run 04upload`）

```typescript
    // ====== 2) 多文件上传 ======
    // 这里没传 storage，用的是 multer 默认的内存存储：文件不落盘，内容在 file.buffer 里，
    // 也**没有** file.filename（那个字段只有 diskStorage 才会填），只演示「一次收多个文件 + 限制数量」
    @Post('photos')
    @UseInterceptors(FilesInterceptor('files', 10)) // 最多 10 张
    uploadPhotos(@UploadedFiles() files: Express.Multer.File[]) {
        return files.map(file => ({
            name: file.originalname,
            size: file.size
        }))
    }
```

实测输出（`npm run 04upload` 第 5 段，一次传 3 个文件）：

```
=== 5) 多文件上传：FilesInterceptor(files, 10) ===
  POST /upload/photos 3 个文件 → 201 [{"name":"p1.png","size":100},{"name":"p2.png","size":200},{"name":"p3.png","size":300}]
```

## 自定义文件校验管道

> 摘自 `./code/advanced-lab/src/04-file-upload.ts`（运行：`npm run 04upload`）

```typescript
@Injectable()
export class FileValidationPipe implements PipeTransform {
    constructor(private readonly maxSize: number) {}

    transform(file: Express.Multer.File) {
        if (!file) {
            throw new BadRequestException('文件不能为空')
        }

        // 校验文件大小
        if (file.size > this.maxSize) {
            throw new BadRequestException(`文件大小不能超过 ${this.maxSize / 1024 / 1024}MB`)
        }

        // 校验文件类型
        const allowed = ['image/jpeg', 'image/png', 'image/webp', 'application/pdf']
        if (!allowed.includes(file.mimetype)) {
            throw new BadRequestException('不支持的文件类型')
        }

        return file
    }
}

// …

    // ====== 3) 文件也能被管道校验 ======
    @Post('document')
    @UseInterceptors(FileInterceptor('file'))
    uploadDoc(@UploadedFile(new FileValidationPipe(10 * 1024 * 1024)) file: Express.Multer.File) {
        return { filename: file.originalname, size: file.size, mimetype: file.mimetype }
    }
```

实测输出（`npm run 04upload` 第 6 段，同一个接口换个 mimetype，结果就不一样）：

```
=== 6) FileValidationPipe：大小与 mimetype 白名单 ===
  POST /upload/document report.pdf   (application/pdf, 4096B) → 201 {"filename":"report.pdf","size":4096,"mimetype":"application/pdf"}
  POST /upload/document tool.exe     (application/x-msdownload, 4096B) → 400 {"message":"不支持的文件类型","error":"Bad Request","statusCode":400}
```

## 静态资源访问

> 摘自 `./code/advanced-lab/src/04-file-upload.ts`（运行：`npm run 04upload`）

```typescript
const app = await NestFactory.create<NestExpressApplication>(AppModule, { logger: false })

// ====== 静态资源访问 ======
// 不挂这行，文件虽然存下来了，但 /uploads/xxx 访问不到
app.useStaticAssets(UPLOAD_ROOT, {
    prefix: '/uploads/' // 访问路径：http://localhost:3000/uploads/xxx.jpg
})

await app.listen(0, '127.0.0.1')
```

实测输出（`npm run 04upload` 第 2 段，按接口返回的 URL 再读一次）：

```
=== 2) 按返回的 URL 把文件读回来：静态资源确实开好了 ===
  GET  /uploads/avatars/1789629115598-201496100.png → 200 image/png
  磁盘上这个文件 2048 字节，和上传的 2048 字节一致：true
```

注意 `prefix` 要和上面返回的 `url` 前缀（`/uploads/avatars/...`）对得上，否则前端拿到的地址就是 404。

## 生产场景：用户头像上传完整流程

| 步骤 | 说明 |
|------|------|
| 1. 前端选择图片 | 客户端限制格式和大小 |
| 2. 服务端验证 | 类型、大小、是否恶意文件 |
| 3. 重命名存储 | 避免文件名冲突和中文乱码 |
| 4. 生成缩略图 | 可选，用 sharp 压缩 |
| 5. 返回 URL | 保存到用户表 |
| 6. 静态资源访问 | 配置 nginx 或 Nest 静态服务 |

## 小结

- **单文件上传**：`FileInterceptor('file', {...})` 首个参数须与表单字段名一致，取参 `@UploadedFile()`；`diskStorage` 用 timestamp+随机数+`extname` 防重名与中文乱码
- **两道校验闸**
  - `limits.fileSize` 限大小（如 `2*1024*1024`），`fileFilter` 用 mimetype 正则挡非图片，拒绝传 `false` 并抛 `BadRequestException`
  - 也可写 `PipeTransform`，在 `@UploadedFile(new FileValidationPipe(10*1024*1024))` 处校验大小与 mimetype 白名单
- **多文件上传**：`FilesInterceptor('files', 10)` 第二个参数为上限数量，取参 `@UploadedFiles()` 拿数组
- **静态资源要显式开**：`app.useStaticAssets(join(...), { prefix: '/uploads/' })`，否则文件存了也访问不到
- **头像上传链路**：前端限格式大小 → 服务端验类型/大小/恶意文件 → 重命名存储 → `sharp` 缩略图(可选) → 返回 URL 存用户表 → 配静态访问
