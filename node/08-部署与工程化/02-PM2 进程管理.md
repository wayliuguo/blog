# PM2 进程管理

---

## [初级] PM2 是什么

PM2 是 Node.js 的进程管理工具，用于在生产环境中运行和管理 Node.js 应用。

### 安装

```bash
npm install -g pm2
```

## [初级] 常用命令

```bash
# 启动应用
pm2 start dist/main.js --name my-app

# 查看所有进程
pm2 list

# 查看日志
pm2 logs
pm2 logs my-app --lines 100  # 查看最后 100 行

# 重启
pm2 restart my-app

# 重新加载（零停机）
pm2 reload my-app

# 停止
pm2 stop my-app

# 删除进程
pm2 delete my-app
```

## [中级] 集群模式

Node.js 默认是单线程的，PM2 的集群模式可以启动多个进程，利用多核 CPU。

```bash
# 启动 4 个进程（利用 4 核 CPU）
pm2 start dist/main.js -i 4 --name my-app

# 启动与 CPU 核心数相同的进程
pm2 start dist/main.js -i max --name my-app

# 查看集群状态
pm2 list
# 你会看到 4 个进程，名称都是 my-app
```

## [中级] 守护进程与自动重启

```bash
# 应用崩溃后自动重启
pm2 start app.js --name my-app --watch  # 监听文件变化

# 内存超过指定大小时自动重启
pm2 start app.js --max-memory-restart 500M

# 保存当前进程列表，系统重启后自动恢复
pm2 save
pm2 startup  # 生成开机自启脚本
```

### ecosystem.config.js

```javascript
module.exports = {
    apps: [{
        name: 'my-app',
        script: 'dist/main.js',
        instances: 'max',         // 集群模式，最大进程数
        exec_mode: 'cluster',     // 集群模式
        max_memory_restart: '500M',
        env: {
            NODE_ENV: 'development'
        },
        env_production: {
            NODE_ENV: 'production'
        },
        error_file: './logs/err.log',     // 错误日志
        out_file: './logs/out.log',       // 输出日志
        log_date_format: 'YYYY-MM-DD HH:mm:ss'
    }]
}
```
