# 脚手架开发入门


---

## 什么是脚手架

脚手架（Scaffold）是用于自动化项目创建的工具。用户通过命令行交互，选择配置后自动生成项目模板。

**常见例子**：
- `create-react-app` → React 项目
- `nest new` → NestJS 项目
- `vue create` → Vue 项目

## 核心流程

```
1. 用户输入命令
2. 交互式问答（项目名称、模板类型等）
3. 根据用户选择复制模板文件
4. 替换模板中的变量
5. 输出生成的项目
```

## 实战：创建一个简易脚手架

### 项目结构

```
my-cli/
├── package.json
├── bin/
│   └── index.js          # 入口文件
├── templates/
│   ├── basic/            # 基础模板
│   │   ├── package.json
│   │   └── index.js
│   └── api/              # API 模板
│       ├── package.json
│       ├── index.js
│       └── routes.js
└── index.js
```

### 入口文件

> 示意片段（无配套脚本）
```javascript
#!/usr/bin/env node
// bin/index.js

const fs = require('fs-extra')
const path = require('path')
const inquirer = require('inquirer')

async function main() {
    // 1. 交互式问答
    const answers = await inquirer.prompt([
        {
            type: 'input',
            name: 'projectName',
            message: '项目名称:',
            default: 'my-app'
        },
        {
            type: 'list',
            name: 'template',
            message: '选择模板:',
            choices: ['basic', 'api']
        }
    ])

    const targetDir = path.join(process.cwd(), answers.projectName)

    // 2. 复制模板
    const templateDir = path.join(__dirname, '../templates', answers.template)
    await fs.copy(templateDir, targetDir)

    // 3. 替换模板变量（使用 ejs 或手动替换）
    const packageJson = await fs.readFile(
        path.join(targetDir, 'package.json'),
        'utf8'
    )
    const result = packageJson.replace(/{{projectName}}/g, answers.projectName)
    await fs.writeFile(path.join(targetDir, 'package.json'), result)

    console.log(`项目 ${answers.projectName} 创建成功！`)
    console.log(`cd ${answers.projectName} && npm install`)
}

main().catch(console.error)
```

### package.json

```json
{
    "name": "my-cli",
    "version": "1.0.0",
    "bin": {
        "create-my-app": "./bin/index.js"
    },
    "dependencies": {
        "inquirer": "^8.0.0",
        "fs-extra": "^10.0.0"
    }
}
```

## yargs 的基本使用

yargs 是 Node.js 最流行的命令行参数解析库。

> 示意片段（无配套脚本）
```javascript
#!/usr/bin/env node
const yargs = require('yargs/yargs')
const { hideBin } = require('yargs/helpers')

yargs(hideBin(process.argv))
    .command(
        'create <name>',
        '创建新项目',
        (yargs) => {
            yargs.positional('name', {
                describe: '项目名称',
                type: 'string'
            })
            .option('template', {
                alias: 't',
                describe: '模板类型',
                choices: ['basic', 'api'],
                default: 'basic'
            })
        },
        (argv) => {
            console.log(`创建项目: ${argv.name}, 模板: ${argv.template}`)
        }
    )
    .option('verbose', {
        alias: 'v',
        type: 'boolean',
        description: '输出详细信息'
    })
    .help()
    .argv

// 使用
// my-cli create my-app
// my-cli create my-app --template api
// my-cli --help
```

## 小结

- **脚手架的定位**：自动化创建项目的工具，用户命令行交互选配置后自动生成模板，如 `create-react-app`、`nest new`
- **核心流程**：用户输入命令 → 交互式问答（项目名、模板类型）→ 复制模板文件 → 替换模板变量 → 输出生成的项目
- **CLI 工程的三个落点**
  1. 入口约定：`bin/index.js` 首行 `#!/usr/bin/env node`，在 `package.json` 的 `bin` 字段映射成全局命令名
  2. 依赖分工：inquirer 负责交互问答，fs-extra 负责目录复制（比原生 fs 多递归与覆盖便利）
  3. 变量替换：复制完模板读文件，用 `replace(/{{projectName}}/g, ...)` 把占位符换成真实项目名
- **yargs 参数解析**：`command('create <name>')` 定义子命令与 positional，`option` 定义 `--template` 等可选参数，`.help()` 自动生成帮助
