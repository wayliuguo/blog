# 设计模式

---

## [中级] 单例模式

确保一个类只有一个实例。NestJS 的 Provider 默认就是单例。

```typescript
// NestJS 中默认就是单例模式
@Injectable()
export class DatabaseService {
    private connections: number = 0

    getConnection() {
        this.connections++
        return `Connection #${this.connections}`
    }
}

// 无论注入到多少个类中，都是同一个实例
```

## [中级] 策略模式

定义一系列算法，使它们可以互相替换。NestJS 的 Guard 和自定义 Provider 常用于实现策略模式。

```typescript
// 登录策略接口
export interface AuthStrategy {
    validate(token: string): Promise<User>
}

// 多种实现
@Injectable()
export class JwtStrategy implements AuthStrategy {
    async validate(token: string) {
        // 验证 JWT
    }
}

@Injectable()
export class WechatStrategy implements AuthStrategy {
    async validate(token: string) {
        // 微信登录验证
    }
}

// 运行时选择策略
@Injectable()
export class AuthService {
    constructor(
        @Inject('AUTH_STRATEGY')
        private strategy: AuthStrategy
    ) {}

    async login(token: string) {
        return this.strategy.validate(token)
    }
}
```

## [中级] 观察者模式

当对象状态变化时，自动通知所有依赖它的对象。NestJS 的事件系统（EventEmitter）实现了观察者模式。

```bash
npm install @nestjs/event-emitter
```

```typescript
// 发布事件
@Injectable()
export class OrderService {
    constructor(private eventEmitter: EventEmitter2) {}

    async createOrder(dto: CreateOrderDto) {
        const order = await this.orderRepository.save(dto)

        // 发布事件
        this.eventEmitter.emit('order.created', order)
        return order
    }
}

// 监听事件
@Injectable()
@OnEvent('order.created')
export class OrderCreatedListener {
    @OnEvent('order.created')
    handleOrderCreated(order: Order) {
        // 发送短信、更新库存等
        console.log('订单创建:', order.id)
    }
}
```

## [中级] 工厂模式

封装对象的创建逻辑。NestJS 的自定义 Provider 的 `useFactory` 就是工厂模式的应用。

```typescript
@Module({
    providers: [
        {
            provide: 'DB_CONNECTION',
            useFactory: (config: ConfigService) => {
                // 根据环境创建不同的数据库连接
                if (config.get('NODE_ENV') === 'production') {
                    return createProdConnection(config)
                }
                return createDevConnection(config)
            },
            inject: [ConfigService]
        }
    ]
})
export class DatabaseModule {}
```
