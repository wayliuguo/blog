# 事件循环与错误处理

---

## [初级] 事件循环（Event Loop）

事件循环是 Node.js 的核心机制，它让 JavaScript 可以"非阻塞"地处理异步操作。

### 简化版执行顺序

```
执行同步代码
    ↓
处理微任务队列（process.nextTick、Promise.then）
    ↓
处理宏任务队列（setTimeout、setInterval、I/O 回调）
    ↓
重复以上步骤
```

### 代码示例

```javascript
console.log('1')  // 同步，先执行

setTimeout(() => {
    console.log('2')  // 宏任务
}, 0)

Promise.resolve().then(() => {
    console.log('3')  // 微任务
})

console.log('4')  // 同步，后执行

// 输出顺序：1 → 4 → 3 → 2
```

## [中级] 宏任务与微任务

| 类型 | 包含 | 优先级 |
|------|------|--------|
| 微任务 | `process.nextTick`、`Promise.then/catch/finally` | 高（先执行） |
| 宏任务 | `setTimeout`、`setInterval`、I/O 回调、`setImmediate` | 低（后执行） |

**关键规律**：
1. 同步代码执行完
2. 清空微任务队列
3. 执行一个宏任务
4. 再清空微任务队列
5. 再执行下一个宏任务

```javascript
console.log('1')

setTimeout(() => {
    console.log('2')
    Promise.resolve().then(() => console.log('3'))
}, 0)

setTimeout(() => {
    console.log('4')
}, 0)

Promise.resolve().then(() => console.log('5'))

console.log('6')

// 输出：1 → 6 → 5 → 2 → 3 → 4
```

## [初级] 常见错误类型

### 语法错误

```javascript
// 代码写错了，Node.js 根本没法运行
console.log('hello  // 少了一个引号
```

### 运行时错误

```javascript
// 代码能运行，但执行时出错
const obj = null
console.log(obj.name)  // TypeError: Cannot read properties of null
```

### 逻辑错误

```javascript
// 代码能运行，但结果不对
function getDiscount(price) {
    if (price > 100) {
        return price * 0.9  // 打 9 折
    }
    return price
}
// 没有考虑到 price 是负数的情况
```

## [初级] 错误处理最佳实践

### 同步代码：try/catch

```javascript
try {
    const data = JSON.parse(userInput)
    console.log(data.name)
} catch (err) {
    console.error('JSON 解析失败:', err.message)
}
```

### 异步代码：Promise.catch

```javascript
// 不好的做法
const data = await riskyFunction()  // 可能抛异常，没处理

// 好的做法
try {
    const data = await riskyFunction()
} catch (err) {
    console.error('操作失败:', err)
}
```

### 全局未捕获异常

```javascript
// 处理未捕获的 Promise 异常
process.on('unhandledRejection', (reason, promise) => {
    console.error('未处理的 Promise 拒绝:', reason)
})

// 处理未捕获的同步异常
process.on('uncaughtException', (err) => {
    console.error('未捕获的异常:', err)
    // 记录日志后优雅退出
    process.exit(1)
})
```

> 注意：`uncaughtException` 不推荐用于恢复程序运行，它只是让你在崩溃前做清理工作。

## 面试题

### Q1: 事件循环中微任务和宏任务的执行顺序？

同步代码 → 清空微任务队列 → 执行一个宏任务 → 清空微任务队列 → 下一个宏任务。微任务包括 `process.nextTick` 和 `Promise.then`，宏任务包括 `setTimeout`、`setInterval`、I/O 回调。

### Q2: `process.nextTick` 和 `Promise.then` 谁先执行？

`process.nextTick` 的优先级高于 `Promise.then`。`nextTick` 是微任务队列中最先被执行的。
