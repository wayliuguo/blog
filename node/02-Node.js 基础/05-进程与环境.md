## [初级] process 对象

`process` 是一个全局对象，提供当前 Node.js 进程的信息和控制。

### 常用属性

```javascript
// 进程信息
console.log(process.pid)          // 进程 ID
console.log(process.title)        // 进程标题
console.log(process.arch)         // 架构: 'x64' | 'arm64'
console.log(process.platform)     // 平台: 'win32' | 'darwin' | 'linux'
console.log(process.version)      // Node.js 版本号

// 内存使用
console.log(process.memoryUsage())
// { rss: 30MB, heapTotal: 10MB, heapUsed: 5MB, external: 1MB }

// 运行时间
console.log(process.uptime())     // 进程运行了多少秒
```

### 命令行参数

```javascript
// 运行: node app.js --port=3000 --env=production
console.log(process.argv)
// [
//   'node.exe 路径',
//   'app.js 路径',
//   '--port=3000',
//   '--env=production'
// ]

// 推荐使用 yargs 或 commander 解析参数
```

### 工作目录

```javascript
console.log(process.cwd())    // 当前工作目录
process.chdir('/tmp')         // 切换工作目录
```

## [初级] 环境变量

环境变量用于配置应用在不同环境下的行为。

### 读取环境变量

```javascript
// 设置（在命令行中）:
//   Windows: set NODE_ENV=production
//   Linux/Mac: export NODE_ENV=production

// 读取
console.log(process.env.NODE_ENV)         // 'production'
console.log(process.env.PORT)             // 可能未定义
console.log(process.env.HOME)             // 用户主目录
```

### 使用 .env 文件

```bash
# .env 文件（不要提交到 Git）
NODE_ENV=development
PORT=3000
DB_HOST=localhost
DB_PASSWORD=mysecret
```

```javascript
// 安装: npm install dotenv
require('dotenv').config()

console.log(process.env.DB_HOST)  // 'localhost'
```

## [初级] exit 与信号

```javascript
// 正常退出
process.exit(0)   // 0 表示成功
process.exit(1)   // 非 0 表示失败

// 监听退出事件
process.on('exit', (code) => {
    console.log(`进程退出，退出码: ${code}`)
    // 注意：exit 事件中只能执行同步操作
})

// 监听 SIGINT 信号（Ctrl+C）
process.on('SIGINT', () => {
    console.log('收到 Ctrl+C')
    process.exit(0)
})

// 优雅关闭
process.on('SIGTERM', () => {
    console.log('收到关闭信号，开始清理...')
    // 关闭数据库连接、保存状态等
    server.close(() => {
        process.exit(0)
    })
})
```

## [初级] os 模块

`os` 模块提供操作系统相关的信息。

```javascript
const os = require('os')

// 系统信息
console.log(os.hostname())      // 主机名
console.log(os.type())          // 操作系统类型: 'Windows_NT' | 'Linux' | 'Darwin'
console.log(os.release())       // 操作系统版本号
console.log(os.uptime())        // 系统运行时间（秒）

// CPU 信息
console.log(os.cpus())          // CPU 核心信息数组
console.log(os.cpus().length)   // CPU 核心数（用于 PM2 设置进程数）

// 内存信息
console.log(os.totalmem())      // 总内存（字节）
console.log(os.freemem())       // 空闲内存（字节）

// 网络信息
console.log(os.networkInterfaces())  // 网络接口信息
```

## 面试题

### Q1: `process.env` 的作用是什么？

`process.env` 是一个包含所有环境变量的对象，用于在 Node.js 应用中读取环境配置。常用于区分开发/生产环境、存储敏感信息（数据库密码、API Key 等）。

### Q2: 如何优雅地关闭 Node.js 应用？

监听 `SIGTERM` 或 `SIGINT` 信号，在回调中执行清理操作（关闭数据库连接、保存状态等），然后调用 `process.exit(0)`。不要使用 `process.exit()` 强制退出，可能导致数据丢失。
