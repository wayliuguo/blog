## @Controller('/users')

控制器负责处理传入的请求并返回响应。

> 摘自 `./code/nestjs-basics/src/users/users.controller.ts`（运行：`npm start`）

```typescript
@Controller('users')  // 路由前缀：所有路由都以 /users 开头
// …
export class UsersController {
    constructor(private readonly usersService: UsersService) {}
// …
    @Get()  // GET /users
    findAll(): User[] {
        return this.usersService.findAll()
    }

    @Get(':id')  // GET /users/1
    findOne(@Param('id', ParseIdPipe) id: number): User {
        return this.usersService.findOne(String(id))
    }
// …
    @Post()  // POST /users
    @HttpCode(201)  // 自定义状态码
    create(@Body() body: CreateUserDto): User {
        return this.usersService.create(body)
    }

    @Put(':id')  // PUT /users/1
    update(@Param('id') id: string, @Body() body: UpdateUserDto): User {
        return this.usersService.update(id, body)
    }

    @Delete(':id')  // DELETE /users/1
    remove(@Param('id') id: string): void {
        this.usersService.remove(id)
    }
// …
}
```

实测输出（`npm start` 后 `curl -H "Authorization: Bearer demo-token" http://localhost:3000/users`）：

```
{"code":0,"data":[{"id":1,"name":"张三","age":28,"email":"zhangsan@test.com","createdAt":"2024-01-01T00:00:00.000Z","balance":100},{"id":2,"name":"李四","age":32,"email":"lisi@test.com","createdAt":"2024-01-02T00:00:00.000Z","balance":200}],"message":"success"}
```

## 参数装饰器

> 摘自 `./code/nestjs-basics/src/users/users.controller.ts`（运行：`npm start`）

```typescript
    @Get(':id/detail')
    detail(
        @Param('id') id: string,                 // 路由参数 /users/1 → id = "1"
        @Query('page') page: number,             // 查询参数 ?page=1 → page = 1
        @Headers('authorization') auth: string,  // 请求头
        @Ip() ip: string                        // 请求 IP
    ): object {
        return { id, page, auth, ip }
    }
// …
    @HttpCode(201)  // 自定义状态码
    create(@Body() body: CreateUserDto): User {
```

实测输出（`curl -H "Authorization: Bearer demo-token" "http://localhost:3000/users/1/detail?page=2"`，四个装饰器取到的值都在响应里；`@Body()` 取请求体的例子见上面 `create`）：

```
{"code":0,"data":{"id":"1","page":2,"auth":"Bearer demo-token","ip":"::ffff:127.0.0.1"},"message":"success"}
```

### 参数装饰器大全

| 装饰器 | 说明 | 示例 |
|--------|------|------|
| `@Param()` | 路由参数 | `/users/:id` |
| `@Query()` | 查询参数 | `?page=1&size=10` |
| `@Body()` | 请求体 | POST/PUT 的 JSON |
| `@Headers()` | 请求头 | `Authorization` |
| `@Ip()` | 请求 IP | |
| `@Req()` | 原始 Request 对象 | Express 的 req 对象 |

## 响应处理

NestJS 会自动将返回值序列化为 JSON：

> 摘自 `./code/nestjs-basics/src/users/users.controller.ts`（运行：`npm start`）

```typescript
    @Get()  // GET /users
    findAll(): User[] {
        return this.usersService.findAll()
    }
// …
    @Post()  // POST /users
    @HttpCode(201)  // 自定义状态码
    create(@Body() body: CreateUserDto): User {
        return this.usersService.create(body)
    }
// …
    @Get('legacy')  // 老路径重定向到新路径，注意要写在 @Get(':id') 之前
    @Redirect('/users', 301)
    legacy(): void {}
```

实测输出（`npm start` 后：`POST /users` 返回 201，`GET /users/legacy` 返回 301）：

```
{"code":0,"data":{"id":1789625733409,"name":"王五","age":30,"email":"ww@test.com","createdAt":"2026-09-17T06:15:33.409Z","balance":0},"message":"success"}

Moved Permanently. Redirecting to /users
```

## RESTful 设计规范

### HTTP 方法与资源操作

| HTTP 方法 | 操作 | 示例 | 说明 |
|-----------|------|------|------|
| GET | 查询 | `GET /users` | 获取列表 |
| GET | 查询 | `GET /users/1` | 获取单个 |
| POST | 创建 | `POST /users` | 创建资源 |
| PUT | 全量更新 | `PUT /users/1` | 替换整个资源 |
| PATCH | 部分更新 | `PATCH /users/1` | 更新部分字段 |
| DELETE | 删除 | `DELETE /users/1` | 删除资源 |

### 资源命名最佳实践

```
✅ 好的设计
GET    /users              # 获取用户列表
GET    /users/1            # 获取用户 1
GET    /users/1/orders     # 获取用户 1 的订单
POST   /users              # 创建用户
PATCH  /users/1            # 更新用户 1 的部分信息
DELETE /users/1            # 删除用户 1

❌ 不好的设计
GET    /getUsers           # 动词操作
GET    /userList           # 不一致的命名
POST   /getUserById        # 用 POST 做查询
DELETE /deleteUser?id=1    # 查询参数传 ID
```

## 小结

- **@Controller 与路由前缀**：`@Controller('users')` 后该控制器所有路由以 `/users` 开头；`@Get()`/`@Post()`/`@Put(':id')`/`@Delete(':id')` 分别对应查/建/改/删
- **参数装饰器**：`@Param` 取路由参数（`:id`）、`@Query` 取查询串（`?page=1`）、`@Body` 取请求体、`@Headers` 取请求头、`@Ip` 取请求 IP、`@Req` 拿原始 Request 对象
- **响应处理**：返回值自动序列化成 JSON（默认 200，不用手写响应）；`@HttpCode(201)` 自定义状态码、`@Redirect('/users', 301)` 做重定向
- **RESTful 规范**
  - 方法语义：GET 查询、POST 创建、PUT 全量替换、PATCH 部分更新、DELETE 删除
  - 命名反例：动词式路径 `/getUsers`、命名不一致 `/userList`、用 POST 做查询、把 ID 塞进查询参数
