# 快速上手

> NestJS 是 Node.js 的企业级框架，内置 TypeScript 支持，遵循 MVC 架构。

---

## [初级] NestJS 是什么

NestJS 是一个用于构建高效、可扩展的 Node.js 服务端应用的框架。

核心特点：

- **内置 TypeScript**：类型安全，开发体验好
- **借鉴 Angular 架构**：模块化、依赖注入、装饰器
- **底层可切换**：默认 Express，可切换为 Fastify
- **开箱即用**：内置验证、序列化、ORM 集成等

## [初级] 项目初始化

### 安装 CLI

```bash
npm install -g @nestjs/cli
```

### 创建项目

```bash
nest new my-project
```

### 项目目录结构

```
my-project/
├── src/
│   ├── app.controller.ts      # 控制器（处理请求）
│   ├── app.controller.spec.ts # 测试文件
│   ├── app.module.ts          # 根模块（组织代码）
│   ├── app.service.ts         # 服务（业务逻辑）
│   └── main.ts                # 入口文件
├── test/                      # E2E 测试
├── package.json
├── tsconfig.json
└── nest-cli.json
```

### 启动项目

```bash
npm run start       # 开发模式
npm run start:dev   # 开发模式（热重载）
```

访问 `http://localhost:3000`，你会看到 `Hello World!`。

## [初级] 第一个 Controller

```typescript
// app.controller.ts
import { Controller, Get } from '@nestjs/common'

@Controller('users')  // 路由前缀 /users
export class UserController {
    @Get()             // GET /users
    findAll(): string {
        return '所有用户'
    }

    @Get(':id')        // GET /users/1
    findOne(@Param('id') id: string): string {
        return `用户 ${id}`
    }
}
```

## [初级] CLI 常用命令

```bash
# 生成模块（含 Controller、Service 等）
nest g resource users

# 生成模块
nest g module users

# 生成控制器
nest g controller users

# 生成服务
nest g service users

# 生成类
nest g class users/helpers/validation
```

### nest g resource 生成的完整结构

```bash
nest g resource users
# 选择 REST API → 生成代码

# 生成后：
src/
├── users/
│   ├── dto/              # 数据传输对象
│   │   ├── create-user.dto.ts
│   │   └── update-user.dto.ts
│   ├── entities/         # 实体
│   │   └── user.entity.ts
│   ├── users.controller.ts
│   ├── users.controller.spec.ts
│   ├── users.module.ts
│   ├── users.service.ts
│   └── users.service.spec.ts
```
