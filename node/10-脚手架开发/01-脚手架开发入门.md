## 什么是脚手架

脚手架（Scaffold）是用于自动化项目创建的工具。用户通过命令行交互，选择配置后自动生成项目模板。

**常见例子**：
- `create-react-app` → React 项目
- `nest new` → NestJS 项目
- `vue create` → Vue 项目

## 核心流程

```
1. 用户输入命令
2. 交互式问答（项目名称、模板类型等）
3. 根据用户选择复制模板文件
4. 替换模板中的变量
5. 输出生成的项目
```

## 实战：创建一个简易脚手架

### 项目结构

```
my-cli/
├── package.json
├── bin/
│   └── index.js          # 入口文件
├── templates/
│   ├── basic/            # 基础模板
│   │   ├── package.json
│   │   └── index.js
│   └── api/              # API 模板
│       ├── package.json
│       ├── index.js
│       └── routes.js
└── index.js
```

### 入口文件

```javascript
#!/usr/bin/env node
// bin/index.js

const fs = require('fs-extra')
const path = require('path')
const inquirer = require('inquirer')

async function main() {
    // 1. 交互式问答
    const answers = await inquirer.prompt([
        {
            type: 'input',
            name: 'projectName',
            message: '项目名称:',
            default: 'my-app'
        },
        {
            type: 'list',
            name: 'template',
            message: '选择模板:',
            choices: ['basic', 'api']
        }
    ])

    const targetDir = path.join(process.cwd(), answers.projectName)

    // 2. 复制模板
    const templateDir = path.join(__dirname, '../templates', answers.template)
    await fs.copy(templateDir, targetDir)

    // 3. 替换模板变量（使用 ejs 或手动替换）
    const packageJson = await fs.readFile(
        path.join(targetDir, 'package.json'),
        'utf8'
    )
    const result = packageJson.replace(/{{projectName}}/g, answers.projectName)
    await fs.writeFile(path.join(targetDir, 'package.json'), result)

    console.log(`项目 ${answers.projectName} 创建成功！`)
    console.log(`cd ${answers.projectName} && npm install`)
}

main().catch(console.error)
```

### package.json

```json
{
    "name": "my-cli",
    "version": "1.0.0",
    "bin": {
        "create-my-app": "./bin/index.js"
    },
    "dependencies": {
        "inquirer": "^8.0.0",
        "fs-extra": "^10.0.0"
    }
}
```

## yargs 的基本使用

yargs 是 Node.js 最流行的命令行参数解析库。

```javascript
#!/usr/bin/env node
const yargs = require('yargs/yargs')
const { hideBin } = require('yargs/helpers')

yargs(hideBin(process.argv))
    .command(
        'create <name>',
        '创建新项目',
        (yargs) => {
            yargs.positional('name', {
                describe: '项目名称',
                type: 'string'
            })
            .option('template', {
                alias: 't',
                describe: '模板类型',
                choices: ['basic', 'api'],
                default: 'basic'
            })
        },
        (argv) => {
            console.log(`创建项目: ${argv.name}, 模板: ${argv.template}`)
        }
    )
    .option('verbose', {
        alias: 'v',
        type: 'boolean',
        description: '输出详细信息'
    })
    .help()
    .argv

// 使用
// my-cli create my-app
// my-cli create my-app --template api
// my-cli --help
```
