# 配套代码索引

这个体系里所有可运行的示例代码，都放在仓库的 `code/node/` 目录下。本页是「章节 ↔ 代码」的双向索引：想跑代码时按项目找，想深挖某篇文档时按章节找。

> 每个项目都可以独立运行。通用步骤是 `cd code/node/<项目名>` → 读该项目的 `README.md` → `npm install` → 按 `package.json` 里的 scripts 逐个执行。

## 四、怎么跑

以 `node-basics` 为例：

```bash
cd code/node/node-basics
npm install          # 这个项目零依赖，此步可跳过
node src/04-eventloop-order.js
```

以 `mysql-demo` 为例（需要本地 MySQL 8.0+）：

```bash
cd code/node/mysql-demo
mysql -u root -p < sql/01-schema.sql
mysql -u root -p mysql_demo < sql/02-seed.sql
cp .env.example .env      # 改成你自己的连接信息
npm install
npm run index             # 跑索引对比实验
```

每个项目的 `README.md` 里都有完整的「脚本清单表」，写明了**每个脚本演示什么、跑完你该观察到什么**。
