# 学习路径图

> 从零开始的后端学习路线，预计 9 周达到初中级水平。

---

## 总览

```
第1周：认识后端 + Node.js 基础
	    ↓
	第2周：Express 与 Koa（轻量框架入门）
	    ↓
	第3-4周：MySQL + MongoDB（数据库）
	    ↓
	第5周：Redis（缓存系统）
	    ↓
	第6周：NestJS 入门（核心概念）
	    ↓
	第7周：NestJS 进阶（实战能力）
	    ↓
	第8周：部署与工程化 + 脚手架
	    ↓
	第9周：查漏补缺 + 面试准备
```

---

## 第 1 周：认识后端 + Node.js 基础

### 学习目标

- 理解后端在全栈中的位置
- 掌握 Node.js 基础语法和模块系统
- 理解异步编程和事件循环

### 学习内容

| 文件 | 预估时间 | 必须掌握 |
|------|---------|---------|
| 后端在做什么 | 30 分钟 | 请求链路、前后端分工 |
| Node.js 是什么 | 30 分钟 | 安装、第一个程序 |
| 模块系统与包管理 | 1 小时 | CommonJS、npm 命令 |
| 异步编程入门 | 1.5 小时 | Promise、async/await |
| 事件循环与错误处理 | 1 小时 | 宏任务/微任务、try/catch |

### 动手实践

- 安装 Node.js，运行第一个程序
- 使用 npm 安装一个包（如 lodash）
- 用 fs 模块读取文件（同步和异步）

---

## 第 2 周：Express 与 Koa

### 学习目标

- 能搭建简单的 Web 服务器
- 理解中间件机制

### 学习内容

| 文件 | 预估时间 | 必须掌握 |
|------|---------|---------|
| Express 快速入门 | 1.5 小时 | 路由、中间件 |
| Koa 快速入门 | 1 小时 | 洋葱模型、与 Express 对比 |
| Express 项目模板 | 1.5 小时 | 项目结构、数据库集成、Redis、JWT |
	| Express 源码分析 | 1.5 小时 | 最小实现 Express、路由匹配、中间件链 |
	| Koa 项目模板 | 1.5 小时 | 项目结构、数据库集成、Redis、JWT |
	| Koa 源码分析 | 1.5 小时 | 最小实现 Koa、compose、洋葱模型 |

### 动手实践

- 用 Express 搭建一个简单的 CRUD API
- 实现一个日志中间件
- 对比 Koa 的洋葱模型
- 参考模板搭建完整项目结构
- 动手运行最小实现代码，理解框架原理

## 第 3-4 周：数据库

### 学习目标

- 掌握 SQL 基础和表设计
- 理解索引、事务、锁等核心概念，能排查慢查询
- 掌握主从复制、分库分表、数据库迁移等生产技能
- 能使用 TypeORM 操作数据库
- 了解 MongoDB 的适用场景，掌握日志系统和评论系统设计
- 深入理解 Redis 缓存策略和分布式锁等生产场景

### 学习内容

| 文件 | 预估时间 | 必须掌握 |
|------|---------|---------|
| MySQL 基础 | 2 小时 | SQL 基础、表设计、JOIN |
| MySQL 进阶 | 3 小时 | 索引、执行顺序、GROUP BY、子查询、锁与死锁、慢查询排查 |
| MySQL 高级实战 | 3 小时 | 主从复制、分库分表、Online DDL、连接池调优、备份恢复 |
| Node.js 操作 MySQL | 2 小时 | TypeORM 基础 |
| MongoDB 入门 | 1.5 小时 | CRUD、Mongoose、文档关系设计、日志系统、评论系统、TTL 索引 |
| MongoDB 进阶 | 1.5 小时 | 索引优化、聚合管道、事务、副本集与选举、分片集群、读写分离、慢查询排查 |

### 动手实践

- 设计一个完整的用户-订单-商品表结构
- 写 SQL 实现按月统计销售额（GROUP BY + 聚合函数）
- 用 EXPLAIN 分析一条慢查询并优化
- 配置主从复制，测试读写分离
- 在 NestJS 中集成 TypeORM
- 使用 MongoDB 设计日志系统（TTL 索引自动过期）
- 使用 MongoDB 设计评论/回复系统（嵌入式文档）

---

## 第 5 周：Redis

### 学习目标

- 掌握 Redis 5 种核心数据类型及使用场景
- 理解持久化、过期策略和内存淘汰机制
- 能在 Node.js/NestJS 中集成 Redis
- 掌握缓存实战和分布式锁方案

### 学习内容

| 文件 | 预估时间 | 必须掌握 |
|------|---------|---------|
| Redis 基础与数据类型 | 1.5 小时 | 5 种数据类型、应用场景 |
| Redis 持久化与淘汰策略 | 1.5 小时 | RDB/AOF、过期策略、内存淘汰 |
| Node.js 操作 Redis | 1.5 小时 | ioredis、NestJS 封装、Pipeline |
| Redis 缓存实战 | 2 小时 | 缓存三大问题、分布式锁、限流、缓存预热、全局 ID 生成器 |
| Redis 进阶 | 1.5 小时 | 主从复制、哨兵、Cluster 集群、高级数据类型、慢查询、多线程 IO、监控告警 |

### 动手实践

- 用 redis-cli 操作所有数据类型
- 在 NestJS 中封装 Redis 模块
- 实现缓存穿透防护和分布式锁
- 实现缓存预热机制（应用启动时加载热点数据）
- 实现全局 ID 生成器（基于 Redis INCR）
- 排查 Big Key 和慢查询

## 第 6 周：NestJS 入门

### 学习目标

- 能创建 NestJS 项目
- 理解 IOC 和 DI 容器
- 掌握请求处理链的各个组件（三种中间件方式、Guard、Pipe、Interceptor、Filter）

### 学习内容

| 文件 | 预估时间 | 必须掌握 |
|------|---------|---------|
| 快速上手 | 1 小时 | 项目创建、CLI 命令 |
| IOC 与依赖注入 | 1.5 小时 | DI 原理、@Injectable |
| 模块与提供器 | 1 小时 | @Module、动态模块 |
| 控制器与路由 | 1 小时 | 参数装饰器、RESTful |
| 请求处理链 | 2 小时 | 中间件/Guard/Pipe/Interceptor/Filter 全流程、@UseXxx、全局绑定、DTO 校验、自定义管道、统一响应格式、内置 HTTP 异常、三种中间件方式 |
| 数据库集成 | 1 小时 | TypeORM 集成 |

### 动手实践

- 创建一个 CRUD 的用户模块
- 实现一个 AuthGuard
- 使用 ValidationPipe 校验请求参数

- 使用 Bull 处理异步邮件任务

## 第 8 周：部署与工程化 + 脚手架

### 学习目标

- 能管理多环境配置并搭建日志体系
- 能用 Docker + Compose 容器化部署应用
- 理解 PM2 进程管理与 Docker 的分工
- 掌握 Nginx 反向代理与统一入口架构
- 理解数据库迁移与发布链路（迁移 Job 分离）
- 能完成一次完整的生产部署并排障
- 了解 CI/CD 自动化部署流程
- 了解脚手架开发流程

### 学习内容

| 文件 | 预估时间 | 必须掌握 |
|------|---------|---------|
| 环境管理与配置 | 1 小时 | ConfigModule、多环境、类型安全 |
| 日志体系 | 1 小时 | Winston、双写架构、日志查看 |
| PM2 进程管理 | 1 小时 | 常用命令、fork vs cluster |
| Docker 容器化 | 2 小时 | 多阶段构建、生产级 Dockerfile |
| Docker Compose 编排 | 1.5 小时 | 堆栈分离、启动顺序 |
| Nginx 反向代理与网关 | 1.5 小时 | 反向代理、负载均衡、WebSocket |
| 数据库迁移与发布 | 1.5 小时 | migrations 机制、迁移 Job 分离 |
| 生产部署实战 | 2 小时 | 首次部署、迭代、备份、排障 |
| CI/CD 自动化部署 | 1.5 小时 | GitHub Actions、镜像推送、自动部署 |
| 脚手架开发（可选） | 1 小时 | 了解即可 |

### 动手实践

- 搭建多环境配置系统（.env.development / .env.production）
- 配置 Winston 双写日志与按日轮转
- 编写生产级多阶段 Dockerfile 并用 Compose 编排全栈
- 使用 PM2 部署 Node.js 应用，区分 fork / cluster 场景
- 配置 Nginx 反向代理与负载均衡
- 用迁移 Job + 业务容器完成一次带迁移的生产部署
- 推送 tag 触发 CI/CD 自动部署

### 第 8 周主线

```
本地工程化（配置+日志）→ 单机部署（PM2）→ 容器化（Docker+Compose）
→ 生产发布（迁移+部署实战）→ 网关（Nginx）→ 自动化（CI/CD）
```

## 学习建议

1. **不要跳过基础**：直接学 NestJS 而不懂异步编程，后面会很难
2. **动手写代码**：每个阶段看完后，一定要动手写示例
3. **先掌握再深入**：初级内容必须全部掌握，高级内容可后续学习
4. **遇到不会的先放过**：不要在一个问题上卡太久，继续往下走，回头再看
