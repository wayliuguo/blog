# 学习路径图

> 从零开始的后端学习路线，预计 10 周达到初中级水平。

---

## 总览

```
第1周：运行环境（Node.js 怎么跑）        ─ 模块一 · 运行环境
         ↓
第2周：网络底层（请求怎么进来）          ─ 模块二 · 网络底层
         ↓
第3周：Express 与 Koa                    ─ 模块三 · Web 框架基础
         ↓
第4-5周：MySQL + MongoDB + PostgreSQL    ┐
                                         ├ 模块四 · 数据与缓存
第6周：Redis                             ┘
         ↓
第7周：NestJS 入门                       ┐
                                         ├ 模块五 · 后端架构
第8周：NestJS 进阶                       ┘
         ↓
第9周：部署与工程化 + 脚手架              ─ 模块六 · 工程化与拓展
         ↓
第10周：查漏补缺 + 面试准备               ─ 附录
```

> 顺序依据的是依赖关系：先懂运行环境，再懂网络；先懂网络，才看得清框架封了什么；框架原理通了，数据层才有落点；架构跑通之后，才谈工程化。

## 第 1 周：运行环境

> 对应 **模块一 · 运行环境**。前置依赖：无。
> 这一模块是一条有顺序的链：模块系统 → 事件循环 → 异步与事件驱动 → Buffer/Stream → 进程线程 → 错误兜底与优雅退出 → 收束。不要跳着读，尤其不要跳过事件循环。

### 学习目标

- 理解后端在全栈中的位置
- 能用一组真实耗时数字解释 Node.js 为什么适合 I/O 密集型场景
- 掌握 Node.js 基础语法和模块系统
- 理解异步编程和事件循环（这是后面一切的地基）
- 能针对一个性能问题说出该用哪种并发方式

### 学习内容

| 文件 | 预估时间 | 必须掌握 |
|------|---------|---------|
| Node.js 是什么 | 1 小时 | 请求链路、一笔真实的耗时账、I/O 密集型论证（本模块的锚） |
| 模块系统与包管理 | 1 小时 | CommonJS、ESM、npm 命令、锁文件 |
| 事件循环 | 1.5 小时 | libuv 六阶段、宏任务/微任务、微任务检查点、nextTick 饿死、内核多路复用 |
| 异步编程与事件驱动 | 1.5 小时 | Promise、async/await、Promise.all、EventEmitter |
| 内置模块与文件操作 | 1 小时 | fs、Buffer、Stream 四种类型、背压、pipe |
| 进程线程与优雅退出 | 1 小时 | process、child_process、cluster、worker_threads、错误兜底、优雅关闭 |
| 运行机制收束 | 30 分钟 | 知识关系总图、抽象栈、"见 X 想 Y"决策表、误区清单、自测 6 问 |

### 动手实践

- 安装 Node.js，运行第一个程序
- 使用 npm 安装一个包（如 lodash）
- 用 fs 模块读取文件（同步、异步、流三种方式各写一遍）
- 写一个 `setTimeout` + `Promise.then` 混合的输出题，验证微任务检查点

## 第 2 周：网络底层

> 对应 **模块二 · 网络底层**。前置依赖：第 1 周的 Buffer / Stream / 事件循环。
> 这一周最容易被跳过，但它决定了后面读框架源码时是"看懂"还是"背下来"。

### 学习目标

- 说清一次请求从浏览器到 Node 的完整链路
- 理解 TCP 是字节流而非消息协议、粘包/拆包怎么来的
- 理解 req/res 为什么是可读/可写流
- 能区分 WebSocket 与 SSE，并知道各自适用场景

### 学习内容

| 文件 | 预估时间 | 必须掌握 |
|------|---------|---------|
| 导读与全景图 | 30 分钟 | 网络层为什么排在这里、一次请求的完整路径、每层故障现象 |
| TCP 与 Socket 编程 | 2 小时 | TCP/IP 分层、三次握手、粘包/拆包、node:net、Socket 即 Duplex Stream |
| HTTP 与 HTTPS 深入 | 2 小时 | node:http 手写 Server、Keep-Alive、TLS、HTTP/2 |
| WebSocket 与 SSE 实时通信 | 1.5 小时 | 握手与心跳、SSE 单向推送、两者选型 |
| 一次请求完整经历了什么 | 1 小时 | 31 步链路、NestJS 封装了什么、线上排障思路 |

### 动手实践

- 用 `node:net` 写一个 TCP Server/Client，观察粘包现象
- 用 `node:http` 手写一个带路由的最小 HTTP Server
- 用 SSE 实现一个服务端定时推送的接口

| Koa 项目模板 | 1.5 小时 | 项目结构、数据库集成、Redis、JWT |

### 动手实践

- 实现一个日志中间件

## 第 4-5 周：数据库

> 对应 **模块四 · 数据与缓存** 前半部分。前置依赖：第 3 周（项目模板已用到 TypeORM，这里把原理讲透）。

### 学习目标

- 掌握 SQL 基础和表设计
- 理解索引、事务、锁等核心概念，能排查慢查询
- 看到一条 SQL 能判断它走没走索引、要不要回表
- 掌握主从复制、分库分表、数据库迁移等生产技能
- 能使用 TypeORM 操作数据库
- 了解 MongoDB 的适用场景，掌握日志系统和评论系统设计
- 理解 PostgreSQL 的差异化能力与 pgvector 向量检索

### 学习内容

| 文件 | 预估时间 | 必须掌握 |
|------|---------|---------|
| MySQL 基础 | 2 小时 | SQL 基础、表设计、JOIN |
| MySQL 进阶 | 3 小时 | 索引原理、执行顺序、锁与死锁、慢查询排查、防超卖 |
| MySQL 高级实战 | 3 小时 | 主从复制、分库分表、Online DDL、连接池调优、备份恢复 |
| Node.js 操作 MySQL | 2 小时 | mysql2 连接池、TypeORM、N+1、事务 |
| MongoDB 入门 | 1.5 小时 | CRUD、Mongoose、文档关系设计、日志系统、评论系统、TTL 索引 |
| MongoDB 进阶 | 1.5 小时 | 索引优化、聚合管道、事务、副本集与选举、分片集群、读写分离 |
| PostgreSQL 与 pgvector | 2 小时 | JSONB、窗口函数/CTE、GIN 索引、MVCC 与 VACUUM、pgvector 向量检索 |

### 动手实践

- 设计一个完整的用户-订单-商品表结构
- 写 SQL 实现按月统计销售额（GROUP BY + 聚合函数）
- 用 EXPLAIN 分析一条慢查询并优化
- 实现"先 SELECT 再 UPDATE"与 "UPDATE ... WHERE balance >= 1" 两种扣减，对比并发结果
- 配置主从复制，测试读写分离
- 在 NestJS 中集成 TypeORM
- 使用 MongoDB 设计日志系统（TTL 索引自动过期）与评论/回复系统（嵌入式文档）
- 在 PostgreSQL 中建一张带 `vector(1536)` 的表并跑通相似度查询

## 学习建议

1. **不要跳过基础**：直接学 NestJS 而不懂异步编程与网络，后面会很难
2. **动手写代码**：每个模块看完后，一定要动手写示例
3. **先掌握再深入**：正文是一条平的链，按顺序走即可；难度分层只体现在附录的面试题库（初级 / 中级 / 高级三册）
4. **遇到不会的先放过**：不要在一个问题上卡太久，继续往下走，回头再看
