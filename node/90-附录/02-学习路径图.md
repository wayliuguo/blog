# 学习路径图

> 从零开始的后端学习路线，预计 9 周达到初中级水平。

---

## 总览

```
第1周：认识后端 + Node.js 基础
	    ↓
	第2周：Express 与 Koa（轻量框架入门）
	    ↓
	第3-4周：MySQL + MongoDB（数据库）
	    ↓
	第5周：Redis（缓存系统）
	    ↓
	第6周：NestJS 入门（核心概念）
	    ↓
	第7周：NestJS 进阶（实战能力）
	    ↓
	第8周：部署与工程化 + 脚手架
	    ↓
	第9周：查漏补缺 + 面试准备
```

---

## 第 1 周：认识后端 + Node.js 基础

### 学习目标

- 理解后端在全栈中的位置
- 掌握 Node.js 基础语法和模块系统
- 理解异步编程和事件循环

### 学习内容

| 文件 | 预估时间 | 必须掌握 |
|------|---------|---------|
| 后端在做什么 | 30 分钟 | 请求链路、前后端分工 |
| Node.js 是什么 | 30 分钟 | 安装、第一个程序 |
| 模块系统与包管理 | 1 小时 | CommonJS、npm 命令 |
| 异步编程入门 | 1.5 小时 | Promise、async/await |
| 事件循环与错误处理 | 1 小时 | 宏任务/微任务、try/catch |

### 动手实践

- 安装 Node.js，运行第一个程序
- 使用 npm 安装一个包（如 lodash）
- 用 fs 模块读取文件（同步和异步）

---

## 第 2 周：Express 与 Koa

### 学习目标

- 能搭建简单的 Web 服务器
- 理解中间件机制

### 学习内容

| 文件 | 预估时间 | 必须掌握 |
|------|---------|---------|
| Express 快速入门 | 1.5 小时 | 路由、中间件 |
| Koa 快速入门 | 1 小时 | 洋葱模型、与 Express 对比 |
| Express 项目模板 | 1.5 小时 | 项目结构、数据库集成、Redis、JWT |
	| Express 源码分析 | 1.5 小时 | 最小实现 Express、路由匹配、中间件链 |
	| Koa 项目模板 | 1.5 小时 | 项目结构、数据库集成、Redis、JWT |
	| Koa 源码分析 | 1.5 小时 | 最小实现 Koa、compose、洋葱模型 |

### 动手实践

- 用 Express 搭建一个简单的 CRUD API
- 实现一个日志中间件
- 对比 Koa 的洋葱模型
- 参考模板搭建完整项目结构
- 动手运行最小实现代码，理解框架原理

## 第 3-4 周：数据库

### 学习目标

- 掌握 SQL 基础
- 理解索引、事务等核心概念
- 能使用 TypeORM 操作数据库
- 了解 MongoDB 的适用场景

### 学习内容

| 文件 | 预估时间 | 必须掌握 |
|------|---------|---------|
| MySQL 基础 | 2 小时 | SQL 基础、表设计、JOIN |
| MySQL 进阶 | 2 小时 | 索引、事务、隔离级别 |
| Node.js 操作 MySQL | 2 小时 | TypeORM 基础 |
| MongoDB 入门 | 1.5 小时 | CRUD、Mongoose |
| MongoDB 进阶 | 1.5 小时 | 索引、聚合管道 |

### 动手实践

- 设计一个简单的用户-订单表结构
- 写 SQL 查询多表关联数据

---

## 第 5 周：Redis

### 学习目标

- 掌握 Redis 5 种核心数据类型及使用场景
- 理解持久化、过期策略和内存淘汰机制
- 能在 Node.js/NestJS 中集成 Redis
- 掌握缓存实战和分布式锁方案

### 学习内容

| 文件 | 预估时间 | 必须掌握 |
|------|---------|---------|
| Redis 基础与数据类型 | 1.5 小时 | 5 种数据类型、应用场景 |
| Redis 持久化与淘汰策略 | 1.5 小时 | RDB/AOF、过期策略、内存淘汰 |
| Node.js 操作 Redis | 1.5 小时 | ioredis、NestJS 封装、Pipeline |
| Redis 缓存实战 | 2 小时 | 缓存穿透/击穿/雪崩、分布式锁 |
| Redis 进阶 | 1.5 小时 | 主从复制、哨兵、Cluster、高级类型 |

### 动手实践

- 用 redis-cli 操作所有数据类型
- 在 NestJS 中封装 Redis 模块
- 实现缓存穿透防护和分布式锁

## 学习建议

1. **不要跳过基础**：直接学 NestJS 而不懂异步编程，后面会很难
2. **动手写代码**：每个阶段看完后，一定要动手写示例
3. **先掌握再深入**：初级内容必须全部掌握，高级内容可后续学习
4. **遇到不会的先放过**：不要在一个问题上卡太久，继续往下走，回头再看
