## @Controller('/users')

控制器负责处理传入的请求并返回响应。

```typescript
@Controller('users')  // 路由前缀：所有路由都以 /users 开头
export class UserController {
    @Get()           // GET /users
    findAll() {}

    @Get(':id')      // GET /users/1
    findOne(@Param('id') id: string) {}

    @Post()          // POST /users
    create(@Body() body: CreateUserDto) {}

    @Put(':id')      // PUT /users/1
    update(@Param('id') id: string, @Body() body: UpdateUserDto) {}

    @Delete(':id')   // DELETE /users/1
    remove(@Param('id') id: string) {}
}
```

## 参数装饰器

```typescript
@Get(':id')
findOne(
    @Param('id') id: string,      // 路由参数 /users/123 → id = "123"
    @Query('page') page: number,  // 查询参数 /users?page=1 → page = 1
    @Body() body: any,            // 请求体 POST 请求的 JSON
    @Headers('authorization') auth: string, // 请求头
    @Ip() ip: string,             // 请求 IP
) {}
```

### 参数装饰器大全

| 装饰器 | 说明 | 示例 |
|--------|------|------|
| `@Param()` | 路由参数 | `/users/:id` |
| `@Query()` | 查询参数 | `?page=1&size=10` |
| `@Body()` | 请求体 | POST/PUT 的 JSON |
| `@Headers()` | 请求头 | `Authorization` |
| `@Ip()` | 请求 IP | |
| `@Req()` | 原始 Request 对象 | Express 的 req 对象 |

## 响应处理

NestJS 会自动将返回值序列化为 JSON：

```typescript
@Get()
findAll(): User[] {
    return this.userService.findAll()
    // 自动返回 JSON: [{ id: 1, name: "张三" }, ...]
    // 状态码自动为 200
}

@Post()
@HttpCode(201)  // 自定义状态码
create(@Body() body: CreateUserDto) {
    return this.userService.create(body)
}

@Redirect('/users', 301)  // 重定向
redirect() {}
```

## RESTful 设计规范

### HTTP 方法与资源操作

| HTTP 方法 | 操作 | 示例 | 说明 |
|-----------|------|------|------|
| GET | 查询 | `GET /users` | 获取列表 |
| GET | 查询 | `GET /users/1` | 获取单个 |
| POST | 创建 | `POST /users` | 创建资源 |
| PUT | 全量更新 | `PUT /users/1` | 替换整个资源 |
| PATCH | 部分更新 | `PATCH /users/1` | 更新部分字段 |
| DELETE | 删除 | `DELETE /users/1` | 删除资源 |

### 资源命名最佳实践

```
✅ 好的设计
GET    /users              # 获取用户列表
GET    /users/1            # 获取用户 1
GET    /users/1/orders     # 获取用户 1 的订单
POST   /users              # 创建用户
PATCH  /users/1            # 更新用户 1 的部分信息
DELETE /users/1            # 删除用户 1

❌ 不好的设计
GET    /getUsers           # 动词操作
GET    /userList           # 不一致的命名
POST   /getUserById        # 用 POST 做查询
DELETE /deleteUser?id=1    # 查询参数传 ID
```
