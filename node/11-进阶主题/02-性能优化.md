## 缓存策略

| 问题 | 现象 | 解决方案 |
|------|------|---------|
| 缓存穿透 | 查询不存在的数据，每次都穿透到数据库 | 缓存空值、布隆过滤器 |
| 缓存击穿 | 热点 key 过期瞬间，大量请求打到数据库 | 互斥锁、热点数据永不过期 |
| 缓存雪崩 | 大量 key 同时过期，数据库压力暴增 | 过期时间加随机值、多级缓存 |

## 并发限流

### 限流算法

| 算法 | 说明 | 特点 |
|------|------|------|
| 计数器 | 固定时间窗口内计数 | 实现简单，有突刺问题 |
| 滑动窗口 | 细粒度时间窗口 | 解决突刺，更平滑 |
| 令牌桶 | 匀速放入令牌，请求消耗令牌 | 允许突发流量 |
| 漏桶 | 匀速处理请求 | 平滑流量，不允许突发 |

### NestJS 限流

```bash
npm install @nestjs/throttler
```

```typescript
@Module({
    imports: [
        ThrottlerModule.forRoot({
            ttl: 60000,     // 时间窗口（60秒）
            limit: 10,      // 窗口内允许的最大请求数
        })
    ]
})
export class AppModule {}

// 使用
@Controller('users')
export class UserController {
    @Throttle(5, 60000)  // 覆盖默认：60秒内最多5次
    @Get('search')
    search(@Query('q') q: string) {}
}
```

## 数据库优化

| 优化手段 | 说明 |
|---------|------|
| 索引优化 | 合理建索引，避免全表扫描 |
| 慢查询日志 | 定位慢 SQL，用 EXPLAIN 分析 |
| 连接池 | 复用数据库连接，避免频繁创建 |
| 读写分离 | 主库写，从库读 |
| 分库分表 | 数据量大时水平拆分 |
