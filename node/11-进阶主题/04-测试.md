## 测试金字塔

```
        ⬆
    E2E 测试  ⬆ 少
  集成测试  ⬆
单元测试  ⬆ 多
```

| 测试类型 | 速度 | 数量 | 覆盖范围 |
|---------|------|------|---------|
| 单元测试 | 极快 | 最多 | 单个函数/方法 |
| 集成测试 | 快 | 中等 | 模块间交互 |
| E2E 测试 | 慢 | 最少 | 完整请求链路 |

## NestJS 测试

### 单元测试

> 示意片段（无配套脚本）
```typescript
import { Test, TestingModule } from '@nestjs/testing'

describe('UserService', () => {
    let service: UserService

    beforeEach(async () => {
        const module: TestingModule = await Test.createTestingModule({
            providers: [UserService],
        }).compile()

        service = module.get<UserService>(UserService)
    })

    it('should return user by id', async () => {
        const user = await service.findById(1)
        expect(user).toBeDefined()
        expect(user.id).toBe(1)
    })
})
```

### 集成测试

> 示意片段（无配套脚本）
```typescript
describe('UserController', () => {
    let app: INestApplication

    beforeAll(async () => {
        const moduleFixture = await Test.createTestingModule({
            imports: [AppModule],
        }).compile()

        app = moduleFixture.createNestApplication()
        await app.init()
    })

    it('/users (GET)', async () => {
        const response = await request(app.getHttpServer())
            .get('/users')
            .expect(200)

        expect(response.body).toBeInstanceOf(Array)
    })
})
```

## Mock / Stub / Spy

> 示意片段（无配套脚本）
```typescript
// Mock：模拟整个对象
const mockUserService = {
    findById: jest.fn().mockResolvedValue({ id: 1, name: '张三' })
}

// Stub：替换方法返回值
jest.spyOn(userService, 'findById').mockResolvedValue({ id: 1, name: '张三' })

// Spy：监控方法调用
const spy = jest.spyOn(userService, 'findById')
userService.findById(1)
expect(spy).toHaveBeenCalledWith(1)
```

## 小结

- **测试金字塔：按性价比分层**
  1. **单元测试**：极快、数量最多，覆盖单个函数/方法
  2. **集成测试**：速度与数量居中，覆盖模块间交互
  3. **E2E 测试**：最慢、数量最少，覆盖完整请求链路
- **NestJS 里两类测试怎么写**
  - **单元测试**：`Test.createTestingModule({ providers: [...] })` 编译后 `module.get()` 取出待测服务
  - **集成测试**：`imports: [AppModule]` 编译出完整应用，`createNestApplication()` + `app.init()` 后用 supertest 打真实 HTTP
- **三种测试替身**
  1. **Mock**：模拟整个对象，如 `jest.fn().mockResolvedValue(...)`
  2. **Stub**：替换方法返回值，如 `jest.spyOn(...).mockResolvedValue(...)`
  3. **Spy**：只监控调用情况，`jest.spyOn` 后断言 `toHaveBeenCalledWith`
