## 常见攻击类型

### XSS（跨站脚本攻击）

攻击者在网页中注入恶意脚本，当用户访问时执行。

> 示意片段（无配套脚本）
```typescript
// 防御：对用户输入进行转义
// NestJS 的模板引擎（如 Pug）默认会转义 HTML
// 前端框架（React/Vue）默认也会转义
```

### CSRF（跨站请求伪造）

攻击者诱导用户点击链接，在用户不知情的情况下执行操作。

> 示意片段（无配套脚本）
```typescript
// 防御：使用 CSRF Token
// NestJS 中可以使用 csurf 中间件
```

### SQL 注入

攻击者通过输入恶意 SQL 片段，获取或篡改数据库数据。

> 示意片段（无配套脚本）
```typescript
// 错误：字符串拼接 SQL
await pool.query(`SELECT * FROM users WHERE id = ${userId}`)

// 正确：参数化查询
await pool.query('SELECT * FROM users WHERE id = ?', [userId])
```

## Helmet

Helmet 通过设置 HTTP 头来防御常见的 Web 攻击。

```bash
npm install helmet
```

> 示意片段（无配套脚本）
```typescript
import helmet from 'helmet'

const app = await NestFactory.create(AppModule)
app.use(helmet())  // 设置多个安全相关的 HTTP 头
```

## CORS

CORS（跨域资源共享）控制哪些域名可以访问你的 API。

> 示意片段（无配套脚本）
```typescript
// 开发环境：允许所有来源
app.enableCors()

// 生产环境：只允许指定域名
app.enableCors({
    origin: ['https://example.com', 'https://admin.example.com'],
    methods: ['GET', 'POST', 'PUT', 'DELETE'],
    credentials: true,  // 允许携带 Cookie
    maxAge: 3600        // 预检请求缓存时间
})
```

## 参数校验

> 示意片段（无配套脚本）
```typescript
// 永远不要信任用户输入
// 使用 ValidationPipe 进行校验

@Post()
create(@Body(new ValidationPipe({
    whitelist: true,
    forbidNonWhitelisted: true,
})) body: CreateUserDto) {
    // 只有 DTO 中定义的字段会被接受
}
```

## 小结

- **三类常见攻击与对应防线**
  1. **XSS（跨站脚本攻击）**：往页面注入恶意脚本，靠模板引擎（Pug）与前端框架（React/Vue）默认的 HTML 转义防御
  2. **CSRF（跨站请求伪造）**：诱导用户在不知情下执行操作，靠 CSRF Token 防御，NestJS 里可用 `csurf` 中间件
  3. **SQL 注入**：字符串拼接 SQL 就是注入入口，必须用参数化查询（`?` 占位）让驱动做转义
- **框架层的三道通用防护**
  1. **Helmet**：一个 `app.use(helmet())` 批量设置安全响应头，成本极低收益高
  2. **CORS**：开发可放开（`app.enableCors()`），生产必须用 `origin` 白名单；带 Cookie 时 `credentials` 与前端 `withCredentials` 要成对配
  3. **参数校验**：永远不信任用户输入，`ValidationPipe` 开 `whitelist + forbidNonWhitelisted` 只放行 DTO 声明过的字段
