## 常见攻击类型

### XSS（跨站脚本攻击）

攻击者在网页中注入恶意脚本，当用户访问时执行。

```typescript
// 防御：对用户输入进行转义
// NestJS 的模板引擎（如 Pug）默认会转义 HTML
// 前端框架（React/Vue）默认也会转义
```

### CSRF（跨站请求伪造）

攻击者诱导用户点击链接，在用户不知情的情况下执行操作。

```typescript
// 防御：使用 CSRF Token
// NestJS 中可以使用 csurf 中间件
```

### SQL 注入

攻击者通过输入恶意 SQL 片段，获取或篡改数据库数据。

```typescript
// 错误：字符串拼接 SQL
await pool.query(`SELECT * FROM users WHERE id = ${userId}`)

// 正确：参数化查询
await pool.query('SELECT * FROM users WHERE id = ?', [userId])
```

## Helmet

Helmet 通过设置 HTTP 头来防御常见的 Web 攻击。

```bash
npm install helmet
```

```typescript
import helmet from 'helmet'

const app = await NestFactory.create(AppModule)
app.use(helmet())  // 设置多个安全相关的 HTTP 头
```

## CORS

CORS（跨域资源共享）控制哪些域名可以访问你的 API。

```typescript
// 开发环境：允许所有来源
app.enableCors()

// 生产环境：只允许指定域名
app.enableCors({
    origin: ['https://example.com', 'https://admin.example.com'],
    methods: ['GET', 'POST', 'PUT', 'DELETE'],
    credentials: true,  // 允许携带 Cookie
    maxAge: 3600        // 预检请求缓存时间
})
```

## 面试题

### Q1: 什么是 SQL 注入？如何预防？

SQL 注入是通过在用户输入中插入恶意 SQL 代码来攻击数据库。预防方法：使用参数化查询（`?` 占位符）、ORM 框架、对用户输入进行校验和转义。

### Q2: CORS 是什么？如何配置？

CORS 是浏览器的一种安全机制，限制跨域请求。服务端通过设置 `Access-Control-Allow-Origin` 等 HTTP 头来控制哪些域名可以访问。NestJS 中通过 `app.enableCors()` 配置。
