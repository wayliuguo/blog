# 后端在做什么

> 适合完全没有后端经验的同学，了解后端在全栈中的位置。

---

## [初级] 一个完整的请求链路

当你在浏览器输入 `https://example.com` 并回车，发生了什么？

```
用户输入 URL
    ↓
DNS 解析（域名 → IP 地址）
    ↓
请求到达服务器（后端）
    ↓
后端处理请求（读取数据库、计算等）
    ↓
返回响应（HTML / JSON / 图片等）
    ↓
浏览器渲染页面
```

后端就处在 **"服务器处理请求"** 这个环节。

## [初级] 前端 vs 后端的分工

| 前端 | 后端 |
|------|------|
| 页面展示、用户交互 | 数据存储与读写 |
| 按钮点击、表单输入 | 业务逻辑处理 |
| 调接口获取数据 | 提供接口（API） |
| 浏览器端运行 | 服务器端运行 |

## [初级] 后端开发的核心能力

### 1. 接收请求 → 处理逻辑 → 返回响应

```js
// 伪代码
app.get('/user/:id', async (req, res) => {
    const user = await database.findUser(req.params.id)
    res.json(user)
})
```

### 2. 数据存储与读写

- 关系型数据库（MySQL / PostgreSQL）
- 非关系型数据库（MongoDB / Redis）
- 文件存储

### 3. 用户认证与权限控制

- 登录、注册、Token 验证
- 哪些接口需要登录才能访问

## [初级] 你即将学到的技术栈

```
Node.js      → 运行环境（JavaScript 跑在服务器上）
TypeScript   → 类型安全的 JavaScript（减少 Bug）
Express/Koa  → 轻量级 Web 框架（入门用）
NestJS       → 企业级框架（生产环境用）
MySQL        → 关系型数据库（存结构化数据）
MongoDB      → 文档型数据库（存灵活数据）
Redis        → 缓存（提升性能）
Docker       → 容器化部署
```
