无障碍审查：坏例子与改对之后的对照

下面两块内容是同一组控件，一块故意写坏（#bad-zone）、一块是改对之后的版本（#good-zone）。 页面加载后自动对两块跑同一套检查，结果写在页尾探针里——两块代码的差别只有那么几行，结论差多少可以直接对比。

① 坏例子：看起来能用，无障碍树里全是空的

左边这张图没写 alt

只用 placeholder 当标签的输入框
去掉了焦点轮廓的链接 键盘 Tab 过来时看不出焦点在哪

这行字的对比度不足（灰字白底）

这级标题跳过了 h3

② 改对之后：同样的外观，多出来的只是语义

有信息的图：补上 alt
纯装饰的图：alt="" 明确表示"跳过我"（注意它与"没写 alt"完全是两件事）
直接用 button
