# 表单与标签

## `<form>` 与表单是怎么提交的

> 示意片段（无配套脚本）

```html
<form action="/login" method="post">
  <input type="text" name="username" />
  <button type="submit">登录</button>
</form>
```

| `form` 属性 | 作用 |
| ---- | ---- |
| `action` | 数据发往的地址 |
| `method` | `get`（拼到 URL，适合搜索）或 `post`（放请求体，适合提交数据） |

提交时浏览器会**收集所有带 `name` 且非 `disabled` 的控件**去发送。**没有 `name` 的控件不会被带上**，这是最常见的坑。

## `<input>` 类型速查

> 示意片段（无配套脚本）

```html
<!-- 文本 / 密码 / 邮箱（自带格式校验） -->
<input type="text" name="username" />
<input type="password" name="password" />
<input type="email" name="email" />

<!-- 多行文本框：用 textarea，不是 input -->
<textarea name="intro" rows="4"></textarea>

<!-- 单选（同组 name 只选一个）/ 复选（可多选） -->
<input type="radio" name="gender" value="male" /> 男
<input type="checkbox" name="hobby" value="read" /> 阅读

<!-- 下拉：select + option -->
<select name="city">
  <option value="beijing">北京</option>
  <option selected>上海</option>   <!-- selected 默认选中 -->
</select>

<!-- 文件 / 数值 / 日期 -->
<input type="file" name="avatar" />
<input type="number" min="0" max="150" name="age" />
<input type="date" name="birthday" />
```

**HTML5 新增的类型**（自带交互控件或格式校验）：

> 示意片段（无配套脚本）

```html
<input type="search" name="q" />          <!-- 搜索框，自带清除小叉 -->
<input type="range" min="0" max="100" />   <!-- 滑块，配合 min/max/value -->
<input type="color" />                     <!-- 颜色拾取器 -->
<input type="time" /> <input type="week" /> <input type="month" />  <!-- 时间/周/月 -->
<input type="datetime-local" />            <!-- 本地日期时间 -->
```

> 移动端数字输入优先 `inputmode="numeric"`（见第 9 节）；`date`/`time` 等类型在部分桌面浏览器上控件样式不统一，业务上常结合日期选择库使用。

## `<label>`：帮你点击文字也能聚焦控件

> 示意片段（无配套脚本）

```html
<!-- 隐式：标签包裹控件 -->
<label>用户名：<input type="text" name="username" /></label>

<!-- 显式（推荐）：for 对应控件 id -->
<label for="email">邮箱：</label>
<input type="email" id="email" name="email" />

<!-- 单选用法：点"男"字也能选中 -->
<label for="m">男</label><input type="radio" id="m" name="gender" value="male" />
```

`label` 既是便利性（点文字聚焦/选中），也是无障碍：读屏器会把标签和控件绑在一起朗读。

## 常用属性

> 示意片段（无配套脚本）

```html
<!-- 提示 / 限制 -->
<input placeholder="请输入用户名" maxlength="11" />
<!-- 校验约束 -->
<input name="phone" required pattern="[0-9]{11}" />
<!-- 状态 -->
<input value="只读" readonly />   <!-- 只读：不可改但会提交 -->
<input value="禁用" disabled />   <!-- 禁用：不可交互且不提交 -->
```

| 属性 | 作用 |
| ---- | ---- |
| `required` | 必填 |
| `placeholder` / `maxlength` | 占位提示 / 最大长度 |
| `pattern` / `min` `max` | 正则约束 / 数值范围 |
| `autocomplete` | 浏览器自动填充开关 |
| `autofocus` | 页面加载后自动聚焦该控件 |
| `multiple` | 允许选择多个值（`file` 多文件、`email` 多地址） |
| `form="表单id"` | 让**表单外的控件**归属到指定表单一起提交 |
| `readonly` / `disabled` | 只读(可提交) / 禁用(不提交) |

> 示意片段（无配套脚本）

```html
<input type="file" name="files" multiple />          <!-- 多文件 -->
<input type="email" name="emails" multiple />        <!-- 逗号分隔多邮箱 -->
<input name="outside" form="reg" />                  <!-- 在 <form id="reg"> 外，仍随它提交 -->
```

## 提交按钮三兄弟

`<button>` 在表单内**默认是 `submit`**，想当普通按钮务必写 `type="button"`：

| `type` | 作用 |
| ---- | ---- |
| `submit` | 提交表单（默认） |
| `reset` | 重置为默认值 |
| `button` | 无默认行为，配合 JS |

## 原生约束校验：不用 JS 也能拦

HTML5 内置校验，提交时自动拦截非法数据：

> 示意片段（无配套脚本）

```html
<form>
  <input type="text" name="username" required placeholder="用户名" />
  <input type="email" name="email" required />
  <input type="number" name="age" min="18" max="60" />
  <input name="phone" pattern="[0-9]{11}" placeholder="11 位手机号" />
  <button type="submit">注册</button>
</form>
```

校验状态有 CSS 伪类可自定义样式：`:valid`（通过）/ `:invalid`（不通过）。

## 表单事件：`oninput` / `oninvalid`

两个高频的原生表单事件：

- **`input`**：控件值每次变化都触发（比 `change` 更即时，`change` 在失焦/回车时才触发）——做实时校验、字数统计、搜索联想。
- **`invalid`**：原生校验**不通过**时触发——常配合 `setCustomValidity()` 替换默认英文气泡。

> 示意片段（无配套脚本）

```js
const phone = document.getElementById("phone");
phone.addEventListener("input", () => phone.setCustomValidity("")); // 输入时清空旧错误
phone.addEventListener("invalid", () =>
  phone.setCustomValidity("请填写 11 位手机号"));                   // 校验失败时替换提示
```

## FormData：以键值对读表单

不逐个 `getElementById`，用 `FormData` 一次拿全表单（含文件）：

> 示意片段（无配套脚本）

```js
const form = document.getElementById("reg");
form.addEventListener("submit", (e) => {
  const data = new FormData(form);
  console.log(data.get("username"));        // 单个
  console.log([...data.entries()]);         // 全部键值对
  console.log(Object.fromEntries(data));    // 转成对象
});
```

## 数据如何编码（get/post 背景）

- **`get`**：把键值对拼成查询串挂在 URL：`/search?keyword=xx`。适合搜索、可收藏分享。
- **`post`**：放在请求体中，体积大、可含二进制。普通文本用 `application/x-www-form-urlencoded`（`a=1&b=2` 形式）；**上传文件**要把 `form` 的 `enctype` 设为 `multipart/form-data`，否则文件传不上去。

> 示意片段（无配套脚本）

```html
<form action="/upload" method="post" enctype="multipart/form-data">
  <input type="file" name="file" />
  <button type="submit">上传</button>
</form>
```

## 移动端 / 自动填充的几个细节

- 手机端想让"数字键盘"弹出来，给数字输入用 `inputmode="numeric"`（比 `type=number` 更稳）；
- 合理使用 `autocomplete`（`username`/`current-password`/`email`…）配合浏览器记住密码；
- 再有明显依赖关系（二级城市跟随一级）时，再交给 JS 做联动——原生只做"静态"约束。

串起「原生约束 + 自定义提示 + JS 拦截 + FormData 提交」的完整一环。保存为 `register.html` 运行。

> 示意片段（无配套脚本）

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>注册表单</title>
  <style>
    input:valid { border-color: green; }
    input:invalid { border-color: red; }
  </style>
</head>
<body>
  <form id="reg" method="post" novalidate>
    <label for="u">用户名</label>
    <input id="u" name="username" required minlength="2" />
    <label for="p">密码</label>
    <input id="p" name="password" type="password" required minlength="6" />
    <label for="phone">手机号</label>
    <input id="phone" name="phone" type="tel" pattern="[0-9]{11}" />
    <label for="email">邮箱</label>
    <input id="email" name="email" type="email" />
    <button type="submit">注册</button>
  </form>

  <script>
    const form = document.getElementById("reg");
    const phone = document.getElementById("phone");

    // 覆盖默认英文气泡为中文提示
    phone.addEventListener("input", () =>
      phone.setCustomValidity(''));               // 输入时清空
    document.querySelectorAll('input').forEach(inp =>
      inp.addEventListener("invalid", () =>
        inp.setCustomValidity("请按格式填写")));   // 必填通用提示

    form.addEventListener("submit", (e) => {
      e.preventDefault();                         // 阻止页面跳转
      if (!form.checkValidity()) return;          // 未通过则停
      const data = Object.fromEntries(new FormData(form));
      console.log("提交的数据：", data);
      // 真正的发送交给网络章节的 fetch/XHR；这里先拿到干净的 data
    });
  </script>
</body>
</html>
```

> 说明：`novalidate` + `checkValidity()` 是"仍用原生校验、但要自定义展示"的常用组合；真正的数据发送（`fetch`）在 `网络与浏览器` 展开，本章只负责把数据组装到能提交。

## 约束校验是怎么"原生生效"的

`required`/`pattern` 之所以不写 JS 也能拦，是因为浏览器内置了 **Constraint Validation**（约束校验 API）：

> 示意片段（无配套脚本）

```js
const inp = document.getElementById("phone");
inp.validity.valueMissing     // 必填为空 → true
inp.validity.patternMismatch  // 不匹配正则 → true
inp.checkValidity()           // 是否全过 → true/false
inp.setCustomValidity("自定义错误") // 设为非空 → 判定为不通过
```

流程本质：**提交 → 逐一算 `validity` → 有错就命中 `:invalid` 并弹提示 → `invalid`/`submit` 被拦**。你的 `setCustomValidity` 只是替换了这句话，机制是浏览器早就定的。

## `e.preventDefault()` 到底阻止了什么

提交的"默认行为"是：**收集数据 → 按 method 编码 → 跳转/刷新到 action 地址**。`preventDefault()` 就是把这个浏览器内置流程掐断，把控制权交回你的 JS。同理它也能阻止 `<a>` 默认跳转、`<input type=checkbox>` 默认勾选。

> 一句话记忆：`preventDefault` 不是"停下执行"，而是"关掉浏览器帮我做的那个默认动作"。
