3. CSRF 攻击原理与防护（静态示意，不发请求）

        
攻击原理：用户已登录网站 A（浏览器带着 A 的 Cookie），攻击者在网站 B 放置表单或图片，诱导用户浏览器向 A 发送写操作请求——该请求会"自动"携带 A 的 Cookie，服务端误以为是用户本人操作。

防护手段：
1. 同源校验：校验 Origin / Referer 请求头，拒绝跨站来源的写操作；
2. CSRF Token：服务端签发随机 token 随页面下发，写操作必须携带，攻击者无法预知；
3. SameSite Cookie：给 Cookie 设置 SameSite=Lax 或 Strict，跨站请求不再自动携带。
