# CSS 综合实战：一个响应式卡片落地页

把本章 01–05 的能力串成一条完整闭环：**BEM 命名 + Flex/Grid 布局 + 媒体查询响应式 + transform 动画**，做一张"产品特性卡片落地页"。代码已落地在 `code/`，可一键运行。

## 一、需求与设计拆解

我们要做一张页面（而非多个页面），包含：

- 顶部导航 `nav` + 主标题板块；
- 一个**特性卡片网格**（3 列），每张卡片由 BEM 类名承载；
- 卡片有悬停动效（`transform: scale` 合成层动画）；
- 整页**响应式**：桌面 3 列 → 平板 2 列 → 手机 1 列（Mobile First 向上递进）；
- 一个入场动画（`animation … both` 避免闪跳）。

技术对应：

| 需求 | 用到的章节能力 |
| --- | --- |
| 语义结构 + 命名 | 01 语义化 + 05 BEM |
| 3 列网格 / 布局 | 02 Grid + Flex |
| 断点自适应 | 03 媒体查询 / vw |
| 悬停与入场动效 | 04 transform / animation |

## 二、只写关键部分（完整代码见项目文件）

### 1. BEM 结构：卡片 `feature__card--modifier`

> 示意片段（无配套脚本）

```html
<section class="features">
  <article class="feature feature--primary">
    <div class="feature__icon">🚀</div>
    <h3 class="feature__title">快速启动</h3>
    <p class="feature__desc">秒级冷启动，开发体验丝滑</p>
  </article>
  <!-- ……更多卡片 -->
</section>
```

> 示意片段（无配套脚本）

```css
.feature { padding: 1.5rem; border: 1px solid #e5e7eb; border-radius: 12px;
           transition: transform .3s ease, box-shadow .3s ease; }
.feature--primary { background: #eff6ff; border-color: #bfdbfe; }
.feature__title { font-size: 1.1rem; font-weight: 600; }
.feature:hover { transform: translateY(-4px); box-shadow: 0 8px 24px rgba(0,0,0,.12); }
```

### 2. Grid 三列 + Mobile First 媒体查询

> 示意片段（无配套脚本）

```css
.features {
  display: grid;
  gap: 1rem;
  grid-template-columns: 1fr;            /* 手机：1 列 */
}
@media (min-width: 600px) {
  .features { grid-template-columns: 1fr 1fr; }  /* 平板：2 列 → 复用/覆盖手机声明 */
}
@media (min-width: 900px) {
  .features { grid-template-columns: 1fr 1fr 1fr; } /* 桌面：3 列 */
}
```

> Mobile First = 默认写移动端，断点**向上递进（min-width）**，大屏只是覆盖列数，不必动小屏样式。

### 3. 入场动画（fill-mode: both）

> 示意片段（无配套脚本）

```css
@keyframes rise { from{opacity:0; transform: translateY(24px);} to{opacity:1; transform:none;} }
.features__item { animation: rise .5s ease both; }   /* 入场，结束保留末帧，避免闪跳 */
```

### 4. 导航用 Flex

> 示意片段（无配套脚本）

```css
.nav { display: flex; justify-content: space-between; align-items: center; gap: 1rem; }
```

## 三、验收标准

打开页面检查：

- 拖动窗口宽度，网格在 1 / 2 / 3 列间自适应，内容不溢出；
- 卡片悬停有平滑的"上浮 + 阴影"，流畅不卡顿；
- 页面加载时卡片从下方依次浮现（入场动画）；
- 在 DevTools 里能看到类名遵循 `block__element--modifier`，改一处样式不影响他处。

> 到此，你能独立用纯 CSS 完成"命名规范 + 布局 + 响应式 + 动效"的完整页面——这正是 CSS 面试里"聊到就手写一个"的底气。
