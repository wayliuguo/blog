现代选择器与函数

① :is() 带权、:where() 清零

A：:is(#ghost-a, .probe-a) 与 .probe-a 竞争

B：:where(#ghost-b, .probe-b) 与 .probe-b 竞争

两条规则的写法只差 :is / :where：:is() 会把括号里 #ghost-a 的 ID 权重带进来（1,0,0），所以压过 .probe-a；:where() 权重恒为 0,0,0，于是 .probe-b 反超。

② clamp()：一个值兼顾三档

我在 clamp(1rem, 1rem + 2vw, 1.75rem) 里——本视口触到上限

我在 clamp(1rem, 0.5rem + 1vw, 3rem) 里——本视口落在中间档

③ aspect-ratio：给宽锁比例

只写了 width: 160px 和 aspect-ratio: 16 / 9，高度由浏览器算出来。

④ :has()：按后代状态给容器上样式

⑤ prefers-reduced-motion：动效降级

我在动 —— 若系统开启「减少动态效果」，这里会变成静止。
