BFC：父元素的隔离

① 未触发 BFC（父子 margin 塌陷）

看黄盒本身：它的高度只有 60px，紧贴子元素；子元素的 20px 外边距「穿」到了黄盒外面， 变成黄盒与上方标题之间的空隙——这就是塌陷。
父无 BFC → 子的 20px margin 溢出到父元素外面

② 父触发 BFC（overflow:hidden）→ margin 被包在盒内

黄盒高度变成 100px（60 + 20 + 20），子元素的 20px 外边距在黄盒内部四周都能看到， 不再溢出。
父有 BFC → 子的 20px margin 被父元素包住

结论：触发 BFC（如 overflow:hidden、overflow:auto、display:flow-root）让父形成独立渲染上下文，父子 margin 不再合并、子元素的外边距不会「顶出」父元素。
