自定义属性：把「值」抽成令牌

同一个 .token-box，颜色与间距全部来自 var()。页面尾部的探针会打印浏览器解析后的值，用来佐证继承、作用域、主题切换与 @property 这四件事。

① 令牌与使用处

背景取自 var(--brand)，内边距取自 var(--space)

② 局部重定义只影响子树

我在 .scope 里，用的是重定义后的 --brand
我在 .scope 外面，--brand 没被影响

③ 不存在时用兜底值

令牌名写错不会让整条声明作废：var(--not-defined-anywhere, #f59e0b) 直接用了兜底色。

我的背景来自 var() 的兜底参数

④ @property 决定「有没有类型、继不继承」

--no-inherit 注册为 <length> 且 inherits: false：父元素上的 40px 不会被子元素继承；而未注册的 --space 会照常继承。

我是子元素，看看我拿到的两个变量分别是多少

⑤ 颜色也能当算式

浅色与半透明色从主色算出来，不用再手抄第二、第三个十六进制：color-mix() 按比例混， oklch() 直接按感知亮度给色。

color-mix(in oklab, var(--brand) 80%, #ffffff)
color-mix(in srgb, var(--brand) 25%, transparent)
oklch(0.72 0.15 250)
