三个观察者：让浏览器在"变化发生时"通知你

它们替代的都是"轮询 + 手动计算"：判断元素有没有进视口、容器尺寸变没变、DOM 被谁改过。回调都是异步投递的，不需要你自己开定时器去查。

提示：IntersectionObserver 与 ResizeObserver 的回调投递依赖浏览器产生渲染帧，无头 Chrome 下不保证投递（实测 --dump-dom 抓不到）。所以这两节的结果请看下面灰色那行——需要在真实浏览器窗口里打开；页尾探针给的是任何环境都能核对的几何量与 MutationObserver 记录（后者走微任务队列，不依赖渲染帧）。

① IntersectionObserver：元素进没进视口

同一个目标元素挂两个观察者：一个用默认 rootMargin，一个把底部边界外扩 100px。后者在元素还看不见时就判定为"已进入"——图片懒加载的预加载带就是这么做的。

② ResizeObserver：盒子尺寸变了

它盯的是被观察元素自己的尺寸变化（内容盒），比监听 window.resize 精确得多——容器被 flex 挤窄、侧栏折叠都能感知。
