css-styles：三种样式方案对比

三个卡片分别演示 React 中三种写样式的方式，都不依赖任何库，浏览器直接打开即可交互：

  • 内联 style：把驼峰对象直接赋给元素，适合动态、一次性的样式。
  • className + 样式表：样式写在样式表里，用类名切换，可复用、可换肤。
  • CSS 变量 + 命名前缀：变量限定在带前缀的类内，换变量即换肤，模拟 CSS Module 的隔离思路。

方案一：内联 style（驼峰对象）

计数：0

样式来自 JS 里的驼峰对象：{ backgroundColor, border, borderRadius }，等价于 React 的 style 属性。

方案二：className + 样式表

当前主题：浅色

样式写在 <style> 里，只切换 className（对应 React 里动态拼接类名）。

方案三：CSS 变量 + 命名前缀（模拟 CSS Module）

我是 cmod-box：颜色来自 var(--cmod-*) 变量

变量全部带 cmod- 前缀并只在 .cmod-box 内生效，换一组变量即换肤—— 前缀命名避免污染全局，对应 CSS Module 编译出 hash 类名的隔离思路。
