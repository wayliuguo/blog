## 知识主线（一句话）

网络与浏览器的主轴是**浏览器渲染原理**：01 讲页面资源怎么从服务器传过来（HTTP/HTTPS/DNS/缓存/版本演进），02 讲传过来的资源如何走完"解析 → 布局 → 绘制 → 合成"变成像素，03 讲运行中产生的状态存到哪里（Cookie/Web Storage/IndexedDB/Cache Storage），04 把前面所有环节放回"信任边界"视角讲 XSS/CSRF/CSP 防御——串起来正好是"输入 URL → 渲染完成 → 持久化 → 安全防护"的完整链路。

## 高频核心点

### 01 HTTP 与 HTTPS

**HTTP 基础与方法**

- **无状态**：每个请求独立、服务器不记忆客户端，靠 Cookie/Session/Token 显式携带身份模拟"有状态"
- **方法语义与幂等**：GET 取数据无体幂等、POST 提交非幂等、PUT 整体替换幂等、DELETE 删除幂等；GET/POST 本质差异是语义
- **报文结构**：请求/响应行 + 头 + 空行 + 体；请求行 METHOD+路径+版本、响应行 版本+状态码+描述

**状态码五类**

- **2xx**：200 正常、201 已创建、204 成功无内容
- **3xx**：301 永久 / 302 临时 / 304 协商缓存命中
- **4xx**：401 未认证 vs 403 无权限、404、405、429 限流
- **5xx**：500 / 502 网关无效响应 / 503 / 504 网关超时

**HTTP 缓存**

- **强缓存**：`Cache-Control: max-age`（相对时间优先）vs `Expires`（绝对时间依赖客户端时钟），命中不发请求直接用本地
- **协商缓存**：`If-None-Match`/ETag（内容指纹，优先）与 `If-Modified-Since`/Last-Modified，304 复用
- **开发实践**：静态资源内容指纹文件名（`app-5f8c2a.js`）+ 长 `max-age`，HTML 用 `no-cache`；`no-store` 全不缓存、`no-cache` 每次协商

**版本演进（消除队头阻塞）**

- **HTTP/1.1**：Keep-Alive 持久连接，一个连接同时一个请求，靠多连接（约 6 个）缓解
- **HTTP/2**：二进制分帧 + 多路复用 + HPACK 头部压缩，解应用层队头阻塞
- **HTTP/3**：传输层换 QUIC（UDP），TLS 1.3、0-RTT、连接迁移，解传输层队头阻塞

**HTTPS / DNS / TCP / UDP / WebSocket**

- **混合加密**：非对称协商会话密钥 + 对称加密（AES）传大流量；CA 证书让客户端内置根证书验签防中间人；`HSTS` 防降级
- **DNS**：缓存 → 本地递归 → 根/顶级/权威迭代；`dns-prefetch`/`preconnect` 预热
- **TCP vs UDP**：TCP 可靠（确认/重传/乱序重排）会粘包；UDP 快但不可靠、自带消息边界；实时音视频/DNS 走 UDP，QUIC 折中
- **WebSocket**：Upgrade 101 握手后的全双工持久连接，服务端可推；无同源限制须校验 `Origin`；断线重连 + 心跳保活；性能 WebSocket > SSE > 长轮询 > 短轮询

### 02 浏览器渲染原理

**多进程与导航**

- **四进程**：浏览器主进程（UI/网络/调度）、渲染进程（每标签页一个，解析/布局/绘制/脚本）、GPU 进程（合成）、网络进程；价值是隔离稳定 + 沙箱
- **导航流程**：URL → DNS → TCP（TLS）→ 请求 HTML → 渲染进程解析 → 布局 → 绘制 → 合成；命中强缓存跳过网络请求

**解析与阻塞**

- **HTML 解析五步**：字节流 → 字符 → Token → 节点 → DOM 树
- **CSS 阻塞渲染**：构造样式必须拿到全部 CSS（渲染阻塞资源），CSSOM 就绪前不渲染
- **script 阻塞解析**：普通同步脚本暂停解析；`defer` 解析完按序执行、`async` 下载完立即执行

**DOM / CSSOM / Render Tree**

- **DOM 管结构、CSSOM 管样式**（选择器匹配 + 层叠 + 继承算计算样式），合并成"可绘制"的 Render Tree
- **可见性过滤**：剔除 `display:none` 与 `<head>`/`<script>` 等不可见节点

**回流 / 重绘 / 合成**

- **回流（Layout）**：改几何最贵、必带重绘；读 `offsetWidth` 触发强制同步布局
- **重绘（Paint）**：只改颜色/背景相对便宜
- **合成（Composite）**：走 GPU 最廉价；动画只用 `transform`/`opacity` 是性能铁律

**优化清单**

- 减少关键资源（压缩/合并/按需加载）、脚本 `defer`/async 或放底部、CSS 尽早
- 批量读写 DOM 避免"读-写"交替、`will-change` 适度、`content-visibility` 跳屏外渲染

**事件流与事件委托**

- 捕获 → 目标 → 冒泡；`addEventListener` 第三参 `true` 捕获、默认冒泡，`onclick` 只能冒泡
- 委托 = 绑公共祖先利用冒泡（省内存 N→1、动态节点免绑定）；`focus`/`blur`/`scroll` 不冒泡无法委托

### 03 浏览器存储与本地缓存

**Cookie**

- 服务端 `Set-Cookie` 下发、自动随同源请求携带，约 4KB，只承载会话标识
- 核心属性：`Expires/Max-Age`、`Path`、`Domain`（含子域）、`Secure`（仅 HTTPS）、`HttpOnly`（禁 JS 读防 XSS）、`SameSite`
- `document.cookie` 可读写非 HttpOnly 部分、一次写一个

**localStorage vs sessionStorage**

- 共同点：同步、约 5MB、只存字符串、不随请求发送
- 区别：持久 vs 关标签页清；同源所有标签页共享 vs 同一标签页内共享
- 坑：同步写大对象卡线程、容量满抛 `QuotaExceededError`（try/catch）

**IndexedDB**

- 内置 NoSQL 事务型数据库，对象仓库/索引/事务/异步，百 MB~GB 级
- 适合大量结构化数据（离线笔记、聊天记录）；API 繁琐常用 Dexie.js 封装

**Service Worker + Cache Storage**

- SW = 独立线程网络代理、须 HTTPS，拦截请求实现离线访问
- Cache Storage 以"请求-响应"为单位；四策略：Cache First / Network First / Stale-While-Revalidate / Network Only

**选型流程**

- 会话态 → Cookie（HttpOnly + SameSite=Lax）；复杂大数据 → IndexedDB；跨标签持久 → localStorage；关页即清 → sessionStorage；Web SQL 已废弃用 IndexedDB 替代

### 04 前端安全

**同源与 CORS**

- 同源三要素：协议 + 域名 + 端口全同；管的是"读"不是"发"——请求真的发出去、被拦的只是把响应交给 JS
- 简单请求直接发靠响应头放行；非简单（自定义头/PUT/DELETE/`application/json`）先 `OPTIONS` 预检
- 两条硬规则：`Allow-Credentials: true` 与 `Allow-Origin: *` 互斥；自定义响应头须 `Expose-Headers` 放行
- 失败表现：只拿到 `Failed to fetch`，但请求其实到了服务端——CORS 不能当鉴权

**XSS 三类**

- 反射型（URL 注入）、存储型（入库持久、危害最大可横向传播）、DOM 型（JS 操作 DOM 时注入，`innerHTML`/`document.write`/`eval` 危险入口）
- 防御：输入白名单 + 输出按上下文编码、`textContent`/DOMPurify、Cookie HttpOnly、CSP 纵深；富文本只能白名单不能黑名单

**CSRF**

- 原理：已登录 A 访问恶意 B，浏览器自动带 A 的 Cookie 发请求
- 首选防御 `SameSite=Lax`（现代浏览器默认）阻断跨站 POST；辅助：CSRF Token、Origin/Referer 校验、敏感操作二次验证
- Lax 防不住同站子域与 GET 副作用；Token 需防 XSS 窃取

**CSP 与纵深**

- 指令白名单：`default-src`/`script-src`/`style-src`/`img-src`/`connect-src`；内联用 nonce（每次随机）/hash（每次改动重算）放行；`report-uri` 上报
- 防点击劫持：`frame-ancestors`（现代首选）/ `X-Frame-Options`；SQL 注入根治在服务端参数化查询、上传靠类型白名单 + 魔数 + 非可执行目录、SVG 可内嵌脚本慎开放
