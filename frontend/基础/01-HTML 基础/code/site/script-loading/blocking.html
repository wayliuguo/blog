阻塞对比：同步 script vs defer vs async

三个 iframe 用同一份 slow.js?delay=2000，分别以同步、defer、async 加载。各页在可见内容之后放了一行上报脚本，它的执行时刻 ≈ 内容可被渲染的时刻：

  • 同步：脚本下载完之前解析暂停，内容约 2 秒后才可见（白屏）。
  • defer / async：不阻塞解析，内容立刻可见。脚本本身的执行时机对比见 order.html。
