## 2. 重点题精答（五步法）

### Q1：`defer`、`async`、`type="module"` 的区别？

- **结论**：三者都不阻塞解析；defer 推迟且保序，async 下载完即执行不保序，module 自带 defer 语义。
- **原理**：defer 在 DOM 解析完成后、DOMContentLoaded 前按文档顺序执行；async 在下载完成瞬间执行（可能在解析中途）；module 默认 defer + 严格模式 + 模块作用域。
- **场景**：Vite 产物入口 `type="module"`（自带 defer，无需手写）；统计脚本用 async（独立无依赖）。
- **边界**：async 脚本若访问 `document.body` 可能拿 null，需判空；defer 仍需等 DOM 就绪，首屏关键逻辑应内联。
- **追问**：模块顶层 `this` 是什么？→ undefined。

### Q2：`dns-prefetch`、`preconnect`、`preload`、`prefetch` 的区别？

- **结论**：四者都是预连接/预加载指令，但作用阶段与代价不同。
- **原理**：dns-prefetch 只做 DNS 解析；preconnect 做完 DNS+TCP+TLS；preload 高优先级加载"当前页必需"资源；prefetch 空闲时预取"以后可能用"的资源；modulepreload 预加载 ESM 依赖图。
- **场景**：项目模板里 13 条 `dns-prefetch` 覆盖 CDN/上报域名（成本低、覆盖广）；关键字体用 preconnect（需配合 `crossorigin`）。
- **边界**：preload 误用（加载下一页资源）会抢占首屏带宽并触发 console 警告；preconnect 占用连接池，不宜超 4-6 个。
- **追问**：preconnect 不写 `crossorigin` 加载跨域字体会怎样？→ 建立两次连接，失效。

### Q3：`<!doctype html>` 与怪异模式？

- **结论**：doctype 是标准模式开关，缺失进入怪异模式。
- **原理**：浏览器按 doctype 选择解析模式；怪异模式下盒模型、行高、margin 折叠与标准不一致。
- **场景**：SPA 一般不会遇到，但多页模板/服务端直出漏写就会中招。
- **边界**：`document.compatMode === 'CSS1Compat'` 为标准，`'BackCompat'` 为怪异。
- **追问**：怪异模式对 box-sizing 默认值？→ 仍是 content-box。

### Q4：如何用 Vite 插件向 HTML 注入内联错误监控脚本？

- **结论**：用 `transformIndexHtml` 钩子在 `<head>` 标签后切片插入内联 `<script>`。
- **原理**：监控脚本必须最早执行才能捕获 polyfill 与业务代码之前的错误；内联零网络延迟；`enforce:'post'` 保证在 legacy 等插件之后执行不被覆盖。
- **场景**：真实代码 `error-monitor-plugin`，`indexOf('<head>')` 后插入，缩进对齐保持 HTML 结构。
- **边界**：若插到 `<body>` 末尾，会漏掉 `<head>` 解析期间发生的错误。
- **追问**：内联 vs 外部 src 选哪个？→ 必须内联，否则有网络延迟漏报。

### Q5：`src` 与 `href` 的区别？

- **结论**：href 是"引用"，src 是"加载并嵌入"。
- **原理**：`<link href>`、`<a href>` 建立关联不替换内容；`<script src>`、`<img src>`、`<iframe src>` 需下载并执行/渲染。
- **场景**：CSS 放 `<head>`（CSSOM 早就绪避免重排）、JS 用 `defer`/module 不阻塞首屏。
- **边界**：`<a href="app.js">` 不会执行脚本；`<script href>` 不加载。
- **追问**：同步 script 为什么阻塞而 stylesheet 不阻塞解析？→ 语义不同：src 要执行，href 只是关联。

## 3. 追问链

1. "为什么 CSS 放 head、JS 放 body 末尾？" → CSSOM 尽早就绪避免重排与 FOUC；JS 阻塞解析放末尾或 defer。
2. "错误监控为什么必须最早内联？" → 捕获 polyfill 前的语法错误/资源错误；内联零延迟。
3. "`user-scalable=0` 合规吗？" → 违反 WCAG 缩放要求，需在面试主动说明业务取舍。
4. "`preload` 的 `as` 属性写错会怎样？" → 优先级/CSP/缓存分区错误，甚至重复下载。

## 4. 场景设计题

**场景：H5 活动页首屏白屏，怎么从 HTML 层定位与优化？**
- 答题骨架：同步脚本阻塞 → 检查是否 `type="module"`/defer → 关键 CSS 是否内联 → 跨域资源是否 dns-prefetch/preconnect → 错误监控是否最早注入可观测 → 图片是否懒加载。
- 加分点：给出"先让错误可见（监控）→ 再用数据定位 → 最小改动修复"的方法论，呼应简历的 iOS 白屏 case。
