mini-router · 断点调试入口

零依赖，浏览器直接打开本文件，F12 打开控制台 + Sources 面板即可断点。打开时控制台会自动跑完 3 个 demo，对应正文三条主线：

  • demo 1 · matcher（正文二）：动态段 → 捕获组、嵌套路由的 matched 链、未匹配为空、addRoute 动态追加
  • demo 2 · 路由器主体（正文 4.1 · 4.3）：currentRoute 是唯一状态源、一次导航视图恰好重跑一次、前进后退走 listen
  • demo 3 · 守卫流程（正文 4.2）：重定向 / 取消 / 守卫顺序（beforeEach → beforeEnter → afterEach）

建议断点（Sources 面板按分区注释搜索）：compilePath（:id → 正则）· insert（matched 链成形）· resolve（精确表 → 正则回退）· createMemoryHistory 的 push / go（静默 vs fire）· navigate（守卫主干：改 URL → 改状态）· resolveView（按深度取组件）。
