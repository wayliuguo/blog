mini-pinia · 断点调试入口

零依赖，浏览器直接打开本文件，F12 打开控制台 + Sources 面板即可断点。打开时控制台会自动跑完 3 个 demo，对应正文三条主线：

  • demo 1 · 响应式底座（正文二）：三层依赖表精确到字段、改一个字段只唤醒读过它的 effect、computed 惰性与缓存
  • demo 2 · store（正文三·四）：defineStore（id 即命名空间）、ref 自动解包第一层、storeToRefs、$patch 逐键 Object.is
  • demo 3 · 三条路线对照（正文五）：Pinia / 直接 reactive / Vuex 式 mutation，数字一模一样——差别在约定不在机制

建议断点（Sources 面板按分区注释搜索）：track / trigger（依赖表与精确唤醒）· reactive 的 get / set（惰性深度代理）· computed 的 scheduler（只置脏不重算）· defineStore（id 即命名空间）· createSetupStore 的 Proxy get / set（解包第一层 / 写走 ref setter）· storeToRefs · store.$patch。
