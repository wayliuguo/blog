demo · 整体运行（官网 CDN 用法）

页面加载即按官网 CDN 的方式运行：<div id="app"> 里的 HTML 就是模板，脚本里 createApp({...}).mount('#app')——mount 时读取容器 innerHTML 交给 compile（@click / v-for / :key / 插值都在这一步编译），清空容器后由渲染器重建真实 DOM。左栏是组件源码，右栏渲染区就是这个组件；下面的页面层按钮负责触发各条链路。

组件源码（与官网 CDN 示例同构）

const { createApp, ref } = MiniVue

createApp({
  setup() {
    const message = ref('Hello vue!')
    const count = ref(0)
    const todos = ref([
      { id: 1, text: 'a' },
      { id: 2, text: 'b' },
      { id: 3, text: 'c' },
      { id: 4, text: 'd' },
      { id: 5, text: 'e' }
    ])
    const increment = () => count.value++
    return { message, count, todos, increment }
  }
}).mount('#app')

断点标注（按链路顺序）
  1. mount('#app')：字符串选择器 → querySelector；读容器 innerHTML 当模板 → compile()（断点：parse / transform / generate）→ 清空容器 → render(vnode, container)
  2. setup()：建响应式状态；render 执行时模板里的插值读 ctx.xxx（ref 自动解包）→ track 建立依赖
  3. patch(null, subTree)：v-for 展开的 li 带 key，逐个 mountElement 生成真实 DOM
  4. 改状态：trigger → queueJob（同一 tick 多次写入去重成 1 个 job）→ 微任务 flushJobs → patch(prev, next)（插值文本走 patchFlag=1；列表走 keyed diff：头尾同步（整段增删走快速通道：批量 mount / unmount）→ 中间乱序 key 索引 → LIS 跳过本就位节点 → 只挪必须动的）
  5. unmount()：unmounted 钩子 → 渲染 effect stop（死写不再触发渲染）→ 递归 remove；重新加载页面即可重看挂载
