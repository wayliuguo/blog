effect 首跑读数据时 track 建依赖，改数据时 trigger 唤醒依赖重跑；computed 依赖变化只置脏、读了才算；watch 是独立 effect，回调经 scheduler 执行。下面每行数值都由 effect / computed / watch 回调驱动刷新。

操作
渲染区（每行由各自的 effect / computed / watch 驱动）
ref：count = 0（effect 渲染）
reactive：nested.msg = hello · title = 标题 A（深层属性也被代理拦截）
computed：double = 0 · getter 调用 0 次（依赖变了不读就不算）
watch 回调最近一次：新值 — ← 旧值 —（停止侦听后这里不再更新，但上面的 count 还在变）
