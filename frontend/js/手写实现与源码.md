# 手写实现与源码

本篇按统一体例整理高频手写题：**思路一两句 → 精简实现 → 调用示例 → 关键点**。所有实现以"讲清原理、能在面试白板上写出"为准，生产环境直接用原生方法或成熟库。

## call / apply / bind

### 思路

三者都用于显式指定函数的 `this`：`call`/`apply` 立即调用（参数一个逐个传、一个以数组传），`bind` 返回绑定了 `this` 的新函数。核心原理是**谁调用函数，`this` 就指向谁**——把函数临时挂到目标对象上再调用，就能借机改变 `this`。用 `Symbol` 做临时 key，避免覆盖对象原有属性。

### 代码

> 示意片段（无配套脚本）

```js
Function.prototype.myCall = function (thisArg, ...args) {
  thisArg = Object(thisArg ?? globalThis) // null/undefined 指向全局；基本类型包装成对象
  const key = Symbol('fn') // 避免与原有属性冲突
  thisArg[key] = this
  const result = thisArg[key](...args)
  delete thisArg[key] // 用完删掉，不留痕迹
  return result
}

Function.prototype.myApply = function (thisArg, args) {
  thisArg = Object(thisArg ?? globalThis)
  const key = Symbol('fn')
  thisArg[key] = this
  const result = Array.isArray(args) ? thisArg[key](...args) : thisArg[key]()
  delete thisArg[key]
  return result
}

Function.prototype.myBind = function (thisArg, ...boundArgs) {
  const fn = this
  return function (...callArgs) {
    return fn.apply(thisArg, [...boundArgs, ...callArgs])
  }
}
```

### 调用示例

> 示意片段（无配套脚本）

```js
const obj = { name: '张三' }

function greet(greeting, punctuation) {
  return `${greeting}，${this.name}${punctuation}`
}

console.log(greet.myCall(obj, '你好', '！'))      // 你好，张三！
console.log(greet.myApply(obj, ['早上好', '。']))  // 早上好，张三。
const bound = greet.myBind(obj, '晚上好')
console.log(bound('～'))                          // 晚上好，张三～
```

### 关键点

- `thisArg ?? globalThis` 一行兜底 `null`/`undefined`（非严格模式下应指向全局对象），不需要区分浏览器/Node 环境，`globalThis` 两边通用。
- `Object(thisArg)` 让传数字/字符串时也能挂属性；`Symbol` key 保证不污染、`delete` 保证不留痕。
- `bind` 返回普通函数，靠闭包锁住 `thisArg` 和预置参数。

## new

### 思路

`new` 做四件事：创建空对象 → 原型指向构造函数的 `prototype` → 以该对象为 `this` 执行构造函数 → 构造函数返回对象时用返回值，否则返回新对象。

### 代码

> 示意片段（无配套脚本）

```js
function myNew(Constructor, ...args) {
  const obj = Object.create(Constructor.prototype) // 建对象 + 连原型，一步完成
  const result = Constructor.apply(obj, args)
  return typeof result === 'object' && result !== null ? result : obj
}
```

### 调用示例

> 示意片段（无配套脚本）

```js
function Person(name) {
  this.name = name
}
Person.prototype.greet = function () {
  return `hello, ${this.name}`
}

const p = myNew(Person, '张三')
console.log(p.greet())            // hello, 张三
console.log(p instanceof Person)  // true
```

### 关键点

- 只有构造函数**显式返回对象**才覆盖新对象；返回原始值会被忽略。

## instanceof

### 思路

`a instanceof B` 就是判断 `B.prototype` 是否出现在 `a` 的原型链上——沿 `Object.getPrototypeOf` 一路向上找。

### 代码

> 示意片段（无配套脚本）

```js
function myInstanceof(left, right) {
  let proto = Object.getPrototypeOf(left)
  while (proto !== null) {
    if (proto === right.prototype) return true
    proto = Object.getPrototypeOf(proto)
  }
  return false
}
```

### 调用示例

> 示意片段（无配套脚本）

```js
console.log(myInstanceof([], Array))   // true
console.log(myInstanceof([], Object))  // true，数组也在 Object 的原型链上
console.log(myInstanceof({}, Array))   // false
```

### 关键点

- `Object.create(null)` 创建的对象没有原型，对任何构造函数都是 `false`。

## 深拷贝与浅拷贝

### 思路

浅拷贝只复制第一层（`{...obj}` / `Object.assign`），引用类型属性仍共享；深拷贝递归所有层级。`JSON.parse(JSON.stringify())` 能深拷贝但丢函数/`undefined`/`Symbol`、循环引用直接报错，所以健壮版要手写。

### 代码

> 示意片段（无配套脚本）

```js
function deepClone(target, map = new WeakMap()) {
  if (target === null || typeof target !== 'object') return target // 原始类型直接返回
  if (map.has(target)) return map.get(target) // 循环引用：返回缓存

  if (target instanceof Date) return new Date(target)
  if (target instanceof RegExp) return new RegExp(target.source, target.flags)

  const clone = Array.isArray(target) ? [] : {}
  map.set(target, clone)
  Reflect.ownKeys(target).forEach((key) => { // ownKeys 连 Symbol 键一起拷
    clone[key] = deepClone(target[key], map)
  })
  return clone
}
```

### 调用示例

> 示意片段（无配套脚本）

```js
const obj = { name: '张三', tags: ['a'], meta: { level: 1 }, when: new Date() }
obj.self = obj // 循环引用

const copy = deepClone(obj)
console.log(copy.meta === obj.meta) // false，完全独立
console.log(copy.self === copy)     // true，循环引用被正确重建
```

### 关键点

- `WeakMap` 记录「原对象 → 拷贝」映射，既解循环引用，又不妨碍 GC。
- `Reflect.ownKeys` 同时含字符串键和 `Symbol` 键；`Date`/`RegExp` 有内部槽，需单独 `new`。
- 更完整的实现还要处理 `Map`/`Set`，面试先讲清主体再补强即可。

## Promise 与 Promise.all / allSettled

### 思路

`Promise` 有 `pending / fulfilled / rejected` 三种状态，**状态一经变更不可逆**。实现四要素：构造函数立即执行 `executor`；维护状态与回调队列；`then` 返回新 Promise（链式），回调放进微任务；返回 Promise 时等它决议。

### 代码

> 示意片段（无配套脚本）

```js
class MyPromise {
  constructor(executor) {
    this.state = 'pending'
    this.value = undefined
    this.onFulfilledCbs = []
    this.onRejectedCbs = []

    const resolve = (value) => {
      if (this.state !== 'pending') return // 状态不可逆
      this.state = 'fulfilled'
      this.value = value
      this.onFulfilledCbs.forEach((fn) => fn())
    }
    const reject = (reason) => {
      if (this.state !== 'pending') return
      this.state = 'rejected'
      this.reason = reason
      this.onRejectedCbs.forEach((fn) => fn())
    }
    try {
      executor(resolve, reject)
    } catch (err) {
      reject(err)
    }
  }

  then(onFulfilled, onRejected) {
    // 值穿透：没传回调就补默认行为
    onFulfilled = typeof onFulfilled === 'function' ? onFulfilled : (v) => v
    onRejected = typeof onRejected === 'function' ? onRejected : (r) => { throw r }

    return new MyPromise((resolve, reject) => {
      const run = (task, val) => {
        queueMicrotask(() => { // 回调放微任务，保证"Promise 永远异步"
          try {
            const result = task(val)
            result instanceof MyPromise ? result.then(resolve, reject) : resolve(result)
          } catch (err) {
            reject(err)
          }
        })
      }
      if (this.state === 'fulfilled') run(onFulfilled, this.value)
      else if (this.state === 'rejected') run(onRejected, this.reason)
      else {
        this.onFulfilledCbs.push(() => run(onFulfilled, this.value)) // pending 先入队
        this.onRejectedCbs.push(() => run(onRejected, this.reason))
      }
    })
  }

  catch(onRejected) {
    return this.then(null, onRejected)
  }

  static all(promises) {
    return new MyPromise((resolve, reject) => {
      const results = []
      let count = 0
      promises.forEach((p, i) => {
        MyPromise.resolve(p).then(
          (val) => {
            results[i] = val // 用下标存，保证顺序与输入一致
            if (++count === promises.length) resolve(results)
          },
          reject // 任意一个失败，整体立即失败
        )
      })
    })
  }

  static allSettled(promises) {
    return new MyPromise((resolve) => {
      const results = []
      let count = 0
      promises.forEach((p, i) => {
        MyPromise.resolve(p).then(
          (value) => done(i, { status: 'fulfilled', value }),
          (reason) => done(i, { status: 'rejected', reason })
        )
      })
      function done(i, item) {
        results[i] = item
        if (++count === promises.length) resolve(results) // 永不 reject
      }
    })
  }
}
```

### 调用示例

> 示意片段（无配套脚本）

```js
new MyPromise((resolve) => resolve(1))
  .then((v) => v + 1)
  .then((v) => console.log(v))       // 2

MyPromise.all([MyPromise.resolve(1), MyPromise.resolve(2)])
  .then((res) => console.log(res))   // [1, 2]

MyPromise.allSettled([MyPromise.resolve(1), MyPromise.reject(new Error('x'))])
  .then((res) => console.log(res))   // [{status:'fulfilled',value:1},{status:'rejected',reason:Error}]
```

### 关键点

- `resolve`/`reject` 先判状态，保证单向不可逆；`then` 返回新 Promise 是链式的根基。
- 回调放 `queueMicrotask`，模拟"Promise 永远异步"；返回值是 Promise 时接 `then` 传递决议。
- `all` 用**下标**存结果保证顺序；`race` 是同一套 `then(resolve, reject)` 全员注册即可，`any` 只把 reject 换成计数。

## 防抖 debounce / 节流 throttle

### 思路

- **防抖**：触发后等 `delay` 再执行，期间再触发就**重置倒计时**——只认最后一次，适合搜索输入、resize。
- **节流**：固定间隔内**最多执行一次**——控制频率，适合滚动、拖拽。

### 代码

> 示意片段（无配套脚本）

```js
function debounce(fn, delay = 300) {
  let timer = null
  return function (...args) {
    clearTimeout(timer) // 灵魂：每次触发重置倒计时
    timer = setTimeout(() => fn.apply(this, args), delay)
  }
}

function throttle(fn, delay = 300) {
  let last = 0
  return function (...args) {
    const now = Date.now()
    if (now - last >= delay) {
      last = now
      fn.apply(this, args)
    }
  }
}
```

### 调用示例

> 示意片段（无配套脚本）

```js
input.addEventListener('input', debounce((e) => search(e.target.value), 500))
window.addEventListener('scroll', throttle(() => console.log(window.scrollY), 200))
```

### 关键点

- 两者都必须**保留 `this` 和 `...args`**（用 `apply` 透传），否则包装后的函数丢上下文。
- 节流时间戳版"首次立即执行、末尾可能丢"；需要"保证末尾也执行"就换定时器版（`if (!timer)` + 到期清空），面试能点出取舍即可。

## 发布订阅 EventBus

### 思路

事件总线：`on` 订阅、`emit` 发布并把参数透传给所有回调。用「事件名 → 回调数组」存储，每个条目带 `once` 标记，订阅返回解绑函数。

### 代码

> 示意片段（无配套脚本）

```js
class EventBus {
  constructor() {
    this.events = {} // eventName -> [{ fn, once }]
  }

  on(name, fn) {
    ;(this.events[name] ||= []).push({ fn, once: false })
    return () => this.off(name, fn) // 返回解绑函数
  }

  once(name, fn) {
    ;(this.events[name] ||= []).push({ fn, once: true })
  }

  off(name, fn) {
    this.events[name] = (this.events[name] || []).filter((it) => it.fn !== fn)
  }

  emit(name, ...args) {
    ;(this.events[name] || []).forEach((it) => {
      it.fn(...args)
      if (it.once) this.off(name, it.fn) // once 触发后自动解绑
    })
  }
}
```

### 调用示例

> 示意片段（无配套脚本）

```js
const bus = new EventBus()

bus.on('cart:add', (id) => console.log('收到：', id))
bus.emit('cart:add', 42) // 收到： 42（可触发多次）

bus.once('init', () => console.log('只执行一次'))
bus.emit('init') // 只执行一次
bus.emit('init') // 无输出，once 已自动解绑

const un = bus.on('log', () => console.log('logged'))
un()            // 主动解绑
bus.emit('log') // 无输出
```

### 关键点

- `on` 返回解绑函数，比暴露 `off` 更适合组件卸载时清理。
- `once` 靠条目上的 `once` 标记在 `emit` 时自动摘除；`(this.events[name] ||= [])` 一行完成初始化。

## 柯里化 / compose / pipe

### 思路

- **柯里化**：`fn(a, b, c)` → `fn(a)(b)(c)`，参数收齐才执行，用 `fn.length`（形参个数）判断。
- **compose**：`compose(f, g)(x)` = `f(g(x))`，从右往左；`pipe` 方向相反。

### 代码

> 示意片段（无配套脚本）

```js
function curry(fn) {
  return function curried(...args) {
    if (args.length >= fn.length) return fn.apply(this, args)
    return (...rest) => curried.apply(this, [...args, ...rest])
  }
}

function compose(...fns) {
  return (initValue) => fns.reduceRight((acc, fn) => fn(acc), initValue)
}

function pipe(...fns) {
  return (initValue) => fns.reduce((acc, fn) => fn(acc), initValue)
}
```

### 调用示例

> 示意片段（无配套脚本）

```js
const add = (a, b, c) => a + b + c
console.log(curry(add)(1)(2)(3))  // 6
console.log(curry(add)(1, 2)(3))  // 6，支持分批传参

const add1 = (x) => x + 1
const double = (x) => x * 2
console.log(compose(add1, double)(3)) // 7，先 double 后 add1
console.log(pipe(add1, double)(3))    // 8，先 add1 后 double
```

### 关键点

- `compose` 用 `reduceRight`、`pipe` 用 `reduce`，只差方向。
- 柯里化与偏函数应用（partial application）思想相通，是函数式组合的基础。
