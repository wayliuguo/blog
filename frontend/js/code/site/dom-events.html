③ 解绑的三个手段

{ once: true } 让回调只执行一次；AbortController.signal 可以在组件卸载时一次性解绑挂在它名下的所有监听器，不必逐个记住函数引用。

④ 自定义事件：不依赖框架的组件通信

子元素派发 CustomEvent、祖先监听，detail 携带数据、bubbles: true 让它能冒泡上去——Web Components 与原生组件的通信就建立在这套机制上。

⑤ 程序化触发事件

el.click() 与 el.dispatchEvent(new KeyboardEvent(...)) 可以造出任意交互；差别是后者能带 key、 metaKey、clientX 这些真实属性。
