# 布局

> 级别：初级→中级

布局是 CSS 最核心的实战能力。按本书四层推进：

- **实战**：见 `06-综合实战`；
- **最小实现掌握原理**：到 `code/frontend/02-css` 运行 flex / grid / 居中三个 demo 验证行为。

从最传统的文档流与浮动，到现代主流的 Flex 弹性布局、Grid 网格布局，再到各种经典多栏布局与垂直水平居中方案。读懂本文，你就能独立完成 90% 的页面布局需求。

## 文档流与脱离文档流

### 文档流（Normal Flow）

默认情况下，块级元素（`div`、`p` 等）**自上而下**排布，行内元素（`span`、`a` 等）**从左到右**排布，这就是"文档流"。元素按照出现顺序占据空间，后面的元素自然排在前面元素下方/右侧。

### 脱离文档流

某些定位方式会让元素**不再占据原来的文档位置**，其他元素会"顶上来"，仿佛它凭空消失。常见手段：`position: absolute / fixed` 和 `float`。

| 属性值 | 相对谁定位 | 是否脱离文档流 |
|--------|-----------|----------------|
| `static`（默认） | 无 | 否 |
| `relative` | 自身原本位置 | **否**（仍占位，可偏移） |
| `absolute` | 最近的非 static 祖先 | **是** |
| `fixed` | 浏览器视口 | **是** |
| `sticky` | 滚动容器的视口 | 占位（滚动时吸附） |

```css
/* relative：相对自身偏移，不脱离文档流 */
.box1 {
  position: relative;
  top: 10px;
  left: 20px;
}

/* absolute：相对最近非 static 祖先（常配合父级 relative）*/
.parent {
  position: relative; /* 定位锚点 */
}
.child {
  position: absolute;
  top: 0;
  right: 0; /* 定位到父元素右上角 */
}
```

> 口诀：**」`absolute` 的参照物是最近的非 `static` 的祖先**，没有则相对 `body`/视口。

## float 浮动与清除浮动

`float` 让元素向左或向右"飘"，脱离文档流但保留在文本流上的行为（文本会环绕它），常用于图文混排和早期的多栏布局。

```css
img {
  float: left; /* 或 right */
  margin-right: 12px;
}
```

### 经典问题：父元素高度塌陷

子元素 `float` 后不再占据高度，父元素"撑不起来"，此时需要**清除浮动**。

清除浮动的几种方式：

```css
/* 方式1：父元素触发 BFC（触发方式详见 01 篇，这里只写结论） */
.parent {
  overflow: hidden;
}

/* 方式2：使用 ::after 伪元素清除（经典做法） */
.clearfix::after {
  content: "";
  display: block;
  clear: both;
  /* 兼容写法：
     content: "";
     display: table;
     clear: both; */
}
```

```html
<div class="parent clearfix">
  <div class="child" style="float: left;">左侧</div>
  <div class="child" style="float: right;">右侧</div>
</div>
```

> 现状：`float` 已不再是布局首选，被 Flex/Grid 取代，但理解它仍能读懂历史代码，且图文环绕（文字环绕图片）仍需用到。

## Flex 布局

Flex（Flexible Box，弹性盒）是目前最主流的**一维**（一行或一列）布局方案，垂直水平居中尤其方便。

### 启用与基本主轴方向

```css
.container {
  display: flex;             /* 让子元素进入弹性布局 */
  flex-direction: row;       /* 主轴方向：row 左→右（默认） | column 上→下 | row-reverse | column-reverse */
  flex-wrap: wrap;           /* 是否换行：nowrap（默认）| wrap | wrap-reverse */
  justify-content: center;   /* 主轴对齐 */
  align-items: center;       /* 交叉轴对齐 */
}
```

- **主轴（main axis）**：由 `flex-direction` 决定，`justify-content` 控制其对齐。
- **交叉轴（cross axis）**：与主轴垂直，`align-items` / `align-content` 控制其对齐。

### 容器属性

| 属性 | 作用 |
|------|------|
| `flex-direction` | 主轴方向 |
| `flex-wrap` | 是否换行 |
| `justify-content` | 主轴对齐（start/end/center/space-between/space-around） |
| `align-items` | 交叉轴对齐（stretch 默认/flex-start/center/flex-end/baseline） |
| `align-content` | 多行时的整体对齐（需 wrap 生效） |
| `gap` | 子项间距（一行搞定） |

```css
.container {
  display: flex;
  justify-content: space-between; /* 两端对齐，间距自动分配 */
  align-items: center;            /* 垂直居中 */
  gap: 12px;                      /* 子项间距 12px */
}
```

### 项目（子元素）属性

| 属性 | 作用 |
|------|------|
| `flex` | `flex-grow` `flex-shrink` `flex-basis` 的简写 |
| `flex-grow` | 放大比例，容器有剩余空间时按比例分配 |
| `flex-shrink` | 缩小比例，空间不足时按比例收缩 |
| `flex-basis` | 基础尺寸（主轴方向的初始大小） |
| `order` | 排列顺序，越小越靠前 |
| `align-self` | 覆盖容器的 `align-items` |

```css
/* flex: 简写示例 */
.item-1 { flex: 1; }       /* = flex-grow:1; flex-shrink:1; flex-basis:0% */
.item-2 { flex: 2; }       /* 占两倍空间 */
.item-3 { flex-grow: 1; flex-basis: 200px; } /* 基础 200px，剩余再分配 */
```

> 常用：`flex: 1` 让子项均分剩余空间，`flex: 0 0 auto` 让子项按内容自适应、不缩放。

### 常用居中（横向居中 + 垂直居中）

```css
/* 终极居中大法 */
.center {
  display: flex;
  justify-content: center; /* 水平居中 */
  align-items: center;     /* 垂直居中 */
}
```

## Grid 布局

Grid 是更强大的**二维**布局（同时管行和列），适合整体页面骨架与复杂网格。它与 Flex 的关系：**Flex 管"方向"（一维），Grid 管"网格"（二维）**。

### 基本网格

```css
.grid {
  display: grid;
  grid-template-columns: 100px 100px 100px;  /* 三列，各 100px */
  grid-template-rows: 50px 50px;             /* 两行，各 50px */
  gap: 10px;                                 /* 行列间距 */
}
```

### fr 与 auto 单位

- `fr`（fraction）：**比例单位**，按份数分配剩余空间，类似 Flex 的 grow。
- `auto`：按内容自适应。
- `repeat()`：简化重复写法。

```css
.grid {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;          /* 三列：1:2:1 */
  grid-template-columns: repeat(4, 1fr);        /* 四列等分 */
  grid-template-columns: 200px 1fr;             /* 固定 + 自适应 */
  grid-template-columns: repeat(auto-fill, minmax(120px, 1fr)); /* 响应式自动填充 */
}
```

### 区域定位（grid-area / grid-template-areas）

可以给网格划分**命名区域**，直观地摆放子元素位置：

```html
<style>
  .layout {
    display: grid;
    grid-template-columns: 200px 1fr;
    grid-template-areas:
      "header header"
      "aside  main"
      "footer footer";
    gap: 10px;
  }
  .header { grid-area: header; }
  .aside  { grid-area: aside; }
  .main   { grid-area: main; }
  .footer { grid-area: footer; }
</style>

<div class="layout">
  <header class="header">顶部</header>
  <aside class="aside">侧边栏</aside>
  <main class="main">内容区域</main>
  <footer class="footer">底部</footer>
</div>
```

### 显式定位子项（span）

```css
.item {
  grid-column: 1 / 3;  /* 从第1列到第3列（跨2列） */
  grid-row: 1 / 2;     /* 占第1行 */
}
```

## 经典布局：两栏 / 三栏 / 圣杯 / 双飞翼

### 两栏布局（左侧固定，右侧自适应）

```css
.two-col {
  display: flex;
  gap: 10px;
}
.aside {
  flex: 0 0 200px; /* 固定 200px，不缩放 */
}
.main {
  flex: 1; /* 占满剩余 */
}
```

### 三栏布局（两侧固定，中间自适应）

```css
.three-col {
  display: flex;
  gap: 10px;
}
.left {
  flex: 0 0 200px;
}
.middle {
  flex: 1; /* 中间自适应 */
}
.right {
  flex: 0 0 120px;
}
```

### 圣杯布局（Grail）与双飞翼布局（Double Flying Wing）

两者目的相同：**中间栏优先渲染（先出现在 DOM 中，利于首屏/SEO），且三栏都在同一行、中间自适应、两侧固定**。区别在实现细节。

圣杯布局（利用 padding 与负 margin，把左右栏"缩进"到中间栏两侧）：

```html
<style>
  .container {
    padding: 0 200px 0 150px; /* 左右留出空间放侧栏 */
  }
  .main {
    width: 100%;
    float: left;
  }
  .left {
    width: 150px;
    float: left;
    margin-left: -100%;       /* 拉回到最左 */
    position: relative;
    right: 150px;             /* 移入 container 左内边距区域 */
  }
  .right {
    width: 200px;
    float: right;
    margin-right: -200px;      /* 放进右内边距 */
  }
</style>
<div class="container clearfix">
  <div class="main">中间（DOM 靠前）</div>
  <div class="left">左</div>
  <div class="right">右</div>
</div>
```

双飞翼布局（在 middle 内部再包一层，用 margin 腾出侧栏空间，避免破坏主体高度）：

```html
<style>
  .main-wrap {
    width: 100%;
    float: left;
  }
  .main {
    margin: 0 200px 0 150px; /* 中间内容左右留白 */
  }
  .left {
    width: 150px;
    float: left;
    margin-left: -100%;
  }
  .right {
    width: 200px;
    float: right;
    margin-right: -100%;
  }
</style>
<div class="clearfix">
  <div class="main-wrap">
    <div class="main">中间（内部留白）</div>
  </div>
  <div class="left">左</div>
  <div class="right">右</div>
</div>
```

> **现代简化版**：用 Grid 一行即可实现圣杯效果，中间列优先渲染、自适应，两侧固定：

```css
.grail {
  display: grid;
  grid-template-columns: 150px 1fr 200px;
  grid-template-areas: "left main right";
}
```

高频面试题，重点理解"**中间 DOM 靠前 + 两侧固定 + 中间自适应**"背后的思路即可。

## 垂直水平居中的多种方式

居中是最高频的需求，至少掌握三种：

### 1. Flex（通用、推荐）

```css
.wrap {
  display: flex;
  justify-content: center;
  align-items: center;
}
```

### 2. 绝对定位 + margin: auto（需已知尺寸/定宽）

```css
.wrap {
  position: relative;
}
.child {
  position: absolute;
  top: 0;
  right: 0;
  bottom: 0;
  left: 0;
  margin: auto; /* 配合四条边为0，自动居中 */
}
```

### 3. 绝对定位 + transform 偏移（不知宽高也可用）

```css
.child {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

### 4. 单行文字垂直居中

```css
.line {
  height: 40px;
  line-height: 40px; /* 行高等于高度 */
  text-align: center; /* 文字水平居中 */
}
```

> 性能与易用性：**Flex > transform > margin:auto**；生产环境无脑优先 Flex。

## 布局选型建议

- 整体**页面骨架**用 **Grid**（二维、明确行列）。
- 局部**某一行/某一列**的对齐与分配用 **Flex**。
- 只需简单图文环绕时用 **float**。
- 自适应/响应式界面，Flex + Grid + `minmax` 组合，即可基本替代传统 float 布局。
