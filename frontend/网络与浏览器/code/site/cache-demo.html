提示：maxage 强缓存命中时，浏览器直接取本地副本、不发网络请求，因此服务端计数不会增加； 其余三种每次都会真正发请求（no-cache/ETag/Last-Modified 走协商，服务器说“没变”才回 304）。 ETag/Last-Modified 请连续点击两次，观察「第一次 200 → 第二次 304」。
