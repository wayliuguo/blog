# 学前导览：前端是什么，与如何用好这份体系

> 级别：初级

这是整套前端知识体系的开篇。它不教你写代码，而是先回答三个问题：**前端到底是什么、整个知识体系长什么样、以及你该怎么按顺序用这份文档高效学下去**。读完你能建立一张有重点、可落地的地图，并知道后续每一章在整个体系中的位置。

## 一、前端是什么

前端（Front-end）指用户能直接看到、触摸、交互的那部分内容：浏览器里打开的网页、手机里的 App 界面、微信小程序的页面，其「界面 + 交互 + 视觉反馈」都由前端技术实现。

与之相对是后端（Back-end），负责数据存储、业务逻辑、接口等「看不见却必须存在」的部分。两者通过接口协作，共同组成一个完整 Web 应用。

一句话：**前端负责把数据和逻辑用界面呈现给用户，并让用户顺畅地与之交互。**

## 二、前端能做什么

技术边界一直在扩张。知道「学完能干什么」，你才知道自己为什么学。

| 方向 | 说明 |
| --- | --- |
| 传统网站 / 官网 | 展示型页面、企业官网、博客、后台管理系统 |
| Web 应用 | 电商、社交、办公协作、SaaS 产品 |
| 移动端 | H5 页面、小程序、跨端 App（React Native / Flutter / Taro / uni-app） |
| 桌面应用 | 用前端技术写桌面软件（VS Code、Slack、飞书客户端） |
| 数据可视化 | 图表、大屏、地图（ECharts / D3 / Three.js / WebGL） |
| 服务端渲染与全栈 | 用 Node.js 把 JavaScript 扩展到后端（Next.js / Nuxt） |
| 前端基建 | CLI 工具、脚手架、低代码平台、构建与监控平台 |

## 三、体系总览：一张带「权重」的知识地图

这套体系按「语言 → 框架 → 工程化 → 计算机基础 → 延伸」组织，贯穿全书的目录（`frontend/` 下 0–18 章，配套 90-附录 面试体系）。**权重 ★ 越多，越该先学、越考原理**，是你分配时间的依据。

### 3.1 语言核心（★★★★★ 必须打牢，面试重灾区）
- **HTML**：语义化标签、表单、SEO。
- **CSS**：盒模型、Flex、Grid、响应式、动画、预处理器（Sass/Less）。
- **JavaScript**：ES6+、DOM/BOM、事件、异步（Promise/async await）、闭包、原型、this。→ 全书主力，`03-JavaScript 核心`。
- **TypeScript**：JS 超集加类型，大型项目事实标准。→ `04-TypeScript`。

### 3.2 框架层（★★★★★ 就业主流）
- **React / Vue**：目前国内绝对主流。→ `06/07`。
- **服务端框架**：Next.js / Nuxt（SSR）。
- **状态管理**：Redux / Zustand / Pinia；路由、UI 组件库（Ant Design / Element Plus）。

### 3.3 工程化与构建（★★★★ 规模化必备）
- 包管理器：npm / yarn / pnpm。→ 本册 `02-开发环境与调试` 有最小实现。
- 构建工具：Webpack / Vite / Rollup / ESBuild。→ `13-前端工程化与基建`。
- 版本管理：Git 协作基石。→ 本册 `02`。
- 质量与发布：ESLint / Prettier / 测试 / CI/CD / Docker。

### 3.4 网络与浏览器原理（★★★★ 进阶必考）
- HTTP/HTTPS、缓存、状态码、跨域（CORS）。→ `05-网络与浏览器`。
- 浏览器渲染流程、事件循环、DOM/CSSOM、垃圾回收。
- 浏览器 API：Fetch / XHR / Storage / WebSocket / History。
- 安全：XSS / CSRF / 点击劫持及防御。

### 3.5 性能与质量（★★★ 进阶方向）
- 指标：LCP / INP / CLS / FCP / TTFB。
- 手段：懒加载、代码分割、资源压缩、CDN、缓存、SSR/静态化。
- 监控：错误监控、性能监控、埋点上报。

### 3.6 工程实践与架构（★★★ 资深方向）
- 设计模式；架构演进：模块化 → 组件化 → 微前端。
- 渲染模式：CSR / SSR / SSG / ISR；Monorepo。

> 技术名词很多，但**不必一次吃透**。这张图只作索引——先把 ★ 高的学完、学透，再往里扩充。

## 四、核心能力：决定上限的四件事

技术可慢慢积累，下面四类能力决定你的上限，建议第一天就刻意培养：

1. **扎实语言基础**：ES6+、异步、闭包、原型链，是面试和实战重灾区。
2. **调试与排查**：会用 DevTools、会看网络请求、会打断点、会读堆栈，把「现象」翻译成「根因」。这是会不会干活的分水岭。
3. **工程化与协作**：写能维护、能扩展、能多人协作的代码（Git、规范、组件与模块设计）。
4. **持续学习与抽象**：技术更新快，学习力即生产力；把业务抽象成结构与组件，是资深与初级的分界。

## 五、学习路径：按目录顺序 = 由浅入深主线

这套目录本身就是你的学习主线，**无需另找路线**。它按「入门使用 → 进阶 → 实战 → 最小实现掌握原理」组织每一章，其中：

- **入门使用**：能跑起来、会用即可。
- **进阶**：深入语法与常见坑。
- **实战**：串成能上线的项目闭环。
- **最小实现掌握原理**：用几十行代码手写一个最小版，真正理解它「为什么这样工作」。非每节都需要，会结合 90-附录面试体系取舍。

建议顺序：`00 环境` → `01 HTML/CSS` → `03 JavaScript` → `04 TypeScript` → `05 网络/浏览器` → 一个框架（`06/07`）→ 工程化 → 延伸。每章末的知识卡片与附录面试自测，就是你的「脱稿检验」。

> **判断「掌握」的标准不是看过，而是「能否脱稿讲清 + 独立写出来」。** 每学完一块，做一个迷你项目验证。

### 常见避坑
- 别收藏成瘾、拖延动手；
- 别过早追高级框架、忽视语言基础；
- 别只抄不写、只读不思；
- 别贪多，一阶段吃透一块。

## 六、就业方向（按能力侧重选定位）

| 阶段 / 方向 | 岗位常见名 | 侧重能力 |
| --- | --- | --- |
| 初中级（0-2 年） | 前端开发工程师 | 语言基础、框架使用、调试、Git |

关于「35 岁焦虑 / 前端饱和论」：前端入门门槛不高，竞争激烈是事实，但 **竞争激烈 ≠ 没有机会**——原理扎实、有工程经验者始终稀缺。别被焦虑带走，把精力放在「打牢基础 + 持续输出作品」上即可。
