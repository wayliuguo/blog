## 一、为什么需要原型与继承

面向对象编程强调"复用"。在 JavaScript 中，复用对象能力的方式不是传统类继承，而是通过**原型链（Prototype Chain）**实现的。理解原型与继承，是理解"函数是对象""new 怎么工作""类语法本质是什么""instanceof 怎么判断"等一系列问题的基石。

JavaScript 号称"万物皆对象"，但更准确地说：JavaScript 是一个**基于原型（Prototype-based）**的语言——对象通过一条指向"原型对象"的链，从别的对象那里继承属性和方法。

## 二、三件套：prototype / `__proto__` / constructor

这是最令初学者头大的三角关系，先记下三个关键词：

| 名称            | 谁拥有            | 作用                                                   |
| --------------- | ----------------- | ------------------------------------------------------ |
| `prototype`     | **函数**独有       | 由 `new` 创建出来的实例，其隐式原型指向这个对象         |
| `__proto__`     | **对象**独有       | 指向该对象的原型（一个对象内部属性 `[[Prototype]]`）    |
| `constructor`   | 在 `prototype` 上 | 指回函数本身，形成闭环                                 |

### 1. prototype（显式原型）

只有**函数**才有 `prototype` 属性。它指向一个对象，这个对象会成为"由这个函数 `new` 出来的所有实例"的公共祖先。

```js
function Person(name) {
  this.name = name;
}

Person.prototype.sayHello = function () {
  console.log(`你好，我是 ${this.name}`);
};

const p1 = new Person("张三");
p1.sayHello(); // 你好，我是 张三
```

### 2. `__proto__`（隐式原型）

每个**对象**都有一个 `__proto__`，指向创建它的函数的 `prototype`（一个对象 instanceof 构造该对象的构造函数的原型）。它构成了原型链的"链"。

```js
function Person() {}
const p = new Person();

console.log(p.__proto__ === Person.prototype); // true
console.log(Person.prototype.__proto__ === Object.prototype); // true
console.log(Object.prototype.__proto__); // null，原型链的终点
```

> 说明：`__proto__` 是历史上浏览器暴露出来的非标准属性，现在更推荐用 `Object.getPrototypeOf()` 读取。它只是对象内部的 `[[Prototype]]` 的"窗户"。

### 3. constructor

每个函数的 `prototype` 对象上默认带有一个 `constructor` 属性，指回这个函数本体。

```js
function Person() {}
console.log(Person.prototype.constructor === Person); // true

const p = new Person();
// 实例本身没有 constructor，是通过原型链访问到的
console.log(p.constructor === Person); // true
```

### 4. 完整关系图（文本版）

```js
Person                           Person.prototype                      p (实例)
 |   ┌────────────────────────┐     ┌───────────────────────────────┐
 |   │ construct a object     │     │  constructor: Person ────────┼──┐
 └───┤ new Person() ──────────┼────▶│  sayHello: function           │  │
     └────────────────────────┘     │  __proto__: Object.prototype◀─┼──┼────────┐
                                    └───────────────────────────────┘  │        │
                                                                       │        │
                                p.__proto__ === Person.prototype ──────┘        │
                                Person.prototype.__proto__ === Object.prototype ┘
```

总结三角关系：

- 实例 `p` 的 `__proto__` === 构造函数 `Person` 的 `prototype`。
- `Person.prototype.constructor === Person`。
- `p.constructor` 是通过原型链找到的 `Person.prototype.constructor`。

## 三、原型链（Prototype Chain）

**原型链**就是对象沿着 `__proto__` 一层层向上直到 `null` 的链条。当访问一个对象的属性时，引擎先查对象自身，找不到就沿着 `__proto__` 向父级找，直到 `Object.prototype`（它自己的 `__proto__` 为 `null`，到此结束）。

```js
function Animal(name) {
  this.name = name;
}
Animal.prototype.eat = function () {
  console.log(`${this.name} 在吃`);
};

function Dog(name) {
  Animal.call(this, name); // 借用构造函数
}
Dog.prototype = Object.create(Animal.prototype); // 让 Dog 的原型链接上 Animal
Dog.prototype.constructor = Dog;
Dog.prototype.bark = function () {
  console.log(`${this.name} 在叫`);
};

const dog = new Dog("旺财");
dog.eat();  // 旺财 在吃（继承自 Animal.prototype）
dog.bark(); // 旺财 在叫（Dog 自己的）
```

属性查找路径：

```js
dog 自身 → Dog.prototype → Animal.prototype → Object.prototype → null
```

- `dog.__proto__` → `Dog.prototype`
- `Dog.prototype.__proto__` → `Animal.prototype`
- `Animal.prototype.__proto__` → `Object.prototype`
- `Object.prototype.__proto__` → `null`

用 `hasOwnProperty` 区分"自身属性"与"继承属性"：

```js
console.log(Object.prototype.hasOwnProperty.call(dog, "name")); // true，自身
console.log(Object.prototype.hasOwnProperty.call(dog, "eat"));  // false，继承
```

## 四、new 的过程

使用 `new` 创建一个实例时，JS 引擎会做四件事：

1. 创建一个新对象。
2. 让这个新对象的 `__proto__` 指向构造函数的 `prototype`。
3. 以这个新对象为 `this`，执行构造函数（给新对象加属性）。
4. 若构造函数返回对象，则返回该对象；否则返回新对象。

```js
function Person(name, age) {
  this.name = name;
  this.age = age;
}

const p = new Person("李四", 25);
```

可以手动实现一个 `myNew`：

```js
function myNew(Ctor, ...args) {
  // 1. 创建空对象并让它的原型指向 Ctor.prototype
  const obj = Object.create(Ctor.prototype);
  // 2. 以 obj 为 this 执行构造函数
  const result = Ctor.apply(obj, args);
  // 3. 如果构造函数返回了对象，返回那个对象；否则返回新对象
  return (result !== null && typeof result === "object") ? result : obj;
}

const p2 = myNew(Person, "王五", 30);
console.log(p2.name);    // 王五
console.log(p2 instanceof Person); // true
```

## 五、Object.create

`Object.create(proto)` 创建一个新对象，并将其 `__proto__` 指向传入的 `proto`。当传入 `null` 时，会得到一个没有任何原型的纯净对象。

```js
const base = { type: "animal" };
const child = Object.create(base);
console.log(child.type);          // animal，继承自 base
console.log(child.__proto__ === base); // true

// 没有任何原型的对象（真正的"最干净"的对象）
const pure = Object.create(null);
console.log(pure.toString);       // undefined，连 toString 都没有
```

`Object.create` 是实现"寄生式/原型链式继承"的核心工具，因为它可以精确地指定一个对象的原型。

## 六、ES6 class 语法

`class` 是 ES6 提供的**语法糖**，底层仍是原型机制，但让继承写起来更清晰。它包含构造器、方法、静态方法、`getter`/`setter` 等。

```js
class Animal {
  constructor(name) {
    this.name = name;
  }
  eat() {
    console.log(`${this.name} 在吃`);
  }
  // 静态方法挂载在类本身，不挂原型
  static isAnimal(x) {
    return x instanceof Animal;
  }
}

class Dog extends Animal {
  constructor(name, breed) {
    super(name);   // 必须先调用 super 再使用 this
    this.breed = breed;
  }
  barking() {
    super.eat();   // 可调用父类方法
    console.log(`${this.name} 在叫`);
  }
}
```

`class` 与普通函数构造的区别：

- `class` 内部默认是严格模式。
- `class` 的方法不可枚举、不可被 `new` 误用之外的方式调用。
- `class` 声明存在类似于 `let` 的 TDZ，且**不能直接调用**（必须 `new`）。
- 继承用 `extends` + `super()`，本质上是 `Object.setPrototypeOf` 做完原型接线后再执行父构造。

```js
const dog = new Dog("旺财", "金毛");
dog.barking(); // 旺财 在吃 \n 旺财 在叫
console.log(Dog.isAnimal(dog)); // true
```

## 七、继承方式的演进

这一节梳理 JS 继承从早期到现代的演变，理解每一步解决了什么问题。

### 1. 原型链继承（最原始）

让子类的 `prototype` 直接指向父类的实例。

```js
function Parent() {
  this.colors = ["red"];
}
function Child() {}
Child.prototype = new Parent();

const c1 = new Child();
const c2 = new Child();
c1.colors.push("blue");
console.log(c2.colors); // ["red","blue"] —— 共享了引用，有缺陷！
```

**问题**：所有实例共享父类的引用类型属性（如数组），一个实例修改会波及所有实例。

### 2. 借用构造函数继承

在子类构造函数里调用父类构造函数，把父类属性复制到实例上，解决共享引用问题。

```js
function Parent(name) {
  this.name = name;
}
function Child(name) {
  Parent.call(this, name); // 借用，复制父类实例属性
}
const c = new Child("张三");
console.log(c.name); // 张三
```

**问题**：无法继承父类 `prototype` 上的方法，方法无法复用。

### 3. 组合继承（最常用经典方案）

原型链 + 借用构造的组合，既复制属性又复用方法。

```js
function Parent(name) {
  this.name = name;
  this.colors = ["red"];
}
Parent.prototype.say = function () {
  console.log(this.name);
};

function Child(name, age) {
  Parent.call(this, name); // 第二次：复制属性
  this.age = age;
}
Child.prototype = new Parent(); // 第一次：接上原型链
Child.prototype.constructor = Child;

const c = new Child("李四", 20);
c.colors.push("blue");
console.log(c.colors); // ["red","blue"]，独立
c.say(); // 李四
```

**小问题**：父类构造函数被调用了两次，父类属性会出现在实例上与原型上各一份（冗余）。

### 4. 寄生组合继承（目前最优）

用 `Object.create` 让子类的原型直接以父类原型为原型，避免重复调用父类构造函数。

```js
function inherit(Child, Parent) {
  Child.prototype = Object.create(Parent.prototype);
  Child.prototype.constructor = Child;
}

function Parent(name) {
  this.name = name;
}
Parent.prototype.say = function () {
  console.log(this.name);
};

function Child(name, age) {
  Parent.call(this, name); // 只调用一次
  this.age = age;
}
inherit(Child, Parent);

const c = new Child("王五", 18);
c.say(); // 王五
console.log(c instanceof Parent); // true
```

这一步的核心：`Object.create(Parent.prototype)` 创建了一个以父类原型为原型的对象，把它当作子类原型，既接上了链又不会触发父类构造函数，属性和方法也不冗余。**这恰好是 ES6 `extends` 在底层做的事**。

### 5. 演进总结

| 方式         | 解决问题                               | 遗留问题                 |
| ------------ | -------------------------------------- | ------------------------ |
| 原型链继承   | 能继承属性和方法                       | 引用共享；无法传参       |
| 借用构造函数 | 解决实例属性隔离、可传参               | 无法复用原型方法         |
| 组合继承     | 属性和方法都完美复用                   | 父类构造函数调用两次     |
| 寄生组合继承 | 组合继承的所有问题，属性方法无冗余     | 底层方案（class 采用它） |

## 八、instanceof 原理

`a instanceof B` 的本质是：**判断 `B.prototype` 是否出现在 `a` 的原型链（`a.__proto__` 一路向上）中**。

```js
console.log(dog instanceof Dog);     // true，Dog.prototype 在链上
console.log(dog instanceof Animal);  // true，Animal.prototype 也在链上
console.log(dog instanceof Object);  // true，Object.prototype 更在链上
console.log(dog instanceof Array);   // false，Array.prototype 不在链上
```

手动实现 `instanceof`：

```js
function myInstanceOf(instance, Ctor) {
  let proto = Object.getPrototypeOf(instance); // 从实例的原型开始
  const prototype = Ctor.prototype;
  while (proto !== null) {
    if (proto === prototype) return true;
    proto = Object.getPrototypeOf(proto);
  }
  return false;
}

console.log(myInstanceOf(new Date(), Date)); // true
```

注意：`instanceof` 只对引用类型有意义，`1 instanceof Number` 为 `false`，因为基本类型没有原型链。想判断基本类型要用 `typeof`。

## 九、总结要点

- 三个核心概念：函数的 `prototype`、对象的 `__proto__`、原型上的 `constructor` 构成三角闭环。
- 原型链是沿着 `__proto__` 从实例通向 `Object.prototype` 再到 `null` 的查找链条，属性查找沿链向上。
- `new` 四步：建对象 → 接原型 → 绑 this 执行 → 返回对象。
- `Object.create` 精确指定原型，是寄生组合继承与继承谱系的核心工具。
- `class` / `extends` 只是寄生组合继承的语法糖，底层仍是原型。
- 继承演进：原型链 → 借用构造 → 组合 → 寄生组合，寄生组合是最优底层方案。
- `instanceof` 判断 `构造函数的 prototype` 是否在实例的原型链上，可手动实现。
