## call / apply / bind

### 思路

三者都用于「显式指定函数的 `this`」：

- `call(fn, thisArg, ...args)`：立即调用，参数逐个传入
- `apply(fn, thisArg, argsArray)`：立即调用，参数以数组传入
- `bind(fn, thisArg, ...args)`：返回一个新函数，调用时才执行，且 `this` 永久锁定，可继续传参

核心原理：**谁调用函数，`this` 就指向谁**。只要把目标函数临时挂到 `thisArg` 上再调用，就能借机改变 `this`。用 `Symbol` 做 key，避免覆盖 `thisArg` 上原本的同名属性。

### 代码

```js
Function.prototype.myCall = function (thisArg, ...args) {
  // 传 null / undefined 时指向全局对象
  thisArg = thisArg ?? (typeof window !== 'undefined' ? window : globalThis)
  thisArg = Object(thisArg) // 基本类型包装为对象
  const key = Symbol('fn') // 用 Symbol 避免与原有属性冲突
  thisArg[key] = this
  const result = thisArg[key](...args)
  delete thisArg[key] // 用完删掉，不留痕迹
  return result
}

Function.prototype.myApply = function (thisArg, args) {
  thisArg = thisArg ?? (typeof window !== 'undefined' ? window : globalThis)
  thisArg = Object(thisArg)
  const key = Symbol('fn')
  thisArg[key] = this
  const result = Array.isArray(args)
    ? thisArg[key](...args)
    : thisArg[key]() // apply 第二个参数必须传数组，不传则当成无参
  delete thisArg[key]
  return result
}

Function.prototype.myBind = function (thisArg, ...boundArgs) {
  thisArg = thisArg ?? (typeof window !== 'undefined' ? window : globalThis)
  const fn = this
  return function BoundFn(...callArgs) {
    // 合并初始化参数和调用时参数；也可以额外支持 new 调用
    return fn.apply(thisArg, [...boundArgs, ...callArgs])
  }
}
```

### 关键点

- **`this` 指向原理**：函数必须作为某个对象的方法调用，`this` 才指向该对象。临时挂载就是利用这一点。
- **兼容基本类型**：`thisArg` 传数字/字符串时用 `Object()` 包装成对象，防止读取属性报错（严格模式下不包装会更复杂）。
- **`null`/`undefined`**：非严格模式下指向全局对象（`window`/`globalThis`）。

## new

### 思路

`new` 做了四件事：创建空对象 → 把空对象的原型指向构造函数的 `prototype` → 以该对象为 `this` 执行构造函数 → 若构造函数返回对象则用返回值，否则返回这个新对象。

### 代码

```js
function myNew(Constructor, ...args) {
  // 1. 创建空对象，并把其原型指向构造函数的 prototype
  const obj = Object.create(Constructor.prototype)
  // 2. 以 obj 为 this 执行构造函数
  const result = Constructor.apply(obj, args)
  // 3. 如果构造函数返回了引用类型，则用返回值；否则返回新对象
  return (typeof result === 'object' && result !== null) || typeof result === 'function'
    ? result
    : obj
}

// 使用
function Person(name, age) {
  this.name = name
  this.age = age
}
Person.prototype.greet = function () {
  return `hello, ${this.name}`
}
const p = myNew(Person, '张三', 18)
console.log(p.greet()) // hello, 张三
```

### 关键点

- `Object.create(Constructor.prototype)` 同时完成了「建对象 + 连原型」两步。
- **返回值判断**：只有构造函数显式返回**对象或函数**（引用类型）才会覆盖新对象；返回原始类型（数字/字符串）则忽略，仍返回 `obj`。

## 深拷贝与浅拷贝

### 思路

- **浅拷贝**：只拷贝第一层属性。引用类型属性新老对象仍共享同一引用，改一个影响另一个。
- **深拷贝**：递归拷贝所有层级，得到完全独立的对象。

常用深浅拷贝手段：

| 方法 | 类型 | 局限 |
| --- | --- | --- |
| 展开运算符 `{...obj}` / `Object.assign` | 浅 | 仅一层 |
| `Array.prototype.slice/concat` | 浅 | 仅数组一层 |
| `JSON.parse(JSON.stringify())` | 深 | 丢函数、`undefined`、`Symbol`、`Date`、`RegExp`、循环引用报错 |
| 递归手写 | 深 | 需自行处理各种边界 |

下面手写一个健壮的深拷贝。

### 代码

```js
function deepClone(target, map = new WeakMap()) {
  // 原始类型直接返回
  if (target === null || typeof target !== 'object') return target

  // 处理循环引用：已拷贝过的直接返回缓存
  if (map.has(target)) return map.get(target)

  // 处理日期和正则（有自己的内部槽，不能按普通对象递归）
  if (target instanceof Date) return new Date(target)
  if (target instanceof RegExp) return new RegExp(target.source, target.flags)

  // 处理数组 / 对象。isArray 放前面保证数组得到数组
  const clone = Array.isArray(target) ? [] : {}

  map.set(target, clone)

  // 拷贝普通键
  Reflect.ownKeys(target).forEach((key) => {
    clone[key] = deepClone(target[key], map)
  })
  return clone
}

// 测试
const obj = {
  name: '张三',
  tags: ['a', 'b'],
  meta: { level: 1 },
  when: new Date(),
  [Symbol('s')]: 'symbolValue',
  reg: /abc/gi,
}
// 制造循环引用
obj.self = obj
const copy = deepClone(obj)
console.log(copy.meta === obj.meta) // false，独立
console.log(copy.self === copy) // true，循环引用被正确重建
```

### 关键点

- **循环引用**：用 `WeakMap` 记录「原对象 → 拷贝对象」的映射，遇到已拷贝的返回缓存，避免无限递归栈溢出。
- **`Symbol`**：`for...in` 和 `Object.keys` 都拿不到 `Symbol` 属性，必须用 `Reflect.ownKeys`（同时含字符串键和符号键）。
- **`Date` / `RegExp`**：不能被当作普通对象递归（内部有特殊槽），需单独 `new` 一份。
- **保留原型**：更完整的实现还应处理 `Map/Set`、`Object.getPrototypeOf` 等，面试时可先讲清主体再补强。

## instanceof

### 思路

`a instanceof B` 判断 `B.prototype` 是否出现在 `a` 的原型链上。原理就是沿着 `.__proto__`（即 `Object.getPrototypeOf`）一路向上找，直到找到相等，或走到 `null`（到顶没找到返回 false）。

### 代码

```js
function myInstanceof(left, right) {
  let proto = Object.getPrototypeOf(left) // 相当于 left.__proto__
  const prototype = right.prototype // 要匹配的目标原型
  while (true) {
    if (proto === null) return false // 走到原型链顶端还没找到
    if (proto === prototype) return true
    proto = Object.getPrototypeOf(proto) // 继续向上
  }
}

// 测试
console.log(myInstanceof([], Array)) // true
console.log(myInstanceof([], Object)) // true（数组也是对象）
console.log(myInstanceof({}, Array)) // false
function Foo() {}
const f = new Foo()
console.log(myInstanceof(f, Foo)) // true
```

### 关键点

- 左侧是实例对象，右侧必须是「有 `prototype` 的构造函数」。
- `Object.create(null)` 产生的对象原型为 `null`，用 `instanceof` 会得到 `false`。
- 循环用 `while(true) + return`，比递归更直观。

## Promise 与 Promise.all / race / allSettled

### 思路

`Promise` 有 `pending / fulfilled / rejected` 三种状态，**状态一旦变更不可逆**。核心是四部分：

1. 构造函数接收 `executor(resolve, reject)`，被调用时立即执行。
2. 维护 `state`、`value`、`reason` 以及回调队列。
3. `.then` 返回新的 Promise（实现链式调用），并把回调放入微任务（这里用 `queueMicrotask` 模拟）。
4. 状态已确定时回调也要异步执行（保证时序正确）。

### 代码

```js
const PENDING = 'pending'
const FULFILLED = 'fulfilled'
const REJECTED = 'rejected'

class MyPromise {
  constructor(executor) {
    this.state = PENDING
    this.value = undefined
    this.reason = undefined
    this.onFulfilledCallbacks = []
    this.onRejectedCallbacks = []

    const resolve = (value) => {
      if (this.state !== PENDING) return
      this.state = FULFILLED
      this.value = value
      this.onFulfilledCallbacks.forEach((fn) => fn())
    }
    const reject = (reason) => {
      if (this.state !== PENDING) return
      this.state = REJECTED
      this.reason = reason
      this.onRejectedCallbacks.forEach((fn) => fn())
    }
    try {
      executor(resolve, reject)
    } catch (err) {
      reject(err)
    }
  }

  then(onFulfilled, onRejected) {
    onFulfilled = typeof onFulfilled === 'function' ? onFulfilled : (v) => v
    onRejected =
      typeof onRejected === 'function'
        ? onRejected
        : (r) => {
            throw r
          }

    return new MyPromise((resolve, reject) => {
      const run = (task, val) => {
        queueMicrotask(() => {
          try {
            const result = task(val)
            // 如果返回的是 Promise，则等待其决议后再 resolve
            if (result instanceof MyPromise) {
              result.then(resolve, reject)
            } else {
              resolve(result)
            }
          } catch (err) {
            reject(err)
          }
        })
      }

      if (this.state === FULFILLED) run(onFulfilled, this.value)
      else if (this.state === REJECTED) run(onRejected, this.reason)
      else {
        // pending：先入队
        this.onFulfilledCallbacks.push(() => run(onFulfilled, this.value))
        this.onRejectedCallbacks.push(() => run(onRejected, this.reason))
      }
    })
  }

  catch(onRejected) {
    return this.then(null, onRejected)
  }

  static resolve(v) {
    if (v instanceof MyPromise) return v
    return new MyPromise((resolve) => resolve(v))
  }

  static reject(r) {
    return new MyPromise((_, reject) => reject(r))
  }
}
```

#### 静态方法：all / race / allSettled / any

```js
// all：全部成功才成功，一个失败立即失败
MyPromise.myAll = function (promises) {
  return new MyPromise((resolve, reject) => {
    const results = []
    let count = 0
    promises.forEach((p, i) => {
      MyPromise.resolve(p).then(
        (val) => {
          results[i] = val // 用索引放，保证顺序
          if (++count === promises.length) resolve(results)
        },
        reject
      )
    })
  })
}

// race：谁先出结果用谁
MyPromise.myRace = function (promises) {
  return new MyPromise((resolve, reject) => {
    promises.forEach((p) => MyPromise.resolve(p).then(resolve, reject))
  })
}

// allSettled：全部结束，各自返回 {status, value|reason}，永不 reject
MyPromise.myAllSettled = function (promises) {
  return new MyPromise((resolve) => {
    const results = []
    let count = 0
    promises.forEach((p, i) => {
      MyPromise.resolve(p).then(
        (value) => {
          results[i] = { status: 'fulfilled', value }
          if (++count === promises.length) resolve(results)
        },
        (reason) => {
          results[i] = { status: 'rejected', reason }
          if (++count === promises.length) resolve(results)
        }
      )
    })
  })
}

MyPromise.prototype.finally = function (callback) {
  return this.then(
    (val) => MyPromise.resolve(callback()).then(() => val),
    (err) =>
      MyPromise.resolve(callback()).then(() => {
        throw err
      })
  )
}
```

### 关键点

- **状态单向不可逆**：`resolve`/`reject` 前先判断 `state !== PENDING` 直接忽略后续。
- **值穿透**：`.then` 若没传回调，要补默认回调，否则结果传不往下传。
- **返回 Promise 的链式处理**：`run` 里判 `result instanceof MyPromise`，保证可等待内层 Promise。
- **异步特性**：回调放 `queueMicrotask`，确保 `.then` 注册时序正确、模拟"Promise 永远异步"。
- `all` 用**下标**存结果而非 `push`，保证输出顺序与输入一致；用 `count` 计数避免依赖 `promises.length` 之外的时序。

## 防抖 debounce / 节流 throttle

### 思路

- **防抖 debounce**：事件触发后，等待 `delay` 毫秒再执行；期间再次触发则**重置倒计时**。适合「搜索输入、窗口 resize」——最后一次才生效。
- **节流 throttle**：固定时间间隔内**最多执行一次**。适合「滚动、点击」——控制频率。

### 代码

```js
// 防抖：最后一次触发延迟执行，支持立即执行选项
function debounce(fn, delay = 300, immediate = false) {
  let timer = null
  return function (...args) {
    const context = this
    // immediate：第一次立即执行，之后在 delay 内不执行
    if (immediate && !timer) {
      fn.call(context, ...args)
    }
    clearTimeout(timer)
    timer = setTimeout(() => {
      fn.call(context, ...args)
      timer = null
    }, delay)
  }
}

// 节流：时间戳版（首次立即执行，最后一次可能被忽略）
function throttle(fn, delay = 300) {
  let last = 0
  return function (...args) {
    const now = Date.now()
    if (now - last >= delay) {
      last = now
      fn.apply(this, args)
    }
  }
}

// 节流：定时器版（delay 后执行，保证最后一次也执行、保证间隔）
function throttleTimer(fn, delay = 300) {
  let timer = null
  return function (...args) {
    if (!timer) {
      timer = setTimeout(() => {
        fn.apply(this, args)
        timer = null
      }, delay)
    }
  }
}
```

### 关键点

- 两个实现都一定要**保存 `this` 和 `...args`**，否则防抖/节流后的函数会丢掉上下文和参数。
- 防抖灵魂是 `clearTimeout` 重置；节流灵魂是「有 timer 就拦截」或「时间差判断」。
- 时间戳版与定时器版各有取舍，面试可点出「首次/末尾是否执行」的差异。

## 发布订阅 EventBus

> 可结合源笔记 `article/eventbus.md`。发布订阅 = 事件管理中枢：多个模块 `subscribe` 订阅事件，别的模块 `emit` 发布事件，事件总线把参数透传给所有订阅回调。关键设计：`eventName` 下挂一个对象，以 `callbackId` 为键存回调，这样就能按 id 精确取消订阅。

### 思路

1. `eventMap`：`{ eventName: { callbackId: callback } }`。
2. `subscribe`：订阅一次可触发多次；返回 `{ unSubscribe }` 用于取消。
3. `subscribeOne`：订阅后 **once**，触发一次即自动移除（实现上用 `one${callbackId}` 前缀标记）。
4. `emit(eventName, ...args)`：遍历回调执行，若 id 以 `one` 开头则执行后删除。
5. `clear / clearAll`：清空某事件 / 全部。

### 代码

```js
class EventBus {
  constructor(maxListeners) {
    this.eventMap = {}               // 事件 → 回调集合
    this.maxListeners = maxListeners || Infinity
    this.callbackId = 0
  }

  // 订阅（可多次触发）
  subscribe(eventName, funCallback) {
    if (!Reflect.has(this.eventMap, eventName)) {
      Reflect.set(this.eventMap, eventName, {})
    }
    if (Object.keys(this.eventMap[eventName]).length >= this.maxListeners) {
      console.warn(`事件 ${eventName} 超过最大监听数`)
    }
    const thisCallbackId = this.callbackId++
    this.eventMap[eventName][thisCallbackId] = funCallback

    const unSubscribe = () => {
      delete this.eventMap[eventName][thisCallbackId]
      if (Object.keys(this.eventMap[eventName]).length === 0) {
        delete this.eventMap[eventName] // 没有回调了就清理整个事件
      }
    }
    return { unSubscribe }
  }

  // 订阅一次（触发一次后自动移除）
  subscribeOne(eventName, funCallback) {
    if (!Reflect.has(this.eventMap, eventName)) {
      Reflect.set(this.eventMap, eventName, {})
    }
    const theCallbackId = `one${this.callbackId++}` // 用前缀标记 once
    this.eventMap[eventName][theCallbackId] = funCallback
    return {
      unSubscribe: () => delete this.eventMap[eventName][theCallbackId],
    }
  }

  // 发布
  emit(eventName, ...args) {
    const callbackList = this.eventMap[eventName]
    if (!callbackList) {
      console.warn(`从未订阅过此事件 ${eventName}`)
      return
    }
    for (const [id, callback] of Object.entries(callbackList)) {
      callback.call(this, ...args)
      if (id.startsWith('one')) delete callbackList[id] // once 用完即删
    }
  }

  // 清空某个事件
  clear(eventName) {
    delete this.eventMap[eventName]
  }

  // 清空所有事件
  clearAll() {
    this.eventMap = {}
  }
}

// 测试
const bus = new EventBus(2)
const f1 = function () {
  console.log('111', ...arguments)
}
bus.subscribe('A', f1)
bus.emit('A', '参数1') // 111 参数1
bus.emit('A', '参数1') // 111 参数1  （subscribe 可多次）

bus.subscribeOne('B', function () {
  console.log('444')
})
bus.emit('B') // 444
bus.emit('B') // 事件 B 无回调（once 已移除）

const { unSubscribe } = bus.subscribe('C', () => console.log('ccc'))
unSubscribe()
bus.emit('C') // 从未订阅过此事件 C？
```

### 关键点

- 用**对象**而非数组存回调，天然支持按 `callbackId` 精确删除。
- `once` 用 `one${id}` 前缀标记，`emit` 时通过 `id.startsWith('one')` 判断并删除，十分巧妙。
- 订阅清理时，若某事件下已无回调，把整个 `eventName` 删掉，避免空对象堆积。

## 柯里化 / 函数式 compose

### 思路

- **柯里化 curry**：把「接收多个参数的函数」转换成「每次只接收一个参数、返回接收下一参数的新函数」，直到参数收齐才真正执行。`fn(a, b, c)` → `fn(a)(b)(c)`。
- **compose**：函数组合，`compose(f, g)(x)` 等价于 `f(g(x))`，从右往左执行，常用于「洋葱模型中间件 / 管道的反向」。
- **pipe**：与 compose 方向相反，从左往右。

### 代码

```js
// 柯里化：不限定一次只传一个，支持分批传参
function curry(fn) {
  return function curried(...args) {
    // 参数够了，直接执行
    if (args.length >= fn.length) {
      return fn.apply(this, args)
    }
    // 参数不够，返回一个继续接收剩余参数的新函数
    return (...rest) => curried.apply(this, [...args, ...rest])
  }
}

const add = (a, b, c) => a + b + c
const curriedAdd = curry(add)
console.log(curriedAdd(1)(2)(3)) // 6
console.log(curriedAdd(1, 2, 3)) // 6
console.log(curriedAdd(1)(2, 3)) // 6

// compose：从右往左，f(g(x))
function compose(...fns) {
  // 至少要一个函数
  return function (initValue) {
    return fns.reduceRight((acc, fn) => fn(acc), initValue)
  }
}

// pipe：从左往右，g(f(x))，跟 compose 相反
function pipe(...fns) {
  return function (initValue) {
    return fns.reduce((acc, fn) => fn(acc), initValue)
  }
}

const add1 = (x) => x + 1
const double = (x) => x * 2
console.log(compose(add1, double)(3)) // add1(double(3)) = 7
console.log(pipe(add1, double)(3)) // double(add1(3)) = 8
```

### 关键点

- 柯里化核心用 `fn.length`（函数形参个数）判断「参数是否收齐」。
- `compose` 用 `reduceRight`、`pipe` 用 `reduce`，方向相反。
- 柯里化让「逐步提供参数」成为可能，与函数式偏函数应用（partial application）思想相通。

## JSON.stringify 简单模拟（可选）

### 思路

`JSON.stringify` 是一个强大的序列化工具。手写一个简化版，重点掌握其**转换规则**：

- `undefined`、函数、`Symbol` 作为属性值 → 忽略（数组里则变成 `null`）。
- `null`、`NaN`、`Infinity` → `null`。
- 字符串要加双引号并转义。
- 数组 → `[v1,v2,...]`；对象 → 非空才加 `{}`，键必须用双引号。
- 循环引用需要 `WeakSet` 检测，否则报错。

### 代码

```js
function myStringify(value, seen = new WeakSet()) {
  // 原始类型与基础处理
  if (value === null) return 'null'
  if (typeof value === 'number' || typeof value === 'boolean') {
    return String(value === Infinity || Number.isNaN(value) ? null : value)
  }
  if (typeof value === 'string') return `"${value}"`
  if (typeof value === 'undefined' || typeof value === 'function' || typeof value === 'symbol') {
    return undefined // 顶层这些值返回 undefined
  }

  // 循环引用检测
  if (seen.has(value)) throw new TypeError('Converting circular structure to JSON')

  if (Array.isArray(value)) {
    seen.add(value)
    const arr = value.map((item) => {
      const s = myStringify(item, seen)
      return s === undefined ? 'null' : s // 数组里 undefined/函数 → null
    })
    seen.delete(value)
    return `[${arr.join(',')}]`
  }

  // 普通对象
  seen.add(value)
  const parts = Object.entries(value)
    .filter(([, v]) => !(v === undefined || typeof v === 'function' || typeof v === 'symbol'))
    .map(([k, v]) => `"${k}":${myStringify(v, seen)}`)
  seen.delete(value)
  return parts.length ? `{${parts.join(',')}}` : '{}'
}
```

### 关键点

- 关键词或属性值出现 `undefined`/`函数`/`Symbol` 时不同场景规则不同（对象忽略、数组 `null`、顶层 `undefined`），这是最容易考到的坑。
- 用 `WeakSet` 记录「正在序列化的对象」，检测到回环就抛错。
- 这只是简化版，真正的 `JSON.stringify` 还处理 `Date`（转字符串）、`toJSON` 钩子等，理解规则即可。

## 数组去重 / 扁平化 / 深浅合并

### 思路

- **去重**：`Set` 一行搞定；保序用 `filter + indexOf`；对象数组去重需要自定义 key。
- **扁平化**：`flat(Infinity)` 一行；手写用递归，可选利用栈迭代。
- **深浅合并**：浅合并覆盖一层；深合并递归合并嵌套对象/数组（类似 `Object.assign` 的递归版、`lodash.merge`）。

### 代码

```js
// —— 去重 ——
const arr = [1, 2, 3, 2, 1, 4]
// 1) Set，最简单
const uniq = [...new Set(arr)]

// 2) filter + indexOf，实现简单也能熟练手写
const uniq2 = arr.filter((v, i) => arr.indexOf(v) === i)

// 3) 对象数组去重（按 key）
function uniqueBy(arr, key) {
  const seen = new Set()
  return arr.filter((item) => {
    const v = item[key]
    if (seen.has(v)) return false
    seen.add(v)
    return true
  })
}

// —— 扁平化 ——
// 1) 原生 flat
const flatArr = [1, [2, [3, [4]]]].flat(Infinity) // [1,2,3,4]

// 2) 手写递归
function flatten(arr) {
  return arr.reduce((acc, cur) => {
    return acc.concat(Array.isArray(cur) ? flatten(cur) : cur)
  }, [])
}

// 3) 栈式非递归
function flattenStack(arr) {
  const stack = [...arr]
  const result = []
  while (stack.length) {
    const item = stack.pop()
    if (Array.isArray(item)) stack.push(...item)
    else result.unshift(item)
  }
  return result
}

// —— 深合并（递归版 merge）——
function isPlainObject(v) {
  return Object.prototype.toString.call(v) === '[object Object]'
}
function deepMerge(a, b) {
  const result = Array.isArray(a) ? [] : {}
  // 先拷 a，再合并 b
  Object.keys(a).forEach((k) => {
    result[k] = Array.isArray(a[k]) && Array.isArray(b?.[k])
      ? deepMerge(a[k], b[k])
      : isPlainObject(a[k]) && isPlainObject(b?.[k])
        ? deepMerge(a[k], b[k])
        : a[k]
  })
  Object.keys(b || {}).forEach((k) => {
    if (result[k] === undefined) result[k] = b[k] // a 中没有的键直接取 b
  })
  // 补充 b 中作为「引用」覆盖的键
  Object.keys(b).forEach((k) => {
    if (!(k in a)) result[k] = b[k]
  })
  return result
}
```

### 关键点

- 去重：`Set` 最简洁；要「保序 + 无需额外空间」选 `filter+indexOf`。
- 扁平化：递归思路是「遇数组继续递归，遇元素直接推进结果」。
- 深合并：核心是「对重叠的键，若双方都是对象则递归；否则以后者为主」，注意区分数组与对象（数组不能走对象递归，且不能污染原型）。

## 二进制相关（Blob / ArrayBuffer / FileReader）

> 可结合源笔记 `article/binary.md`，下面是浓缩版知识骨架。

JS 处理文件/原始数据的常用 API：`File`、`Blob`、`FileReader`、`ArrayBuffer`、`TypedArray`、`DataView`、`base64`。

### Blob（二进制大对象）

不可变的类文件对象。创建 `new Blob(array, { type })`；可 `slice` 分片；`URL.createObjectURL(blob)` 生成可预览的 URL。

```js
const blob = new Blob(['Hello World'], { type: 'text/plain' })
console.log(blob.size, blob.type) // 11 text/plain
console.log(blob.slice(0, 5).size) // 5，分片
const url = URL.createObjectURL(blob) // 用于 img/下载
```

### File

`File` 是特殊的 `Blob`。通常来自 `<input type="file">` 的 `FileList`，或拖放的 `e.dataTransfer.files`。属性：`name`、`size`、`type`、`lastModified`。

### FileReader（异步读取）

把 Blob/File 读成不同格式：

```js
const reader = new FileReader()
reader.onload = (e) => console.log(e.target.result)
reader.readAsText(file)       // 读成文本
// reader.readAsDataURL(file) // 读成 base64
// reader.readAsArrayBuffer(file) // 读成 ArrayBuffer
```

### ArrayBuffer / TypedArray / DataView

`ArrayBuffer` 是**固定长度的原始二进制缓冲**，本身是黑盒，不能直接读写，必须通过视图对象：

- `TypedArray`（如 `Uint8Array`、`Int32Array`）：固定数据格式的视图。
- `DataView`：可自定义格式与字节序的视图，用 `getUint8 / setUint8` 等读写。

```js
const buffer = new ArrayBuffer(16)
console.log(buffer.byteLength) // 16
const view = new Uint32Array(buffer) // 把 buffer 当一组 32 位无符号整数看
const dv = new DataView(buffer)
dv.setUint8(0, 255)
console.log(dv.getUint8(0)) // 255
```

### base64

用 64 个可打印字符表示二进制数据。`btoa()` 编码、`atob()` 解码。

```js
btoa('javascript') // 'amF2YXNjcmlwdA=='
atob('amF2YXNjcmlwdA==') // 'javascript'
```

### 关键点

- Blob → 整体文件，适合传输；ArrayBuffer → 可变二进制数据，适合按字节操作。
- 组合链路：File/Blob → FileReader(-ArrayBuffer) → TypedArray/DataView → 处理后转 Blob 下载/上传。
- 记住 MIME 常见映射：`text/plain`、`application/json`、`image/png`、`audio/mpeg`、`video/mp4` 等。

### `_.get` 手写示例

```js
function get(obj, path, defaultVal) {
  const keys = Array.isArray(path) ? path : path.replace(/\[(\d+)\]/g, '.$1').split('.')
  let res = obj
  for (const key of keys) {
    res = res?.[key]
    if (res === undefined) return defaultVal
  }
  return res
}
console.log(get({ a: { b: [{ c: 1 }] } }, 'a.b[0].c')) // 1（支持 a.b[0].c 写法）
```

### 关键点

- 手写版是为了理解原理，生产环境直接用 `lodash` 即可。
- `_.get` 常见考点：**支持 `a.b[0].c` 路径**、缺省值 `defaultVal` 的处理。
