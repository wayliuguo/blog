前端框架原理 · React 最小实现 Demo 目录

这 3 个 demo 均用原生 JS 手写而成，不依赖任何第三方库，浏览器直接打开即可在页面上看到结果。

React 原理

  • mini-runtime：手写极简渲染器 createElement + render + onUpdate（虚拟 DOM + 声明式更新）
  • vdom-diff：两棵轻量虚拟 DOM 树做最小 diff，输出生成的 patch
  • hooks-demo：用普通数组实现极简 useState / useEffect（hooks 调用顺序原理）

浏览器直接打开本目录下的任一 html 即可看到结果，无需启动服务器。
