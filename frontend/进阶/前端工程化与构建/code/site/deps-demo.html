pnpm 依赖快照 / 硬链接 / 软链

pnpm 把真实文件按内容 hash 只存一份（内容寻址存储），node_modules 里用软链指过去，同名目录内再硬链接到本地。相比 npm/yarn 的扁平 hoist，它隔离了依赖、省磁盘，也防住"幽灵依赖"。 

内容寻址存储（按内容 hash 存一份）：
  .pnpm-store/sha-aaa  <-- "vue@3.4.0" 的内容
  .pnpm-store/sha-bbb  <-- "axios@1.6.0" 的内容
  .pnpm-store/sha-ccc  <-- "vue@3.5.0" 的内容

点击按钮，观察依赖如何被安装、隔离。
