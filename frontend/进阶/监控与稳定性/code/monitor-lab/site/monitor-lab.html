前端监控·单页验证台

用一个页面验证「前端监控体系」的全部概念：三类数据（错误 / 性能 / 业务）在同一个 SDK 里采集、攒批上报， 右侧聚合面板拉取采集端 /api/report 看效果。自动化跑 ?scenario=errors|perf|track。
