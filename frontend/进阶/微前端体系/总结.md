# 模块总结 · 微前端体系

## 知识主线

本模块从"为什么"讲到"怎么造"，五篇是一条从选型到落地的链：

```
01 微前端方案全景与选型（要不要用、用哪类方案）
        │  选定了容器式方案，核心难题浮出水面：同一页面里主子应用怎么互不污染？
        ▼
02 沙箱与隔离机制（JS 沙箱三方案 + 样式隔离）★主轴
        │  隔离有了，主子应用之间怎么通信、共享状态？
        ▼
03 应用通信与状态共享（生命周期协议、事件总线、shared store）
        │  通信通了，子应用的代码和依赖怎么高效加载、去重？
        ▼
04 资源加载与依赖共享（HTML entry、Module Federation shared 协商）
        │  加载和共享都清楚了，把五篇知识拼成一个可运行的 mini 框架
        ▼
05 手写 mini 微前端框架（HTML entry → 生命周期 → 沙箱 → 样式隔离 → 预加载）
```

本模块的主轴是**沙箱与隔离机制**：01 篇回答选型问题（路由分发式 / 微件式 / 容器式、iframe 的取舍、决策矩阵与代价清单）；02 篇深入容器式的技术核心——快照、Proxy 单例、Proxy 多例三种 JS 沙箱与 Shadow DOM / scoped / 动态样式表三条样式隔离路线，全部配可运行实验台；03~05 篇依次补齐通信、加载与依赖共享，最终收拢为手写 mini 框架。

## 分篇知识点

### 01-微前端方案全景与选型

- **动机判定**：多团队 × 多技术栈 × 独立发布同时出现才值得上微前端；仅"代码多"用模块化 + 代码分割即可
- **三类方案**
  - **路由分发式**：Nginx 按路由转发到各子应用静态资源，页面级整合、零侵入，但切换整页刷新、无局部嵌入能力
  - **微件式**：子应用作为页面局部区块嵌入，Web Components（自定义元素 + Shadow DOM）是原生路径，适合客服组件 / 图表卡片
  - **容器式**：容器应用负责布局、路由分发、生命周期调度、沙箱与通信，qiankun / micro-app / wujie 均属此类
- **iframe 取舍**：隔离最强（JS/CSS/DOM 硬隔离）、接入成本最低，但 URL 状态易丢、弹窗困在框内、内存与首屏开销成倍、只能 postMessage 通信；适合一次性接入第三方异构系统，wujie 的思路正是"iframe 管 JS 隔离 + Web Components 管渲染"
- **决策矩阵**
  - **中后台多团队平台**：qiankun / micro-app 类容器框架
  - **多应用共享依赖且同一构建链**：Module Federation（解决依赖共享而非隔离）
  - **嵌一个卡片 / 组件**：Web Components，别上框架
  - **完全不可控的第三方老系统**：iframe / wujie
- **代价清单**：复杂度上移（容器基建本身要维护）、公共依赖重复、样式一致性难、调试链路变长、版本兼容矩阵；微前端是组织架构问题的技术解

### 02-沙箱与隔离机制

- **隔离对象**：`window` 运行时、样式表、DOM 查询、定时器 / 监听器 / fetch 劫持等副作用
- **快照沙箱（legacy）**：激活时拍全局快照，失活时 diff 记下新增与修改并还原全局；简单可靠，但激活/失活必须完整交替，同一时刻只能跑一个应用
- **Proxy 单例沙箱**：`set` 陷阱顺手记账（写过什么），失活只撤销记账的属性，开销与写入次数成正比、与全局大小无关；仍是单例交替
- **Proxy 多例沙箱**：每个应用一份 `fakeWindow`（`Object.create(sharedGlobal)`），读沿原型链回落共享全局、写只进自己那份；天然支持多应用并存，qiankun 2.x / micro-app 采用
- **样式隔离三路线**：Shadow DOM（浏览器级隔离，但弹窗会逃出 shadow 边界）、选择器前缀 scoped（`[data-app=main] .card`，构建期 CSS Modules / postcss 做）、动态样式表（按应用标记整批启停，卸载后新元素丢样式）
- **DOM 与副作用**：`querySelector`/`createElement` 重定向到容器；拦截 `setInterval`/`addEventListener` 记账，unmount 统一回滚——与沙箱"记账"同一思路
- **选型结论**：新项目一律 Proxy 多例；要兼容 IE11 只能退回快照并接受单应用交替
- **最小实现**
  - **`sandbox-lab`**：零依赖实验台，`node run.cjs` 跑四个场景（快照还原 / 单例记账恢复 / 多例互不可见 / scoped 前缀），`node:assert` 自检全绿
