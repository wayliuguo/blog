# collab-app · yjs 双客户端协同（真实工程）

《复杂交互与编辑器》模块「协同编辑」篇配套真实工程：yjs + BroadcastChannel 的最小协同文本编辑器，免服务端即可演示 CRDT 全链路（生产把 provider 换成 `y-websocket` 即可）。

## 跑起来

```bash
npm install
npm run dev     # http://127.0.0.1:5202
```

## 建议动手实验

1. A、B 两侧各打字 → 文本实时收敛；本端/远端事务计数此消彼长。
2. A、B **同时**在文末打字（先点 A 再立刻点 B）→ 两侧结果一致——同位置并发插入由 CRDT 字符 id 全局定序，无需中心裁定。
3. A 点「撤销」→ 只有 A 的输入回退，B 的文字原地不动（协同撤销语义）。
4. 删除一段文字 → 墓碑视图里字符仍在（带划线 `\u0338`）——这就是「协同文档只增不减」的来源，也是文档体积需要服务端压缩的原因。
5. 再开一个浏览器 tab 访问本页 → 第三个客户端自动入会（BroadcastChannel 同源多 tab 自动同步）。

## 与探针实验台的关系

`editor-lab`（`node run.cjs`）用穷举到达顺序把收敛性钉死，可 CI 回归；本工程把「收敛、撤销语义、墓碑、感知」放进真实交互。`src/doc.js` 的 provider 与探针逻辑同源，注释标注了来源篇目。
