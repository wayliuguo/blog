网络与协议进阶 · Demo 目录

这个目录里的页面是「给人看」的演示；所有数字来自 code/net-lab 的场景脚本（npm run http2 / cache / retry / security），零依赖、不需要 npm install。

页面

  • cache.html —— 三种 Cache-Control 的第二次请求有什么不同，页面里可以直接看到状态码与 字节数
  • security.html —— 带 CSP 与 SRI 的页面：一段带 nonce 的内联脚本能跑，另一段没有 nonce 的会被拦下（看 DevTools Console）
  • vendor.js —— 被 SRI 保护的示例脚本，改一个字节校验就失败

可直接访问的端点

  • /api/cache/immutable/app.js · Cache-Control: public, max-age=31536000, immutable
  • /api/cache/etag/doc.json · Cache-Control: no-cache + ETag，带 If-None-Match 时回 304
  • /api/cache/swr/feed.json?age=300 · max-age=60, stale-while-revalidate=600
  • /api/cache/html · Cache-Control: no-store
  • /api/slow?ms=200 · 延迟响应，用来看队头阻塞
  • /api/flaky?key=a&fail=2 · 前两次 503 + Retry-After，之后成功

命令行场景

  • npm run list —— 查看全部场景
  • npm run http2 —— HTTP/1.1 与 HTTP/2 的多路复用、队头阻塞对照
  • npm run cache —— 强缓存 / 协商缓存 / swr / no-store 对照
  • npm run retry —— 重试策略、超时与取消、重试风暴、幂等
  • npm run security —— SRI 校验、CSP 判定、安全响应头体检
