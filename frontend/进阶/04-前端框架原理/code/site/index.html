04-前端框架原理 · 最小实现 Demo 目录

这 6 个 demo 均用原生 JS 手写而成，不依赖任何第三方库，浏览器直接打开即可在页面上看到结果。

React 原理

  • mini-runtime：手写极简渲染器 createElement + render + onUpdate（虚拟 DOM + 声明式更新）
  • vdom-diff：两棵轻量虚拟 DOM 树做最小 diff，输出生成的 patch
  • hooks-demo：用普通数组实现极简 useState / useEffect（hooks 调用顺序原理）

Vue3 原理

  • mini-reactive：手写 Proxy 版响应式 track / trigger（读时收集、改时触发）
  • vdom-vue-diff：轻量 VNode 树 diff 生成 patch（按差异补丁更新）
  • compiler-demo：模板字符串 → 渲染函数（编译模块最小实现）

启动方式：在 code 下执行 npm start（即 node server.js），然后打开 http://localhost:5182/ 。
