前端工程化 · 最小实现 Demo

工程化本质是把"手工流程"交给"工具"。下面几个玩具级 demo,覆盖模块化与包管理、脚手架与依赖隔离;全部为纯前端演示,浏览器直接打开即可。

其中 01 极简打包器 / 03 tree-shaking / 04 热更新属于构建话题,完整可跑的实现已移到 同级的「构建体系」模块 code/build-lab,这里保留为浏览器端的概念演示。

  • 01 极简打包器:手写模块拼装

    把两个存在依赖关系的"模块"字符串拼接成一份打包产物,模拟打包器从入口收集依赖并产出单个文件。

  • 02 package.json:语义化版本解析

    用一段 JS 解释 `^1.2.3`、`~1.2.3`、精确版本三者的区别并给出解析结果。

  • 03 概念可视化:tree-shaking 与代码分割

    列出哪些导出被摇树剔除、哪些被保留,直观呈现"被剔除 = 未使用"。

  • 04 热更新思路:轮询本地信号

    用原生 fetch 定时请求本地 json 作为"文件变更信号",模拟最小 dev-server + 热更新。

  • 05 依赖快照 / 硬链接 / 软链

    模拟 pnpm 的依赖隔离与扁平化:展示依赖快照、硬链接与软链接的结构差异。

  • 06 脚手架 CLI 参数解析与 workspace

    脚手架 CLI 参数解析与 monorepo workspace 简化演示。
