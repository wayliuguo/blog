# 工程素养：模块总结（占位）

> 本模块规划 3 篇（L3），回答一个问题：**资深工程师的「怎么做」——方案、评审与事故复盘。**

## 知识主线（规划）

```
01 技术方案写作与架构评审（方案结构 / 取舍论证 / 风险与回滚）
        ▼
02 代码评审与技术债治理（CR 关注点 / 债的识别与偿还 / 重构安全网）
        ▼
03 线上事故复盘与应急响应（分级 / 止血 / 复盘模板 / 混沌演练）
```

与 `面试方法论` 的边界：方法论教「怎么讲」，本模块教「怎么真的做出来并讲清楚」。

篇目陆续落地；已落地篇目的分节会按「篇小结 → 总结」的反向落回流程补齐。
