# 浏览器底层与 V8：模块总结

> 本模块 4 篇，回答一个问题：**引擎内部是怎么跑的，以及怎么用探针把「感觉」变成「实测」。**

## 知识主线

四篇不是并列的知识点，而是一条有依赖关系的链，每一篇都在回答上一篇留下的问题：

```
01 Chrome 多进程与渲染管线（谁在跑：进程、线程与像素旅程）
        │  主线程只是执行者之一，JS 代码在它上面怎么被加速？
        ▼
02 V8 执行与优化（怎么跑快：分层编译、隐藏类、优化与反优化）
        │  优化得再快，内存不回来还是崩——回收的规则是什么？
        ▼
03 内存模型与 GC（怎么回收：分代、增量标记、泄漏定位）
        │  JS 太慢的极端场景，还有什么牌？
        ▼
04 WebAssembly（最后的底牌：字节码、数字语义与互操作）
```

与基础板块 `浏览器渲染原理` 的边界：基础讲「页面怎么渲染出来」，本模块讲「引擎内部怎么跑 + 怎么实测」。

## 分篇知识点

### 01-Chrome 多进程与渲染管线

- **多进程**：浏览器主进程（UI/调度）/ GPU 进程（合成汇总）/ 网络进程 / 渲染进程（**站点隔离**，每站点一个）/ 插件进程
- **渲染进程四线程**：主线程（JS + 样式 + 布局 + 绘制记录）· 合成器线程（输入 + 合成）· 光栅线程池（位图）· Worker
- **管线**：JS → 样式 → 布局 → 绘制记录（只出指令列表）→ 分块光栅 → 合成出帧
- **合成器为什么快**：transform/opacity 只影响合成、绕开主线程，主线程卡死动画照跑；代价是层爆炸占显存
- **输入流转**：合成器可独立滚动；click 必进主线程排队——`passive: true` 是免费的性能开关
- **进程边界实测（探针）**：崩溃隔离（一进程崩另一正常）· 内存不共享（结构化克隆副本，子改父不变）· 序列化按字节付费（1 万条≈20ms、100 万条≈1.3s，比同进程遍历慢 18→200+ 倍）· 每进程固定开销≈48MB → 进程要复用且设上限

### 02-V8 执行与优化

- **分层执行**：AST → Ignition 字节码（收集类型反馈）→ Sparkplug → Maglev → TurboFan
- **隐藏类（map）+ 内联缓存**：属性按形状偏移直取；`%HaveSameMap` 实测——同构 true · 乱序 false · 事后加属性 false · delete 推入字典模式
- **tier-up 实测**（`--allow-natives-syntax`）：冷（未优化）→ 预热 10 万次 → optimized + TurboFan（status 81）
- **反优化实测**：一个字符串参数让 optimized 位清零
- **军规只在热路径有意义**：构造函数一次初始化全字段 / 类型保持一致 / 热对象别 delete / 字段顺序一致

### 03-内存模型与 GC

- **可达性定义**：从根触达即活——泄漏 = 你以为丢了但还能摸到
- **分代**：新生代 Scavenge（快、小），老生代 Mark-Compact（慢、大），增量 + 并发标记消停顿
- **回收实测**（`--expose-gc`）：200 万作用域垃圾 GC 后回基线（4MB → 4MB）
- **泄漏实测**：全局缓存让 GC 后仍占 88MB，放开引用回到 4MB
- **四大持有模式**：全局缓存只进不出 / 定时器没清 / 监听器没退订 / 分离 DOM
- **定位套路**：快照 A → 操作 N 次 → 快照 B → Comparison 找净增长 → Retainers 看谁攥着

### 04-WebAssembly

- **定位**：沙箱化的可移植字节码，接近原生速度；「算数字的函数库」而非更快的 JS
- **手写字节码实测**：77 字节手工组装 `sum` 模块（类型/函数/导出/代码四节），`Instance.exports` 即普通 JS 函数
- **数字语义分界线**：i32 超 2³¹ 回绕（实测 1784293664），JS double 精确——大数走 i64/BigInt
- **性能实测**：1 亿次循环累加 wasm 39ms vs JS 145ms（约 3.7 倍）
- **边界成本**：跨调用传参有转换开销——一次跨边界调用要干足够多的活；工程路径 Rust/C++ → wasm-pack/Emscripten

## 最小实现

- **`v8-lab`**：零依赖探针实验台，`node run.cjs` 按所需 flag 分子进程执行三探针（分层编译/反优化/隐藏类 · GC 回收与泄漏 · 手写字节码 wasm 对比），`node:assert` 自检全绿
