11-工程实践与架构 · 最小实现 Demo

架构的本质是"把耦合拆散、把复用统一"。看懂下面三个玩具级 demo，你就抓住了事件通信、状态管理与模块化/微前端的最小骨架。全部为纯前端演示，浏览器直接打开即可。

  • 01 发布/订阅：手写事件中心

    极简 EventHub，两个组件互不引用对方，只通过事件中心收发消息，演示组件通信与解耦。

  • 02 状态管理：手写单例 store

    极简单例 store，subscribers 订阅状态、set 变更后自动通知所有组件重渲染，演示"单一数据源 + 订阅更新"。

  • 03 模块化/微前端：按需加载模块

    只在需要时才真正载入某个模块，并对比 import map 与 ESM 静态导入，演示"按需加载/远程模块"的思想。
