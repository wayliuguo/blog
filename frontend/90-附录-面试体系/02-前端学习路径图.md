## 四、学习建议

1. **不要跳步**：初级没过关直接学 React/响应式原理只会越学越乱。
2. **动手写代码**：每个阶段配一个迷你项目（布局页 → 交互页 → 中后台 → SSR → 可视化大屏）。
3. **先掌握再深入**：初级必须全会，高级可先保理解，再逐个攻破。
4. **搭配自测**：完成一个阶段后，回到 [01-面试自测题](./01-面试自测题) 对应题号自测，用 [08-自测记录表](./08-自测记录表) 记录薄弱项。
5. **结合面试方法论**：答题时套用 [07-面试方法论](./07-面试方法论) 的五步法，把知识点讲成"结论 + 原理 + 场景 + 边界 + 追问"。
