## 一、初级篇（45 题）

> 覆盖段：入门/HTML/CSS/JS 基础/网络与浏览器基础/TS 基础/工程化与 Git 基础

### 第三阶段：CSS 基础（11-18）

18. 常见 CSS 单位有哪些？`px`、`em`、`rem`、`vw`、`vh` 有什么区别？

### 第四阶段：JavaScript 基础（19-30）

19. JS 有哪些数据类型？如何区分原始类型和引用类型？

29. JS 中有哪些常用的内置对象？
30. `Map` 和 `Object` 有什么区别？什么场景用 `Map`？

### 第五阶段：网络与浏览器基础（31-37）

31. HTTP 三要素是什么？常见的状态码有哪些？
32. GET 和 POST 有什么区别？
33. `localStorage`、`sessionStorage`、`Cookie` 三者有什么区别？
34. 什么是跨域？JSONP 的原理是什么？
35. 什么是 DOM？什么是 BOM？两者有什么关系？
36. 简述 JavaScript 事件循环入门知识：什么是宏任务、什么是微任务？

### 第六阶段：TypeScript 基础（38-42）

38. TypeScript 是什么？它解决了 JavaScript 的哪些痛点？
39. `interface` 和 `type` 有什么区别？
40. 什么是泛型？举一个简单的使用例子？
41. `any`、`unknown`、`void`、`never` 之间有什么区别？

### 第七阶段：工程化与 Git 基础（43-45）
