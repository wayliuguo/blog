# 方案：移除板块内面试题 + 前端扁平化重构 + /interview 按父目录重组

> 状态：设计稿（待确认后执行）。生成日期 2026-10-15，含两轮澄清。
> 澄清 1：面试题删除不迁移，/interview 为唯一来源；前端保留模块需扩充。
> 澄清 2（本轮）：前端框架原理不单列（归 vue/react）；/interview 面试题按 前端/后端/ai 父目录组织。

## 一、目标

1. **去除面试题**：从 AI / 前端 / Node 三板块移除内嵌的 `面试题.md` 入口与文件，面试知识统一只留在 `/interview`。
2. **前端扁平化**：去掉 `frontend/基础`、`frontend/进阶` 两层目录，模块提到 `frontend/` 根下平铺。
3. **/interview 父目录重组**：面试题不再平铺在 `/interview` 根，而是归入 `前端/`、`后端/`、`ai/` 三个父目录；格式仍用完全自由格式（题面先行 + 要点，不用判断→展开→边界四槽）。

## 二、已对齐的决策

| 项 | 结论 |
|---|---|
| 三板块面试题内容 | **删除入口与文件，不迁移**（/interview 为唯一来源） |
| 前端保留模块 | 用户点名 12 个 + 补充：构建体系、网络与协议进阶；**前端框架原理不单列，归 vue/react** |
| /interview 结构 | **前端/、后端/、ai/ 三个父目录** |
| /interview 格式 | **完全自由格式**，不强制任何骨架 |

## 三、任务一：移除三板块面试题（共 34 篇）

### 3.1 删除文件
- AI：`ai/agent-development/面试题.md`（1）—— 此篇**不删除**，改为迁入 `/interview/ai/` 作为 ai 父目录的内容（见任务三）。
- 前端：`frontend/基础/**/面试题.md` + `frontend/进阶/**/面试题.md`（27）
- Node：`node/<模块>/面试题.md`（6）

### 3.2 侧边栏配置
- `ai.js`：删「Agent 模块面试题」条目。
- `frontend.js`：删 27 条 `模块面试题（XXX）` 条目（随扁平化整体重写）。
- `node.js`：删 6 条 `模块面试题（XXX）` 条目。

### 3.3 文档组织规范同步更新
- `文档组织规范/readme.md` §4：改写为「模块元页面为总结.md；面试题统一收敛到 /interview，不再内嵌各模块」。
- `文档组织规范/reference/模块面试题.md`：删除（四槽规范不再适用）。
- 其余 reference 文档中「面试题」引用：改为指向 /interview 或删除。

## 四、任务二：前端扁平化

### 4.1 目标结构（去掉基础/进阶 两层）
```
frontend/
  html/  css/  js/  ts/  网络与浏览器/  网络与协议进阶/
  vue/  react/  构建体系/(含 Vite 等子页)
  测试体系/  性能优化/  前端监控/(原 监控与稳定性)  工程实践与架构/
```
- 用 `git mv` 把模块提到 `frontend/` 根；模块内子页（语义化、表单、总结等）保留不动。
- 命名映射：
  - `基础/HTML 基础` → `html`；`基础/CSS` → `css`；`基础/JavaScript 核心` → `js`
  - `基础/网络与浏览器` → `网络与浏览器`；`基础/前端框架-Vue` → `vue`；`基础/前端框架-React` → `react`
  - `进阶/TypeScript` → `ts`；`进阶/构建体系` → `构建体系`；`进阶/测试体系` → `测试体系`
  - `进阶/性能优化` → `性能优化`；`进阶/监控与稳定性` → `前端监控`；`进阶/工程实践与架构` → `工程实践与架构`；`进阶/网络与协议进阶` → `网络与协议进阶`
- **前端框架原理**：不单列。其框架无关的原理性内容（响应式、虚拟 DOM、diff 等）按框架归属并入 `vue/`、`react/`；无明确归属的通用原理页删除。

### 4.2 删除模块（非保留，共 14 个）
来自 `基础/`：小程序、工程协作。
来自 `进阶/`：前端工程化、交付与质量、低代码与搭建体系、可视化与图形、复杂交互与编辑器、工程素养、微前端体系、渲染架构、浏览器底层与 V8、跨端与桌面深化、AI 前端工程、前端框架原理（folded 进 vue/react）。

> 已确认（2026-10-15）：以上 14 个模块**全部删除**，含其中的总结.md 与配套代码。`前端工程化`/`浏览器底层与 V8`/`渲染架构` 经用户确认不保留。

### 4.3 侧边栏与链接
- `frontend.js` 重写为单层 flat 列表（路径不再含 基础/进阶）。
- 跨页相对链接、README、文档组织规范中的路径示例同步改路径。
- 跑 `vitepress build` 验证无死链（移目录会破坏大量内部链接，需逐篇修）。

## 五、任务三：/interview 按父目录重组 + 自由格式

### 5.1 目标结构
```
interview/
  反问面试官.md          # 根，通用（向面试官提问的职场技巧）
  项目面试题.md          # 根，通用（项目经验陈述类）
  前端/
    面试题-JS与TS基础.md
    面试题-浏览器与网络.md
    面试题-Vue.md
    面试题-性能优化.md
    面试题-自动化测试.md
    面试题-监控系统.md
    面试题-工程构建.md
  后端/
    面试题-Node.js服务端.md
  ai/
    面试题.md            # 来自 ai/agent-development/面试题.md（从板块移除后迁入此处）
```
- 搬迁用 `git mv`，原 `/interview` 根下的 8 篇 `面试题-*` 移入 `前端/`，`面试题-Node.js服务端.md` 移入 `后端/`。
- `ai/agent-development/面试题.md` → `interview/ai/面试题.md`（既是「从板块移除」，也填满 ai 父目录）。

### 5.2 侧边栏配置
- `interview.js` 改为三层：`反问面试官`/`项目面试题`（根）→ `前端`/`后端`/`ai` 三个分组，每组下挂各自面试题。
- 导航 `nav.js` 的「面试」入口保持指向 `反问面试官`。

### 5.3 格式
- 确认各面试题已是「章节分组 + Qn + 要点」轻量形态；清理任何残留「判断 / 展开 / 佐证 / 边界」标签，统一为「题面先行 + 自然要点」。

## 六、执行顺序与验证

1. 任务一（删 33 篇文件 → 改三份 config → 改规范）→ `vitepress build` 验死链。
2. 任务二（`git mv` → 删 14 模块 → 重写 `frontend.js` → 修链接）→ `vitepress build` 验死链。
3. 任务三（`git mv` 重组 + ai 迁入 → 重写 `interview.js` → 清理格式标签）→ `vitepress build` 验死链。
4. 分桶提交（interview / frontend / .vitepress / 文档组织规范 各自提交）。

## 七、风险

- 移除面试题后，原 34 篇中的「【项目】」实战标记内容随删除丢失（按决策不迁移；仅 ai 面试题迁入 /interview/ai）。
- 扁平化移动目录会触发大量内部链接断裂，修复工作量集中在任务二，需逐模块 `grep` 校对。
- 规范文档中多处把「总结 + 面试题」作为模块标配，改写需全量检索 `面试题` 字样避免遗漏。
- /interview 重组后，旧 `interview/面试题-*` 直链失效，需同步 `/interview` 内部互相引用。
