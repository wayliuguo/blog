## interview/模拟面试.md 内容打磨（多轮）

- 「借钱 H5 首屏优化」定稿口径：串行改并行单点归因 400ms，其余手段组合拳共约 600ms；挽留弹窗叙事 = 原与页面主 bundle 打在一起首屏同步加载 → 拆独立 bundle（实测口径：传输 330KB gzip / 原始 1.2MB）+ defineAsyncComponent + onMounted 注册、load 后 rIC 闲时预热（timeout 5000 防饿死，iOS<16.4 需 setTimeout 兜底）；骨架屏口径对准 FCP/CLS/感知秒开，实测 LCP 元素是背景图不是骨架屏。相关代码统一放题末。
- 「LCP 元素有变 + 自定义指标」独立成题：自定义指标抽成 useCoreBlockReport hook、setup 里调用、模块级 guard 打过一次不再打；measure 基准 start:0（首跳口径，LCP 是导航级指标，SPA 只测首跳；软导航 route-start 基准只作延伸注释）。
- 「请求竞态」成题：双闸（fetch 版 + axios 拦截器版，闸一请求拦截器 abort、闸二响应拦截器按 seq 丢弃）+ generation + onCleanup。关键修正：同 key 序号必须按 key 隔离（全局序号会误杀其他 key 响应）；axios 判断 seq===latest 才清在飞记录（controller !== signal 的比较 bug）。
- 「请求缓存」拆成独立一题：key = method+url+稳定序列化入参（stableStringify 排序），不暴露业务 key；入参开关 cache:true | {ttl} 默认关闭（写接口误缓存是事故级）；axios adapter 短路回缓存；失败不缓存用 p.catch 非 finally（finally 会把成功缓存立刻删掉 + TS 循环推断报错需显式标注 p 类型）；invalidateByPrefix 按 URL 前缀批量失效。
- 踩坑记录：**markdown 代码围栏失衡**会触发 Vite「Element is missing end tag」（191 行 ts 块提前闭合，后面三段代码裸露被当 Vue 模板解析）；另有一次编辑被编辑器旧内容保存覆盖回退——提交前用 `grep -c '^\s*```'` 校验围栏数为偶数。
