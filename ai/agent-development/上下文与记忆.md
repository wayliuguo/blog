# 上下文与记忆：让 Agent 记住对话

## 多轮对话本质 = Context 管理

Agent 要"记住对话"，短期靠把历史 `messages` 重新塞回请求；但历史不可能无限增长，必须主动管理。所谓"记住"，首先是 **Context 管理问题**：在 `Context Window` 内保留对当前任务有用的信息，丢掉的用别的方式补回。

```
User → LLM → Answer            （无记忆）
User → LLM → Tool → LLM → Answer   （单轮 Agent）
User → [历史 messages] → LLM  （多轮：把历史重新塞回）
```

## 按对话轮次裁剪历史

最朴素的裁剪按 token 截断，会切坏一条完整交互。更合理的是**按"对话轮次（Round）"裁剪**：一次 `user` 触发的连续交互（含中间的 `assistant(tool_calls) / tool / assistant`）算一轮，只保留最近 N 轮。

> 摘自 `code/agent-lab/memory/context-manager.ts`（运行：`npm run context`）

```ts
type Role = 'system' | 'user' | 'assistant' | 'tool'

interface Message {
  role: Role
  content?: string
  tool_calls?: unknown[]
}

// 按"完整对话轮次"裁剪历史：一轮 = 一次 user 触发的连续交互。
export function trimMessages(messages: Message[], maxRounds = 5): Message[] {
  const rounds: Message[][] = []
  let current: Message[] = []
  for (const message of messages) {
    if (message.role === 'user') {
      if (current.length > 0) rounds.push(current)
      current = [message]
      continue
    }
    current.push(message)
  }
  if (current.length > 0) rounds.push(current)
  return rounds.slice(-maxRounds).flat()
}
```

核心思想：遇到 `user` 就开新轮。普通对话 `user/assistant` 是一轮；带 Tool 的 `user/assistant(tool_calls)/tool/assistant` 也是一轮；一次多个 Tool 仍算一轮。

## Rolling Summary 压缩历史

当轮次也装不下时，把较早的历史压缩成一段摘要（Rolling Summary）注入 System Context，腾出空间。摘要的质量决定了 Agent 长期对话的连贯性——它替代了被丢弃的原始消息，所以摘要要保留关键事实与未决任务。

> 示意片段（无配套脚本）

```ts
// 思路：把超出窗口的旧轮次交给 LLM 压成一段 summary，再注入 System
const oldRounds = rounds.slice(0, rounds.length - keep)
const summary = await llm.summarize(flatten(oldRounds))
systemContext = `已知背景摘要：\n${summary}`
```

## 短期记忆 vs 长期记忆

| 类型 | 存什么 | 生命周期 | 实现 |
| ---- | ---- | ---- | ---- |
| 短期记忆 | 当前会话 `messages` + 裁剪 + 摘要 | 随会话结束消失 | 内存数组 + `trimMessages` + Summary |
| 长期记忆 | 跨会话的用户偏好、事实 | 持久化、按需检索 | Embedding + 向量库（见第 5 篇） |

长期记忆不能靠"全量塞入 Context"——既撑爆窗口又浪费 token。正确做法是语义检索 TopK 注入（第 5、6 篇）。

## 架构演进：Agent 是怎么一点点长出来的

```
LLM
  → +Tool            （能调用外部能力）
  → +AgentLoop       （能连续行动）
  → +ContextManager  （能管理有限窗口）
  → +Memory          （短期 摘要 / 长期 向量）
```
