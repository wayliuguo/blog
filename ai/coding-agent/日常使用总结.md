## 使用AI 遇到的问题

- 代码规范类
  - 表现
    - 生成的代码不符合已有配置的eslint 规范
    - ts 类型不符合规范
  - 解决方案
    - 规范添加上代码规范文档
    - 添加agent 钩子搭配代码格式化或push 进行代码格式化
- 质量类
  - 表现
    - 模板逻辑复杂、变量语义、变量冗余
    - 组件提取、逻辑提取复用、类型提取复用
    - 改动引起其他模块的失败
  - 解决方案
    - 引入对应的框架最佳实践 skill
    - 定义相关变量规范文档，按需引入
    - 严格使用SDD，先方案再确认执行
    - 引入自动化测试，执行完成或push执行用例
- 协作类
  - 表现
    - spec kit 太重了，前置的流程很多，要看的文档太多了
    - 频繁触发权限，无法做到【全天候工作】，不注意会被打断
    - 对于内部组件库等私有库，不会去使用
  - 解决
    - 使用更轻量的工作流，如CE\superpowers
    - 定义好权限
    - 构建好 readme，进行链接，及时提醒
- 工程类
  - 表现
    - 多 agent，规范不好统一
    - skill 等团队的沉淀，跨工程、个人没有做好积累共享
  - 解决
    - 前期手工定制过，后面可以看看腾讯 team AI
    - 进行插件化构建
