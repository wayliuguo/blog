17-Web游戏开发 · 最小实现 Demo

本目录用零依赖的纯前端代码演示章节里的核心原理，浏览器打开即可运行。

① game-loop.html — 手写主循环与 deltaTime

用 requestAnimationFrame 手写主循环驱动一个小方块匀速移动并在边界反弹，演示"更新 + 渲染"分离与按时间缩放的 deltaTime 速度控制。

② sprite-anim.html — 精灵表逐帧动画

用原生 Canvas 画几个角色帧并按帧率计数器切帧循环播放，等价于 PixiJS AnimatedSprite，演示精灵表与帧率控制。

③ minigame.html — 接住下落的物品（实战）

一个可玩的小游戏：左右移动接住下落的物品，命中加分、漏接减命，演示 AABB 碰撞检测、计分与 Game Over / 重开流程。

启动方式：在 code/frontend/17-game 下执行 npm start（即 node server.js），然后浏览器访问 http://localhost:5190/。
