01 模拟 SSR vs CSR：首屏 HTML 里有没有内容

真正的 SSR 在服务端把组件渲染成 HTML 字符串再返回，所以浏览器拿到的 HTML 里已经包含正文；CSR 则是浏览器先拿到空壳，再由 JS 运行时把 DOM 填进去。下面用两个"模拟服务器"与"模拟客户端"函数，把这两条渲染路径搬到浏览器里直观对比。

① 模拟服务端渲染：先拼好整段 HTML 再 insert

这一段假装"服务器把文章渲染成了完整 HTML 字符串"，随后一次性写入页面。此刻它的 HTML（即爬虫能看到的内容）是满的。

（尚未渲染）

② 模拟客户端渲染：先挂空壳，再由 JS 填充

这一段假装"服务器只返回一个空壳 div"，正文要等 JS（模拟 client.js）执行后才被动态创建出来。渲染空壳那一刻，它的 HTML（爬虫看到的内容）是空的。

（这里只是空壳，正文还没来）
