02 水合 Hydration：静态 HTML + 客户端再绑定交互

服务端（或构建期）直出的 HTML 是"看得见但点不动"的静态骨架。水合（Hydration）就是在不重建 DOM 的前提下，由客户端 JS 给这些既有节点补上事件监听与状态，让页面"活"起来。下面这个计数器，页面初始时已经写死了静态 HTML，等点击"水合"后才真正能交互。
