03 构建期静态生成 SSG / ISR：构建时产出 + 增量再生成

SSG（静态站点生成）在构建期就把每个页面渲染成静态 HTML，之后浏览器直接拿到现成文件，无需服务器实时算——开发期那些 markdown 就是这么被打包成 HTML 的。ISR 则是"构建生成 + 到点/按需对单个页面增量再生成"。下面用一个玩具构建器演示这份产出。

① 点击"构建"：模拟 SSG 构建器把 markdown 数据渲染成静态 HTML 文件表

生成的静态文件 标题 更新于（生成戳）
（尚未构建）
② 模拟 ISR：对单个页面"增量再生成"，其余静态文件不动

点下面按钮，只重新生成一篇文章页（相当于 revalidate 到点的产物刷新），其它已生成文件保持原样不变。

            更省成本。
