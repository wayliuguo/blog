BFC：父元素的隔离

① 未触发 BFC（父子 margin 塌陷）

子元素 `margin:20px` 没有把父撑出 20px 内边距，而是与父一起把父"拉出" 20px（塌陷）。
父无 BFC → 子 margin 与父合并（塌陷）

② 父触发 BFC（overflow:hidden）→ 子 margin 被父边界包裹

父有 BFC → 子 margin 从父内侧算起，右上角是正常 20px 间距

结论：触发 BFC（如 overflow:hidden、overflow:auto、display:flow-root）让父形成独立渲染上下文，父子 margin 不再合并、子元素也不会"顶出"父。
