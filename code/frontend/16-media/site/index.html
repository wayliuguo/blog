16-音视频与富媒体前端 · 最小实现

对应章节概念的可运行 demo（全部零依赖、纯前端演示原理），请使用现代浏览器（Chrome / Edge / Firefox）打开。

  • 媒体采集media-capture.html

    用 navigator.mediaDevices.getUserMedia 打开摄像头 / 麦克风，实时回显到 <video>，含权限拒绝与不支持时的友好降级提示。

  • Web Audioaudio-viz.html

    用 Web Audio API + AnalyserNode 生成合成振荡器音并实时把声音频谱画到 canvas（无音频文件也能发声）。

  • 语音合成speech-synth.html

    用 speechSynthesis 朗读文本，讲解浏览器的语音合成（TTS）API。

  • MSEmse-hls.html

    MediaSource Extensions 流式播放原理页 + 受控样例说明：浏览器如何用 appendBuffer 实现"边下边播"。

提示：返回章节阅读「最小实现」小节可获得每个 demo 对应的原理说明。
