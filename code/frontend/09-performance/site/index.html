09 性能优化与监控 · 最小实现示例

用浏览器直接打开下面的页面即可看到效果。本组 demo 全部离线可运行，纯前端输出，无任何外部依赖。

perf-reader.html · 读取并展示性能指标

通过 performance.getEntriesByType('paint') 与 PerformanceObserver 读取 FCP / LCP，再算 DOMContentLoaded 与 TTFB，页面先显示 waiting 再打印真实值。

fps-frames.html · FPS 帧率与主线程卡顿

用 requestAnimationFrame 统计当前 FPS，点击按钮同步阻塞主线程，观察帧率骤降与页面卡顿，直观理解"长任务拖垮 60fps"。

lazy-load.html · 懒加载 / IntersectionObserver

用 IntersectionObserver 监听占位元素，滚动进入视口才填充内容并输出观察结果，理解"按需加载"如何省下非首屏资源。

error-report.html · 错误监控与上报

通过 window.onerror 与 unhandledrejection 捕获运行时错误与 Promise 拒绝，拼成 URLSearchParams 模拟一次上报并回显。
