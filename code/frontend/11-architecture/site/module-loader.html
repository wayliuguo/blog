03 模块化/微前端：按需加载模块

微前端的本质之一,就是模块可以独立、按需地加载:业务不需要某个模块时,绝不去下载/执行它;一旦用到,才把它拉进来并缓存。下面用一个"远程模块注册表"模拟这套机制。

import map 与按需加载对比

        

            ES Module 里,import map 的作用是把"裸模块名"(如 import React from 'react')在运行时映射成真正的
            URL;而按需加载/代码分割则是"用到才 import"。两者配合,就能做到"一个运行时里,各微模块各自版本、按需现取"。
        

        

            

                机制
                解决什么
                怎么工作
                前端场景
            

            

                import map
                运行时解析裸模块名
                浏览器按映射表替换 specifier 为 URL
                微前端运行时、共享第三方库
            

            

                动态 import 按需加载
                用到才取、少下载
                import() 返回 Promise,触发 fetch 并缓存
                路由懒加载、组件懒加载
            

            

                远程模块(Webpack Module Federation)
                让多个应用在运行时共享模块
                应用暴露/引用其他应用的模块,按需加载
                微前端多个子应用共享与隔离
