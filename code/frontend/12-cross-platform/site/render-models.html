03 · 渲染模型对比与桥接

跨端方案的差异根源在渲染模型：UI 到底由谁、用什么方式画出来。下面是 React Native / Flutter / Taro / uni-app 四家的"快照"，再用一个简化桥接器演示它们与原生/宿主"适配、桥接"的共同套路。

① 四种渲染模型快照对比

方案 语言内核 渲染路径 与原生/宿主通信 一致性
React Native JS / TS + JSX 映射为原生控件（iOS/Android View） JSI / Bridge（桥） 平台差异中
Flutter Dart 自绘引擎（Skia/Impeller）GPU 绘制 MethodChannel / FFI 极高（UI 引擎绘制）
Taro React（编译型） 编译为各端宿主产物（WXML / H5 / RN） 编译 + 宿主适配层 依目标端
uni-app Vue（编译型） 编译为小程序 / H5 / App（内置引擎） 编译 + 差量原生桥 依目标端
