手写实现 Partial / Exclude

映射类型把对象每个属性变可选（Partial）；条件分发把「拿来取出的类型」剔除（Exclude）。我们用 JS 对象模拟出这两个工具类型在「值层面会怎么变化」。

TS 定义（编译期运算）

type MyPartial<T> = { [K in keyof T]?: T[K] };   // 每个键变可选
type MyExclude<T, U> = T extends U ? never : T;   // 从 T 里剔除属于 U 的成员
type Keys = MyExclude<'id'|'name'|'email', 'email'>; // 'id' | 'name'
