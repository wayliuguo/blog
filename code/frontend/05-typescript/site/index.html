05-TypeScript · 最小实现 Demo 目录

TypeScript 是类型层面的语言，运行时执行的仍是 JavaScript。以下 demo 用纯 JS 把 TS 的类型概念可视化并输出到页面，帮助理解“这些类型到底在说什么”。

  • 结构类型（鸭子类型）：只关心“形状”对得上
  • 联合类型 / 交叉类型：多选一 vs 全都要
  • 泛型容器 + infer 提取返回类型
  • 手写实现 Partial / Exclude（映射类型与条件分发）

启动方式：在 code/frontend/05-typescript 下执行 npm start（即 node server.js），浏览器打开 http://localhost:5178/。

附带 check.ts：可选做类型编译校验（见文件顶部注释，用 npx tsc --noEmit）。
