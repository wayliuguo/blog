结构类型 / 鸭子类型 · 只关心“形状”

TypeScript 用结构性子类型化做判断：一个对象只要“形状”（属性名 + 类型）满足要求即可，不要求是某个类的新实例。运行时仍是普通 JS 对象。

TS 定义（编译期检查，编译后消失）

interface LabelledValue { label: string }
function printLabel(obj: LabelledValue) { console.log(obj.label) }
printLabel({ size: 10, label: 'Size 10 Object' }); // OK，多出的 size 不影响
