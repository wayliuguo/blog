18 · 新兴方向：纯前端原理演示

浏览器里逐个打开下面的 demo，亲手验证 PWA / WebAssembly / AI 前端这几类"新兴方向"的最小实现原理。无需任何第三方依赖与网络。

① PWA：Service Worker 生命周期与缓存策略
在同一目录注册一个精简 Service Worker，给出 install / activate / fetch 的注册结果与说明，并列出四种常见缓存策略及适用场景。
对应《02-PWA渐进式网页应用》
② WebAssembly：为何快 & 编译链路 & wat 示例
用表格与文本可视化 WebAssembly 的概念：为什么接近原生、从源码到 .wat/.wasm 再到实例化的编译链路，以及一个最小 add 的 wat 文本格式展示。
对应《01-WebAssembly》
③ AI 前端：浏览器推理概念 + 文字分类假推理
说明在浏览器跑模型（WebNN / ONNX / WASM）的概念，并用一份预训练常量模拟"文字分类"的假推理演示，离线也能看到完整输出。
对应《03/04/05-AI前端》与《06-WebGPU》

提示：Service Worker 演示请在 http://localhost:5191/pwa-sw.html 下打开，以便满足 SW 需要的安全来源（localhost 被浏览器视为受信）。
