原生 WebGL 旋转三角形 · 着色器原理

顶点着色器（vertex shader）

attribute vec2 a_position;
attribute vec3 a_color;
varying vec3 v_color;
void main() {
  v_color = a_color;                       // 传递给片元着色器，随像素插值
  gl_Position = vec4(a_position, 0.0, 1.0); // 输出裁剪坐标
}

片元着色器（fragment shader）

precision mediump float;
varying vec3 v_color;
void main() {
  gl_FragColor = vec4(v_color, 1.0); // 对该像素计算最终颜色
}

这段代码在做什么

webgl-triangle.html 用原生 WebGL 无任何第三方库画一个旋转三角形。三个顶点各带一个颜色， 顶点着色器把它们通过 varying 传给片元着色器；GPU 光栅化三角形时会把顶点色逐像素线性插值， 于是看到红→绿→蓝的平滑渐变——这正是 Three.js 材质与光照着色的最底层来源。每帧用 requestAnimationFrame 更新一个旋转矩阵（uniform u_rot）并重新 drawArrays。
