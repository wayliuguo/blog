手写坐标系映射与 SVG 元素生成

蓝色是 <rect> 柱状图，橙色是 <polyline> 折线。每个图形都是真实的 DOM 节点，可单独绑定事件——下方两个按钮就是"改一个属性即局部更新"。

这段代码在做什么

svg-chart.html 演示"数据 → 像素坐标 → SVG 元素"的最小链路：先求出数据 min/max 做线性映射得到每个节点的坐标， 再用 createElementNS 创建 <rect>（柱子）与 <polyline>（折线）并设置其绘图属性。 因为 SVG 是保留模式、节点常驻文档，想改一根柱子就只需改它一个元素的属性，无需像 Canvas 那样重绘整块——这是它与 Canvas 的核心差异。
