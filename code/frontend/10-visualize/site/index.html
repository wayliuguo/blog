10-可视化与WebGL · 最小实现 Demo 目录

以下 demo 全部为纯原生 JS 编写、零第三方依赖，用「最小实现」逐点演示可视化与 WebGL 的底层原理。

  • Canvas 2D 手写折线图+柱状图 —— 数据 → 像素坐标，命令式逐笔绘制与按数据重绘
  • 手写坐标系映射与 SVG 元素生成 —— 数据 → SVG 节点，保留模式 vs Canvas 立即模式
  • requestAnimationFrame 粒子动画 —— 帧循环与按帧更新，"清屏 → 重绘 → 循环"
  • 原生 WebGL 旋转三角形 —— 顶点着色器 / 片元着色器，GPU 管线最小示例

启动方式：在 code/frontend/10-visualize 下执行 npm start（即 node server.js），然后访问 http://localhost:5183/。
