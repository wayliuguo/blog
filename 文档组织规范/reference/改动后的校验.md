# 改动后的校验

改完文档按序跑一组校验：链接检查 → 侧边栏覆盖 → 代码同步 → 构建。其中「代码同步」由仓库内配套脚本兜底（可按模块 `--module` 缩窄范围），核心判据只有一条：**代码块标注存在 + 摘录逐字可溯源 + 标注脚本在本文配套代码表中**。

VitePress 构建会被宿主的安全删除保护拦在「清空 `.vitepress/.temp`」这一步（`SAFE_DELETE_BULK_CONFIRM_REQUIRED`，阈值 50）。绕法是让构建进程不加载该保护包装——清空 `NODE_OPTIONS` 再启动：

```bash
NODE_OPTIONS= node node_modules/vitepress/bin/vitepress.js build .
```

注意 `--outDir <目录>` 这个参数 VitePress **不识别**（传了也不生效），产物始终写在 `.vitepress/dist`，判断构建是否成功要看产物（目标板块 html 数与 `hashmap.json`），不能只看日志里的 `✓ rendering pages`。
