# 单篇文档体例

一篇标准文档的固定骨架：

```markdown
# 篇标题

## 小节标题写成问题或判断句
正文……（可从脚本摘录代码，见「代码片段与配套代码表」篇）

## 配套代码
（表格，见「代码片段与配套代码表」篇）

## 参考
- [模块总结](./总结.md)
- [模块面试题](./面试题.md)
```

约定要点（用例子说明，不逐一列禁项）：

- **小节标题**写成问题或判断句：`require 与 import 的本质区别是什么？`
- **篇间引用**写「见第 X 篇」，不硬编码文件路径。
- **结尾两段顺序固定**：配套代码 → 参考；`## 参考` 前两行固定为本模块「总结 / 面试题」入口。
- **ASCII 图**用裸 ` ``` ` 围栏，不要写成 ` ```text `（VitePress 会刷告警）。
