# 模块总结.md：先大纲、再逐项展开

每个模块在侧边栏保留两个入口：`总结.md` 与 `面试题.md`（在 `node/` 内按主题合并为 6 组：01 · 03 · 04 · 05 跨 06 · 07 跨 08 · 09 跨 10,11）。本篇讲总结.md；面试题.md 见 [`模块面试题.md`](./模块面试题.md)。

## 结构

`# 模块总结` 后**无任何开篇说明**，直接 `## 大纲`；大纲之后正文用与大纲同号的标题逐项展开。

```markdown
# 模块总结 · 运行环境

## 大纲
- **1. 章节名**
  - 1.1 知识域
  - 1.2 知识域
- **2. 章节名**
  - 2.1 知识域
  - …

## 1. 章节名
### 1.1 知识域
（知识域正文，必要时嵌局部 ASCII 图 / 代码）
```

要点：

- **开头无说明段**：`# 模块总结` 之后直接进 `## 大纲`，不写知识主线、分篇知识点等独立说明。
- **大纲按知识体系章节分层**，不扁平：一级章节用 `- **N. 章节名**`，章节下再列 `N.N` 知识域；按模块知识体系的板块归类，不把所有知识域平铺 1~N。
- **正文两级标题**：章节用 `## N`、知识域用 `### N.N`，与大纲编号一一对应，标题层级不跳级。
- **局部 ASCII 图**：不画模块级总骨架图；只在知识域节点内、内容本身有结构时落局部 ASCII 图（树 / 分步 / 对比盘）。
- **形态 → 表达**：有父子 / 嵌套 → 树形 ASCII；有先后 → 分步 ASCII；对比 → 表格 / 两列；平级罗列 → 列表。
- **全量收纳**：按知识体系结构化收纳全部知识文档内容，不遗漏、不做高频筛选、不注出处篇号；每个点细化到"能一句话讲清 + 必要时恰配 ASCII / 代码"，不允许只留名词。
- **代码围栏用裸围栏**（不写 ` ```text ` 等语言名）；正文行内双花括号用 `<code v-pre>`；不用 Mermaid。
